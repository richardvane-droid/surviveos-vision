阁楼仓库 · 模块 0401 · 过道工具间

谁懂啊！3.5 米见方的小过道被我改成了一面会发光的工具墙

洞洞板从头铺到尾，每把工具都有自己的影子和名字，伸手就到。

🎬 沉浸式想象

晚上九点，你抱着一根松木条从木工间出来，过道的感应灯一下就亮了。正对面那道北隔断整面洞洞板，锤子、水口钳、六角扳手排成一排，每件工具背后都描了一圈黑色轮廓，少了哪一把一眼就看见。楼梯口旁边是一排透明抽屉柜，标签机打的白底黑字：M4 螺丝、木螺钉 35、扎带 200。你顺手把手上的卷尺挂回它的影子里，“咔”一声磁吸到位。东边木工间那头，喷涂柜的橙色排风灯还亮着，空气里有一点点松木屑的甜味。这块 3.5 米见方的过道不是走廊，是整个仓库区的目录页。

✅ 设想方案清单

  1. 北侧隔断整面铺 5 张 60×90cm 洞洞板（3.5 米刚好排满），白色烤漆钢板，承重比木板稳，磁吸挂钩随便贴
  2. 每件工具挂好后用黑色油性笔沿轮廓描一圈“影子”，缺什么一眼看出，归位零思考
  3. 楼梯口旁 1.2m 高处装一排透明抽屉柜（48 格），标签机打印统一字体，按螺丝规格分格
  4. 顶部 40cm 留给长物件：铝合金导轨挂锯片、水平尺、延长线盘，标签朝下贴
  5. 2060 的平顶上装 2 段人体感应 LED 灯条，色温 4000K，上楼就亮，晚上找工具不摸黑
  6. 洞洞板边上装一块小白板 + 磁吸“去向卡”，工具拿去哪个区写一笔，找不着就看板子
  7. 每张洞洞板角落贴一个 NFC 标签，手机碰一下打开 HomeAssistant 里的工具清单

🔥 小红书灵感点

  • 小红书上爆火的“工具影子墙”（shadow board）：描轮廓那一刻仪式感拉满，归位变成强迫症的快乐
  • 去家务化动线思路：把最常用的 20 件工具放在离木工间门 2 步内，其他往过道深处排
  • 工业风黑白配：白色洞洞板 + 黑色挂钩 + 黑字标签，拍照发帖不用调色直接出片

⚠️ 避坑提醒

  • 别买 3mm 薄木洞洞板挂重型工具，撑不住电钻，一晚上就弯成波浪
  • 标签别手写，字迹一乱整面墙就土；一次买够标签带，中途换字体会强迫症发作
  • 通往木工间的开口留够 90cm，抱着长木料转身要能过，不然每次都撞掉一排扳手

kennetek/gridfinity-rebuilt-openscad ★ 2.2k 无中文

OpenSCAD 重写的 Gridfinity 参数化收纳格生成器，尺寸、分格、磁吸孔随便调

→ 抽屉柜里的螺丝分格、洞洞板下方的小零件托盘直接用它生成后 3D 打印，全站统一模数

Gridfinity 是 YouTube 创作者 Zack Freedman 在 2022 年提出的开放收纳标准：所有盒子都落在 42 毫米见方的底板网格上，高度按 7 毫米一级递增，底部可以嵌磁铁。kennetek 的 gridfinity-rebuilt-openscad 用 OpenSCAD 把这套标准从零重写成参数化代码，2.2k 星，是各种 Gridfinity 生成器里最规范、被引用最多的一个。

它的原理是把每个盒子拆成几个可组合的模块：底座（含磁铁孔、螺丝孔、防滑倒角）、外壁、内部分格、抬手用的唇边和标签位；用户只需要改几行参数——几格宽、几格深、几个单位高、内部横竖各分几格、要不要圆底方便倒小零件——就能生成 STL。同一个仓库还能生成底板：普通、带磁铁、带螺丝孔、可拼接的都有，尺寸按抽屉内空自动排满。OpenSCAD 的 customizer 面板里能图形化调参，不用读代码。

文档是英文网站，但 Gridfinity 在国内打印圈很流行，Makerworld 上成品件极多。

在 0401 里，它管楼梯口那排透明抽屉柜的内部：先量每个抽屉的内空，生成一块贴合的底板，再按螺丝规格生成分格盒，M4 一格、木螺钉 35 一格，盒沿的标签位正好贴标签机打出的条；洞洞板下方的小零件托盘也用同一模数。坑是打印机尺寸：拓竹 P1S 一次最多打 6×6 格底板，大抽屉要分块拼。

MultiMote/niimblue ★ 740 界面有中文

精臣（NIIMBOT）标签机的第三方网页客户端，浏览器里直接蓝牙打印，不用官方 App 和账号

→ 48 格抽屉柜和洞洞板的标签全用它打：一套模板一种字体，离线批量出，白底黑字永远一致

NiimBlue 是开发者 MultiMote 做的精臣（NIIMBOT）标签机第三方网页客户端，740 星。精臣是国内最常见的家用蓝牙标签机品牌，几十块到两百块一台，但官方 App 必须登录账号、模板依赖云端、字体和排版又受限，很多人只想安安静静打一排字体一致的抽屉标签。NiimBlue 逆向了精臣的蓝牙和 USB 协议，做成一个浏览器就能用的离线工具。

它的原理是：网页用 Web Bluetooth 或 Web Serial 直接和打印机通信，内置一个画布式标签编辑器，可以放文本、二维码、条码、图片和线框，选好标签纸尺寸后把画面转成打印机的点阵格式发过去，打印前有预览和几种抖动算法可选。模板能保存、导入导出；支持的机型很多，常见的 D 系列和 B 系列都有人测过，也有 Android 和 Windows 的独立安装版。项目更新频繁，翻译交给 Weblate 社区。

中文资料少，但机器本身是中文品牌，标签纸在国内随手可买。

在 0401 里它负责 48 格抽屉柜和洞洞板上的全部标签：在 0802 中枢的浏览器里开一个页面，统一用一款字体、一种字号做模板，把螺丝规格列表一格一格打完，每张洞洞板角落的 NFC 标签旁也贴一张同款名牌。坑是 Web Bluetooth 只在 Chrome 系浏览器上能用，Safari 不行；蓝牙配对前要先在官方 App 里把机器固件升到最新。

tkubic/GridfinityShadowMaker ★ 119 无中文

把工具拍照转成 DXF 轮廓，再生成可 3D 打印的工具影子板，兼容 Gridfinity

→ 工具“影子”不用手描，拍一张照片就能出轮廓，打印出来贴在洞洞板或抽屉里；照片转影子板这件事上它是 GitHub 上少有的一键流程

GridfinityShadowMaker 是 tkubic 做的一条工具影子板生成流水线，119 星，专门解决一件麻烦事：想给每把工具做一个严丝合缝的凹槽，手工在 CAD 里描轮廓一把要半小时，几十把工具没人描得下去。它是 GitHub 上少数把这件事做成一键流程的项目。

它的流程分三步。第一步照片转 DXF：把工具平放在一块灯板或白纸上，手机拍一张俯视照片，Python 脚本用 OpenCV 找轮廓、按参照物换算比例、平滑毛刺，输出 DXF 轮廓文件，脚本带一个 PyQt 小窗口可以调阈值和偏移量。第二步 DXF 转 STL：OpenSCAD 读入轮廓，在一块 Gridfinity 规格的底座上挖出带指槽的凹坑，几格宽几格深由参数决定，需要 OpenSCAD 的 Manifold 后端，否则布尔运算很慢。第三步进切片软件：用 OrcaSlicer 或 Bambu Studio 给凹坑换色、加上工具名字的浮雕，打印。仓库配有示例照片和参数说明，有 2.0 版分支在开发，没有中文资料。

在 0401 里，它是影子墙的升级版：洞洞板上的影子先用油性笔描，抽屉里和工作台上常用的一组工具则用它出打印影子板，凹坑底用黑色、盘面用白色，少了哪把一眼看见。坑是拍照：手机要正对工具、镜头别用广角，照片里放一枚硬币或一段尺子作比例参照，否则轮廓会整体偏大偏小。

paperless-ngx/paperless-ngx ★ 44.9k 界面有中文 延伸

社区维护的自托管文档管理系统：扫描件和 PDF 进来自动 OCR、打标签、归类，全文搜索秒出，纸质文件从此可以扔

→ 过道工具间几十件工具的说明书、保修卡和发票总要有个地方归档，paperless-ngx 让洞洞板上的 NFC 标签能直接跳到那把工具的全部纸面资料

paperless-ngx 是从 paperless 和 paperless-ng 接力过来的社区项目，用 Python 的 Django 写后端、Angular 写前端，44.9k 星，是自托管圈里文档管理的默认答案。它要解决的问题：说明书、发票、保修卡堆在抽屉里永远找不到，扫进硬盘也只是换个地方堆。

它的工作方式是消费加索引：把扫描件、PDF 或手机拍的照片扔进一个监视目录或通过邮件、网页上传，后台任务队列用 Tesseract 做 OCR 提取全文，再按预设的匹配规则或机器学习自动分配通讯人、文档类型、标签和存储路径，并把归档后的 PDF/A 存到指定目录。前端提供全文搜索、标签筛选、批量编辑和工作流；REST API 完整，手机有第三方 App，HomeAssistant 也有社区集成。

生态上它有 Docker Compose 一键部署，翻译通过 Crowdin 维护，界面有简体中文，中文自托管教程很多；项目由多位维护者活跃更新，几乎每月发版。

对 0401 来说它是延伸项目：洞洞板上每件工具的影子旁边都贴了 NFC 标签，碰一下打开 HomeAssistant 里的工具清单，那份清单里加一个链接，直接跳到 paperless-ngx 里这把工具的说明书和发票。买回一件新工具，先把说明书和小票用手机拍一张扔进监视目录，打上工具名和 0401 的标签，再挂上洞洞板。跑在 0802 服务器上，中文说明书记得把 OCR 语言加上 chi_sim。

zxing/zxing ★ 34.1k 无中文 延伸

斑马线：Java 写的一维码和二维码识别与生成库，几乎所有 Android 扫码功能的祖先，支持 QR、Code 128、EAN 等十几种码制

→ 抽屉柜 48 格和洞洞板的每一格都要一个能扫的码，zxing 是条码世界的教科书，读懂它就知道该选哪种码、怎么打印才扫得准

ZXing 念作斑马线，是 2007 年从 Google 内部开源出来的条码识别与生成库，用 Java 写成，34.1k 星，Android 早期的扫码 App 就是它的作品。它要解决的问题是：用普通摄像头，不要专用扫码枪，就能可靠地读出一维码和二维码。

它的工作方式是图像进、文本出：把摄像头帧或图片转成亮度矩阵，二值化后交给各码制的解码器逐个尝试——QR 码找三个定位图案再纠错解码，Code 128、EAN、UPC 等一维码沿扫描线找黑白条宽比。反过来它也能把任意文本编码成条码的位图。项目已进入维护模式，只接受补丁，但正因为稳定，它成了参考实现：zxing-cpp、zxing-js 都是它的移植，浏览器、Python、树莓派上都能用。

生态上它的码制文档非常完整，中文资料以博客和教程为主，没有官方中文；核心库很久没大改，移植版仍在活跃更新。

对 0401 来说它是延伸项目：楼梯口旁那排 48 格透明抽屉柜和顶部的长物件导轨，标签机打的字之外再加一个小二维码，内容是 0801 数字孪生库里这一格的 ID。生成用 zxing 的编码器批量出图，喂给 niimblue 标签机打印；扫描用手机上任何基于 zxing 的 App，或者在 0802 服务器上用 zxing-cpp 的 Python 绑定给过道的摄像头做识别。码制选 QR 而不是一维码，一格 15 毫米宽的标签也能扫；打印时注意留白边，zxing 对静区很敏感。
