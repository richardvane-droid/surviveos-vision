阁楼间 · 模块 0305 · 3D 打印

谁懂啊！不买成品机了，自己拧一台 Voron 2.4 放阁楼

阁楼上用铝型材搭一台开源打印机 Voron 2.4，再围着它搭一张站着就能操作的工作站。

⬜ 真实项目待设计 #动手主义#Voron#3D打印#铝型材#开源硬件

📐 它在哪、有多大

自建的 Voron 2.4 立在 03 阁楼间可站立区的东南角、天窗东侧 ≈0.5m，围着它是一张占地 0.5×0.5m 的铝型材工作站，腔口中心抬到 1100～1200 站着平视；下层是耗材干燥箱、工具抽屉和一块能整块抽出的接屑盘，排风管 ≈1.5m 直通天窗边的排气口；西北 2m 是 0301 工具台。（0008 未定位，设想落位）

🎬 沉浸式想象

晚上十点，阁楼斜顶下只留一盏灯。你站在那张半米见方的铝型材工作站前，不用弯腰——腔口正好在胸口再往上一点，眼睛平着就能看进去。里面是自己一颗一颗拧起来的 Voron 2.4：黑色型材骨架，四根丝杠托着热床同步升降，CoreXY 的皮带在顶上拉出一个对称的口字。喷头正在打一批帐篷区要用的挂钩，ABS，腔温五十度，玻璃门上蒙了一层暖雾。下层的耗材干燥箱的小屏亮着 12% RH。你把侧板往外一翻，抽出接屑盘，昨晚的碎屑哗一声倒进桶里，再推回去。手机上 Mainsail 还开着：第 214 层，剩 1 小时 47 分。三个月前这堆型材还躺在纸箱里，现在它比任何一台开箱即用的机器都更像自己的东西。

✅ 设想方案清单

  1. 机器选 Voron 2.4 的 250 方案：CoreXY、全封闭腔体、四丝杠自动调平热床，照官方 BOM 和手册自己配件自己拧
  2. 工作站用 0805 定标的欧标喷砂黑型材搭：3030 做立柱横梁、2020 做层板和配件，占地约 0.5×0.5m
  3. 腔口中心抬到 1100～1200，站着平视就能看进打印仓；台面和滑轨接触面铺一层木板，型材划伤露白交给木料挡
  4. 侧板做成可拆可翻的：铰链加磁扣，清碎屑时整块翻开——参考方案固定死侧板这个坑必须改掉
  5. 下层分三格：耗材干燥箱、工具抽屉、一块能整块抽出的接屑盘，碎屑直接端走倒掉
  6. 固件走 Klipper，klippy 跑在 0804 那台常驻的 M1 Mac 上，Mainsail 网页里开打、看摄像头、调参数
  7. 腔体顶部接 100mm 排风管，横过天花 1.5 米到天窗边排气口，排风没做好之前一律不打 ABS
  8. 第一批 ABS 工装打印件找打印服务或朋友的机器代打，机器立起来之后再自己复刻一套备件

🔥 小红书灵感点

  • 小红书「3D打印机工作台 占地仅0.5m²」那篇直接抄作业，但它固定侧板和台面太矮两个坑我都改掉了

⚠️ 避坑提醒

  • 先有鸡还是先有蛋：Voron 的工装件要 ABS 打印，自己还没机器，第一批只能找代打或蹭朋友的机器

OrcaSlicer/OrcaSlicer ★ 15.7k 界面有中文

开源切片软件，自带一整套校准流程，预设库里就有 Voron，支持直发 Klipper、PrusaLink 和 OctoPrint

→ 地堡 0204 工作台装它切片，拿 Voron 2.4 预设当起点，切完经 Moonraker 直发阁楼那台自建机

OrcaSlicer 是由 SoftFever 发起、社区维护的开源切片软件，从拓竹 Bambu Studio 分叉而来，如今独立成组织，15.7k 星，是切片软件里最活跃的开源项目之一。它解决的问题是：各家官方软件都被绑在自家生态里，而社区想要更细的参数控制和更广的机型支持。

切片软件的工作原理是把 STL 或 3MF 模型按层高切成一层层轮廓，再规划每层的墙线、填充、支撑路径，最后输出打印机能执行的 G 代码。OrcaSlicer 在这条流水线上加了很多实用件：内置温度塔、流量、压力提前、最大体积速度的校准流程，精确墙距和接缝控制，悬垂减速与树状支撑，以及 Voron、Prusa、VzBot、RatRig、创想三维等机型的预设库。

它支持局域网直连打印机，Klipper 走 Moonraker、Prusa 走 PrusaLink，OctoPrint 也能直发；界面自带简体中文，B 站和国内 DIY 社区有大量中文教程，几乎每月一版。

放进 0305 的流程里，它装在地堡 0204 的设计工作台上：选 Voron 2.4 的机型预设当起点，按自己那台机的实际行程、喷嘴口径和腔温改一份，切好挂钩、标牌、PSK 内衬后经 Moonraker 直发阁楼，同时在设备页看摄像头。要注意自建机没有出厂预设，第一件事是用它的校准流程把流量、压力提前和最大体积速度逐项跑一遍并存成耗材预设，再和 Spoolman 里的卷号对上，否则木色和白色 PLA 混着用会拉丝。

Klipper3d/klipper ★ 11.6k 有中文文档站

把运动规划搬到一台 Linux 电脑上的 3D 打印机固件：单片机只管步进脉冲，支持输入整形和压力提前

→ 自建那台 Voron 2.4 的固件就是它，klippy 跑在 0804 那台常驻 M1 Mac 上，全部参数集中在一个文本文件里

Klipper 是 Kevin O’Connor 发起的开源 3D 打印机固件，11.6k 星，Voron 全系、创想 K1 这类高速机型用的都是它或它的改版。它要解决的问题是：传统固件把 G 代码解析和运动规划都塞进一颗小单片机，算力不够就跑不快，也加不了复杂算法。

它的做法是把大脑和手脚分开：一台 Linux 电脑跑 klippy 主程序，负责解析 G 代码、做运动规划和各种补偿，再把带时间戳的步进指令发给主板；主板上的单片机只烧一个很小的固件，按时间戳把脉冲打出去。因为规划放在大电脑上做，输入整形（抵消振纹）、压力提前（改善拐角）、共振测量、四丝杠自动调平都是 Python 模块，配置集中在一个 printer.cfg 文本文件里，改完重启就生效，不用重新编译固件。

它本身不带界面，配 Mainsail 或 Fluidd 网页前端，中间隔一层 Moonraker API，HomeAssistant 也从这里接。官方文档站有完整的简体中文翻译，国内 Voron 社群和 B 站教程非常多，项目一直很活跃。

在 0305 里它是自建那台 Voron 2.4 的固件：主板刷 MCU 固件，klippy 和 Moonraker 跑在 0804 那台常驻的 M1 Mac 上，工作站旁边挂一块小屏当面板。装完先跑一遍共振测量生成输入整形参数，再调压力提前，这两步是自建机能不能又快又干净的分水岭。坑是配置文件每一项都要自己填，第一次点火前把限位方向、热敏类型和热保护逐条核对一遍。

VoronDesign/Voron-2 ★ 4.4k 无中文（国内社群有中文搭建长贴）

开源 CoreXY 打印机 Voron 2.4 的完整设计仓库：CAD 源文件、DXF 图纸、STL 打印件、装配手册和 BOM

→ 0305 那台机器就是照它搭的：按官方 BOM 配件、按手册一步步拧，机架尺寸和结构件全部来自这里

Voron 是 2015 年起做开源打印机设计的社区组织，Voron-2 仓库 4.4k 星，放的是旗下 Voron 2.4 这台机器的全套设计：CAD 源文件、DXF 图纸、STL 结构件、装配手册、固件配置和切片预设，许可 GPL-3.0。它要解决的不是卖机器，而是把一台高速、全封闭、可维护的打印机彻底摊开，让你自己买件自己拧。

它的结构是 CoreXY：两条交叉皮带驱动打印头在 X、Y 平面上跑，电机固定在机身上不跟着动，惯量小所以能快；热床由四根丝杠同步升降，开机自动扫描床面并补偿倾斜；机身是铝型材骨架加板材封闭，腔温保得住，才敢打 ABS、ASA 这类会翘边的材料。仓库不卖整机，给的是一份可配置的 BOM，按 250、300、350 三种尺寸选件，其中一两百个结构件要自己打印。

生态上 Voron 是 Klipper 固件最大的用户群，官方在线手册和 Discord 都很完整；设计本身已经定型，主仓库更新不频繁，但社区的改件仓库层出不穷。没有官方中文，不过矿石论坛、太极派和 B 站有大量中文搭建长贴和长视频，这也是选它而不是选成品机的原因之一。

在 0305 里它就是主角的图纸来源：按 BOM 配型材和线性件，按手册的顺序装机架、龙门、打印头，再把它的切片预设导进 OrcaSlicer 当起点。要注意结构件必须用 ABS 打印，自己还没有机器时得先找代打或蹭朋友的机器，这是自建路线的第一道坎；另外它的机架尺寸要和工作站的型材截面一起算，别等机器装好才发现台面留窄了。

Donkie/Spoolman ★ 2.8k 界面有中文

自托管的 3D 打印耗材库存管理，记录每卷剩余克数、颜色、材质，带打印机集成

→ 八格耗材架每卷登记进去，Moonraker 打完自动扣减，标签上的剩余克数不用手写，快用完自动提醒

Spoolman 是瑞典开发者 Donkie 写的自托管 3D 打印耗材库存管理服务，2.8k 星，是 Klipper 圈里管理线材的事实标准。它解决的痛点很具体：家里十几卷线材，每卷还剩多少克、什么材质颜色，靠贴纸和记忆迟早乱掉。

它的架构是一个 Python 后端加内置网页前端，用 Docker 一条命令跑起来，数据库可以用 SQLite 或 PostgreSQL。数据模型分三层：厂商、线材（材质、颜色、直径、密度、推荐温度）、线卷（初始重量、已用克数、所在位置、批号）。打印机每打完一个任务，通过 REST API 或 WebSocket 把消耗的克数回写，剩余量自动扣减；也支持手动称重校正。它还内置二维码标签设计器，扫码就能定位到那一卷；社区维护了一份公共线材数据库，常见品牌直接选。

生态上 Moonraker、Fluidd、Mainsail 原生支持，Home Assistant 有集成，界面通过 Weblate 翻译，简体中文已完成九成以上。

在 0305 里它跑在 0804 那台常驻的 M1 Mac 上，八格耗材架每卷登记一条，架子上的标签就打它生成的二维码；自建的 Voron 2.4 跑 Klipper，Moonraker 自带 spoolman 组件，在 Mainsail 里选好线卷，每打完一单就按切片预估自动扣减，不用再绕一层自动化写回。坑是换料时忘了在界面里切线卷，用量会全记到上一卷头上，最好把切换动作写进换料宏；另外预估和实际总有偏差，每月称重校正一次。

OctoPrint/OctoPrint ★ 9k 界面有中文 延伸

3D 打印机的网页远程控制台：上传文件、看进度、看摄像头、装插件，Python 写的老牌树莓派方案

→ 自建机已经有 Klipper 加 Mainsail，用不上它；但它是打印机远程监控这件事的开山标杆，读懂它的插件体系就知道一块监看面板该有什么

OctoPrint 是德国开发者 Gina Häußge 从 2012 年起维护的开源打印机远程控制软件，用 Python 写成，9k 星，2026 年 6 月还发了 1.11.8 版。它要解决的问题：打印机拴着一台电脑太浪费，树莓派上的一个网页就能远程上传、启动、监看和急停。

它的工作方式是串口加网页：树莓派通过 USB 连打印机，OctoPrint 把 G 代码逐行发过去，同时解析温度回报，在网页上画温度曲线、显示进度和剩余时间，接一个摄像头就能看实时画面并自动生成延时视频。它最大的特点是插件系统：官方仓库有几百个插件，从床面调平可视化到远程访问和 AI 失败检测都有；HomeAssistant 有官方 OctoPrint 集成，进度、温度和急停按钮直接进仪表盘。

生态上 OctoPi 镜像烧进树莓派就能用，教程极多，界面有社区中文语言包；项目靠赞助维持，持续更新。

对 0305 来说它是延伸项目：自建的 Voron 2.4 跑 Klipper，日常界面是 Mainsail，不需要它；它的价值在两处。一是学习：看一个成熟的打印机监控该有什么——温度曲线、摄像头延时、失败检测、推送，这是工作站那块小屏和 HA 通知的参考答案。二是备用：如果 0301 那边收来一台老式串口打印机，或者代打阶段借来的机器不跑 Klipper，把 OctoPrint 装进 0804 的一个容器，USB 拉一根线过去，HA 集成一加，就和自建机并排出现在同一个仪表盘上。

prusa3d/PrusaSlicer ★ 9.1k 界面有中文 延伸

Prusa 维护的开源切片器：OrcaSlicer 和拓竹 Studio 的共同祖先，树状支撑、可变层高、多材料涂色

→ 0305 已经选了 OrcaSlicer，但它和拓竹 Studio 都是从 PrusaSlicer 分叉的；读懂上游才明白切片参数的来龙去脉，也多一条备用切片路线

PrusaSlicer 是捷克 Prusa Research 公司维护的开源切片软件，从 Slic3r 分叉而来，用 C++ 写成，9.1k 星，2026 年 5 月发布 2.9.5 版。它要解决的问题是把 3D 模型变成打印机能执行的 G 代码，并在这一步决定强度、速度、表面质量和耗材用量。

它的工作方式是模型进、G 代码出：导入 STL、3MF 或 STEP 后，先做摆放、缩放、切割和修复，再按层高把模型切成一层层轮廓，为每层生成外墙、内墙、填充、支撑和顶底面路径，最后按打印机配置输出 G 代码并逐层预览走线和时间。它带来的很多功能后来成了行业标配：有机树状支撑、可变层高、熨烫、涂色分区多材料、按区域改参数的修改器，以及联网直接把任务发给打印机。

生态上它是 OrcaSlicer、拓竹 Studio、SuperSlicer 的共同上游，几乎所有厂商都提供 PrusaSlicer 配置文件，界面自带简体中文，中文教程很多；Prusa 公司持续投入，版本更新稳定。

对 0305 来说它是延伸项目：日常切片继续用 OrcaSlicer 给自建的 Voron 推任务，但某个参数看不懂时，去 PrusaSlicer 的官方知识库查同名参数，那里解释最完整，因为参数就是从这里来的。实际用途有二：地堡 0204 设计台装一份当第二意见，同一个 PSK 内衬模型用两个切片器各切一遍，比支撑用量和时长，选省耗材的那版；再给全屋小配件建一个 3MF 项目库，连参数一起存，下次再打挂钩不用重调。

mainsail-crew/mainsail ★ 2.2k 界面有简体中文 延伸

Klipper 的网页控制台：温度曲线、点动、G 代码 3D 预览、床网热力图、摄像头和宏，全在浏览器里

→ Klipper 本身不带界面，自建那台 Voron 的日常操作全靠它；工作站小屏和帐篷里的手机刷的是同一个页面

Mainsail 是 mainsail-crew 维护的 Klipper 网页前端，用 Vue 写成，2.2k 星，和 Fluidd 一起是 Klipper 世界里两个主流界面。它解决的问题很直接：Klipper 只给固件和 API，没有任何界面，机器装好之后你需要一个能上传文件、点动、看温度、改配置的地方。

它的工作方式是纯前端加一层 API：klippy 主程序通过一个本地套接字暴露能力，Moonraker 把它包成 HTTP 和 WebSocket 接口，Mainsail 只是跑在浏览器里的单页应用，连上 Moonraker 就成了机器的仪表盘。界面上有温度曲线与预设、各轴点动、G 代码文件管理、逐层 3D 刀路预览、床网热力图、打印历史统计、宏按钮、多摄像头与延时视频、带语法高亮的配置编辑器，还能管打印队列。

安装用 KIAUH 脚本或 MainsailOS 镜像一条龙，文档站完整，社区在 Discord；界面通过 Weblate 翻译成十几种语言，简体中文可用，国内 Voron 社群基本人手一份，更新很勤。

在 0305 里它是这台自建机的日常操作面板：klippy 和 Moonraker 跑在 0804 那台常驻 M1 Mac 上，工作站旁边挂一块小屏常开着它，人在帐篷里也能用手机刷同一个页面看第几层。作为延伸，它的宏按钮最值得利用——把换料、清喷头、抽接屑盘前的归位动作各做成一颗按钮，省得每次翻文档；另外它只是前端，安全兜底还是在固件和硬件上，别指望网页急停。
