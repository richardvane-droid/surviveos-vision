🎬 沉浸式想象

晚上十一点，你从地堡的设计工作台把文件切好，走上阁楼。拓竹 P1S 放在天窗边一张矮柜上，四面透明，里面的喷头正在一层一层堆一个帐篷区用的挂钩。柜子旁边一排耗材架上，八卷 PLA 按颜色排着：木色、黑色、白色、绿色。打印机上方装了一根排风管，一米多就通到天窗边的排气口，几乎闻不到味道。旁边的小屏幕显示“剩余 2 小时 14 分”。你把台灯调暗，回帐篷区躺着，隔着帐篷布听打印机“滋滋滋”地跑，像细雨。手机上 HomeAssistant 弹出摄像头画面，第 47 层，一切正常。

✅ 设想方案清单

  1. 天窗东侧靠隔断放一张 60×60cm 矮柜，拓竹 P1S 放柜面，柜内放工具和备用喷头
  2. 打印机顶部接一根 100mm 排风管，横过天花 1.5 米到天窗边的排气口，装小风扇
  3. 柜旁做一个 8 格耗材架，每卷 PLA 贴颜色标签 + 剩余克数，放一包干燥剂
  4. 打印机接 HomeAssistant，开始/结束/失败推送到手机，摄像头看层高
  5. 地堡 0204 设计工作台切片，局域网直接推到阁楼打印机，不用来回跑
  6. 打印任务优先级：全屋小配件（挂钩、标牌、PSK 内衬）> 玩具 > 试验件
  7. 打印机下面垫一块 2cm 减震垫，阁楼木地板不共振

OrcaSlicer/OrcaSlicer ★ 15.7k 界面有中文

基于拓竹 Bambu Studio 二次开发的开源切片软件，自带校准流程，支持局域网直发

→ 地堡 0204 工作台装它切片，局域网直接推到阁楼的 P1S，不用来回跑，挂钩标牌批量打

OrcaSlicer 是由 SoftFever 发起、社区维护的开源切片软件，从拓竹 Bambu Studio 分叉而来，如今独立成组织，15.7k 星是切片软件里最活跃的开源项目之一。它解决的问题是：拓竹官方软件功能被绑定在自家生态里，而社区想要更细的参数控制和更多机型支持。

切片软件的工作原理是把 STL 或 3MF 模型按层高切成一层层轮廓，再规划每层的墙线、填充、支撑路径，最后输出打印机能执行的 G 代码。OrcaSlicer 在这条流水线上加了很多实用件：内置温度塔、流量、压力提前、最大体积速度的校准流程，精确墙距和接缝控制，悬垂减速与树状支撑，以及拓竹、Prusa、Voron、创想三维等品牌的机型预设库。

它支持局域网直连打印机，拓竹机型走本机 LAN 模式或云模式，Klipper、PrusaLink、OctoPrint 也能直发；界面自带简体中文，B 站和拓竹社区有大量中文教程，几乎每月一版。

放进 0305 的流程里，它装在地堡 0204 的设计工作台上：把 P1S 设成 LAN 模式并填入访问码，切好挂钩、标牌、PSK 内衬后直接发送到阁楼打印机，同时在设备页看摄像头。要注意先用它的校准流程把每卷耗材的流量和温度跑一遍并存成耗材预设，和 Spoolman 里的卷号对上，否则木色 PLA 和白色 PLA 的参数混着用会拉丝。

Donkie/Spoolman ★ 2.8k 界面有中文

自托管的 3D 打印耗材库存管理，记录每卷剩余克数、颜色、材质，带打印机集成

→ 8 格耗材架每卷登记进去，标签上的剩余克数不用手写，快用完自动提醒，防止囤太多

Spoolman 是瑞典开发者 Donkie 写的自托管 3D 打印耗材库存管理服务，2.8k 星，是 Klipper 圈里管理线材的事实标准。它解决的痛点很具体：家里十几卷线材，每卷还剩多少克、什么材质颜色，靠贴纸和记忆迟早乱掉。

它的架构是一个 Python 后端加内置网页前端，用 Docker 一条命令跑起来，数据库可以用 SQLite 或 PostgreSQL。数据模型分三层：厂商、线材（材质、颜色、直径、密度、推荐温度）、线卷（初始重量、已用克数、所在位置、批号）。打印机每打完一个任务，通过 REST API 或 WebSocket 把消耗的克数回写，剩余量自动扣减；也支持手动称重校正。它还内置二维码标签设计器，扫码就能定位到那一卷；社区维护了一份公共线材数据库，常见品牌直接选。

生态上 Moonraker、Fluidd、Mainsail 原生支持，Home Assistant 有集成，界面通过 Weblate 翻译，简体中文已完成九成以上。

在 0305 里它跑在 0802 中枢的树莓派上，八格耗材架每卷登记一条，架子上的标签就打它生成的二维码；拓竹 P1S 不是 Klipper，扣减要绕一下：用 ha-bambulab 读到的每次打印耗材用量，在 HA 自动化里调 Spoolman 的 API 写回。坑是 AMS 里线卷切换时用量归属会串，最好每卷固定槽位。

greghesp/ha-bambulab ★ 2.3k 组件自带简体中文翻译

拓竹打印机的 Home Assistant 集成，读进度、层数、温度、AMS 耗材，还能看摄像头

→ P1S 接上它，开始、结束、失败自动推手机，躺帐篷里在 HA 上看第 47 层的摄像头画面

ha-bambulab 是 greghesp 发起、社区维护的拓竹打印机 Home Assistant 集成，2.3k 星，通过 HACS 安装，是把 X1、P1、A1 系列接进 HA 的事实方案。拓竹官方只给了自家 App 和 Bambu Studio，想让打印机和家里其他设备联动，就得靠它。

它的工作原理是走拓竹打印机的 MQTT 通道：局域网模式下直接连打印机的本机 MQTT 端口，云模式下连拓竹云。打印机会不断推送一份包含当前层数、进度、剩余时间、喷头与热床温度、AMS 各槽耗材信息、风扇转速、错误码的状态报文，集成把它们解析成几十个 HA 实体；反向可以下发暂停、继续、停止、调温、开关灯的命令。摄像头也接进来了，P1 系列走它自带的低帧率流，X1 走 RTSP。

社区非常活跃，Discord 有专门频道，几乎每月更新，翻译文件里自带简体中文，B 站上也有不少中文安装教程。

在 0305 里它是打印机和这套系统之间的桥：开始、结束、失败推送到手机，摄像头画面贴到 0802 中枢大屏上，AMS 槽位的耗材用量回写给 Spoolman 扣减，柜顶排风扇跟着打印状态自动启停，打完再延时十分钟。要注意 P1S 用局域网模式需要在打印机上开启并填入访问码，固件大版本更新后偶尔会断连，更新集成即可。
