虚拟空间 · 模块 0805 · 全套方案材质总设计

一份所有模块都要继承的材质总纲：铝做骨、木做面、皮草做触感，铝型材已定标欧标 20 系列喷砂黑。

🎬 沉浸式想象

你把三块样板并排放在木屋吧台上：一段喷砂黑的欧标 2020 型材、一块刨过的白蜡木、一块植鞣皮。手指从型材的槽里划过去，冷、硬、直；换到木头上，温、有纹路、有刨痕；最后落在皮上，软，带一点油光。这就是整座园子往后所有手工件的“语法”：型材承力藏在里面，木头露在外面给眼睛和手，皮草只出现在手会长时间停留的地方——椅面、把手、床沿。你翻开 0805 那页，D3 那一行写着“欧标 · 2020 · 槽宽 6mm · 喷砂黑 · 壁厚 1.8”，下面是两行空着的：木料，皮草。你知道下一次进木工间前得把这两行填上。

✅ 设想方案清单

  1. 主材只准三类：木料 / 铝型材 / 皮草；金属件尽量藏在木料后面，皮草只用在手长时间接触的表面
  2. 铝型材（D3 已定标）：欧标体系、主力 2020（槽宽 6mm，M5 T 型螺母）、重载 3030/4040（槽宽 8mm，配件不通用）、表面统一喷砂黑阳极氧化、壁厚默认 1.8mm
  3. 木料（待定标）：候选白蜡 / 白橡做面、松木做隐蔽结构、胡桃木做小件；油蜡饰面不做漆膜
  4. 皮草（待定标）：候选植鞣牛皮 + 少量羊毛毡，颜色只留原色和深棕两档
  5. 三条施工约束继承到所有模块：20 与 30/40 两档配件分箱存放；黑色氧化层不导电，强电模块单独接地；黑色划伤露白，磨损面一律木料覆盖
  6. 每个模块的“设想方案清单”里凡出现材料，都要能对上这一页；对不上的（0103 / 0209 / 0401 / 0301 / 0403 / 0404 / 0501）在定标后回溯改一轮
  7. 在木屋 0102 作品墙下留一格“材质样板格”：三块样板常年摆着，采购前先摸一下

🔥 小红书灵感点

  • 「动手主义」：型材配件全走 MakerWorld 的欧标 STL，自己打印角码盖和端盖

⚠️ 避坑提醒

  • 欧标和国标配件完全不通用，别贪便宜混采，槽宽差 2mm 螺母就卡不住
  • 同是“欧标 2020”壁厚有 1.4～2.0 好几档，详情页不写壁厚的一律当 1.4 处理
  • 黑色角码在部分店铺缺货，采购前先搜一轮，实在没有就用银角码走内置角槽件藏起来

FreeCAD/FreeCAD ★ 32.2k 有中文文档站

开源参数化 3D 建模软件，草图约束、零件设计、电子表格驱动尺寸、出加工图，型材框架和木作都能画

→ 每个模块画型材机架前先在它里面按 0805 的规格建模，2020 / 3030 两档尺寸做成参数化零件库

FreeCAD 是最成熟的开源参数化 3D 建模软件，2002 年发起，几何内核是 OpenCASCADE，32.2k 星，2026 年 4 月发布 1.1.1。它解决的问题是：不花钱、不上云，也能像商业 CAD 那样画出可修改、可出图、可打印的机械件和木作。

它的核心是参数化建模：在 Sketcher 里画带几何约束的二维草图，在 Part Design 里拉伸、旋转、打孔成实体，每一步都记在模型树里，回头改一个尺寸整件跟着变；Spreadsheet 工作台能把型材长度、槽宽这类数字做成表格变量驱动整个装配；TechDraw 出带尺寸的加工图，再加上几百个社区工作台。界面有完整简体中文，官方 wiki 有大量中文页面，是三个方案里中文资料最好的一个。

在 0805 里它是材质总纲的数字样板间：把欧标 2020（槽宽 6mm、壁厚 1.8）和 3030 / 4040（槽宽 8mm）做成两个参数化零件，角码、T 型螺母、端盖各一个，再做一套白蜡木板、植鞣皮面的外观库；以后 0301 工具台、0401 过道工具间、0404 木工间画机架时直接从这个库里拖，选错槽宽的配件就装不上，等于把材质规则写进了模型。零件库放 NAS 上统一版本，别各存各的。

openscad/openscad ★ 9.6k 界面有中文

程序员的 3D CAD：用脚本描述几何体，参数一改整件重生，Thingiverse 和 MakerWorld 上可自定义的型材配件多半用它写

→ 黑色角码缺货时自己打印的角码、端盖、槽盖条都用它写成参数化脚本，槽宽 6 / 8mm 一个变量切换

OpenSCAD 是程序员的 3D CAD：不用鼠标画，而是用一种小脚本语言描述几何体，9.6k 星，稳定版还是 2021.01，但开发版快照一直在更新。它解决的问题是：需要成批量、按参数变化的零件，同一个角码要出 2020 和 3030 两个版本，改一个数字就行。

它的模型是构造实体几何：立方体、圆柱、球这些基本体经过并、差、交和平移旋转拼成复杂件，二维轮廓可以拉伸成体，STL 和 3MF 直接导出去打印。所有尺寸都是变量，顶部定义 slot = 6 之类的参数，Customizer 面板里拖滑块就能改；正因如此，Thingiverse 和 MakerWorld 上绝大多数可自定义的型材配件都是它写的，围绕它长出了 NopSCADlib 等大型零件库。界面有中文语言包，README 英文。

在 0805 里它是配件打印的生产线：黑色角码缺货时，用它写一个参数化角码，槽宽、螺孔间距、壁厚都是变量，欧标 2020 出一版、3030 出一版，再加端盖、槽盖条、脚垫这几个常用件，导出 3MF 发给阁楼的拓竹打印。注意 OpenSCAD 只管形状不管装配关系，装配还是回 FreeCAD 看，两边靠同一份参数文件保持一致；打印件用黑色 PETG，别用 PLA。

nophead/NopSCADlib ★ 1.6k 无中文

OpenSCAD 零件库和项目框架：自带 E2020 / E3030 / E4040 铝型材、角码、滑入式 T 型螺母等标准件，能生成 BOM 和装配图

→ 0804 三机机架和各模块型材框架直接用它的型材与角码模型拼，跑脚本就出切割清单和螺丝数量

NopSCADlib 是 Chris Palmer（nophead）维护的 OpenSCAD 零件库和项目框架，1.6k 星，GPL v3，持续更新十几年。它解决的问题是：做一台机器要用的标准件，每次都自己画一遍太浪费，不如有一个尺寸准确的库，顺手把 BOM 和装配图也生成了。

它的内容分两大块。vitamins（外购件）里直接有 E2020、E3030、E4040 等一整套铝型材模型，带真实槽形截面，配套 extrusion_corner_bracket、extrusion_inner_corner_bracket 角码和 sliding_t_nut 滑入式 T 型螺母；printed（打印件）里有盒子、铰链、线夹、脚垫等结构件。框架部分是一套 Python 脚本：在 OpenSCAD 注释里写 Markdown，脚本就能扫出 BOM 清单和分步装配图。README 和文档只有英文，看示例就会。

在 0805 里它是型材机架的标准件字典：0804 那个 60×40cm 三机机架，直接用 E2020 拼框架、角码做角、T 型螺母挂托板，跑一次脚本就得到型材切割清单和螺丝数量。要注意它的 2020 截面是 6mm 槽，正好对上 D3 定标；但它默认角码是银色通用件，喷砂黑那几件要在 printed 里自己加颜色参数；3030 是 8mm 槽，配件要分别传参。

blender/blender ★ 19.3k 有中文文档站 延伸

开源 3D 创作套件的官方镜像：建模、PBR 材质节点、Cycles 与 EEVEE 渲染、Python API，把 CAD 模型套上真实材质出效果图

→ 型材藏在里面、木头露在外面、皮草只在手停留处，这套材质语法要在采购前看到效果，得有一个能渲染真实材质的工具

Blender 是荷兰 Blender 基金会维护的开源 3D 创作套件，GitHub 上这个仓库是官方镜像，19.3k 星，主开发在他们自己的 Gitea 上。从建模、材质、灯光到渲染、动画，一套免费软件全包，专业到被电影和游戏工作室正式使用。

它和 CAD 关心的不同：CAD 关心尺寸和约束，Blender 关心看起来像不像。材质用节点编辑器搭，原理化 BSDF 一个节点就覆盖了 PBR 的全部参数，金属度、粗糙度、法线贴图、透光；灯光用 HDRI 环境图给出真实反射；渲染有两个引擎，Cycles 是路径追踪，慢但准，EEVEE 是实时光栅，快而够看。FreeCAD 导出的 OBJ 或 glTF 直接拖进去；

4.x 系列 2026 年仍按季度发版；界面自带简体中文，官方手册也有中文翻译，B 站教程数不清。

在 0805 里它是延伸：这一页定的是材质语法，木屋作品墙下那格样板是实物，Blender 里做它的数字版。先把三种材质各调成一个节点组：喷砂黑阳极氧化铝要低金属度、中高粗糙度加细微颗粒法线；白蜡木油蜡饰面用木纹贴图加轻微清漆层；植鞣皮用高粗糙度加皮纹凹凸。然后把 FreeCAD 里各模块的机架模型导出 glTF 拖进来，按规则给每个面指派材质，型材面黑、覆面木、把手皮，用 EEVEE 几秒出一张。0301 工具台、0404 木工间下料前先渲一张看比例和配色，木料和皮草定标时把两三种候选并排渲出来比。

CadQuery/cadquery ★ 5.7k 无中文 延伸

Python 参数化 CAD 脚本框架：基于 OCCT 内核的实体建模，链式 API 几行出一个带倒角的零件，能直接导出 STEP 与 STL

→ D3 规格是一行文字，写成一个 Python 库后每个模块的机架脚本 import 一次就继承，比 OpenSCAD 多出真正的 STEP 和圆角

CadQuery 是一个用 Python 写参数化 CAD 的开源框架，5.7k 星，最初由 Dave Cowden 在 2013 年发起，现在由社区维护。它和 OpenSCAD 一样用代码建模，但内核不同：OpenSCAD 是网格上的布尔运算，CadQuery 基于 OpenCASCADE 的边界表示，所以能做真正的圆角倒角、能识别面和边、能导出工程软件认的 STEP。

它的 API 是链式的：从一个工作平面开始，画草图、拉伸、选边、倒角、打孔，每一步返回新对象继续往下写，几行就是一个零件。选择器用字符串描述，改参数后整条链自动重算。装配模块能把多个零件按约束拼起来，导出格式有 STEP、STL、3MF、DXF 和 SVG。配套的 CQ-editor 是带三维预览的桌面编辑器，build123d 是社区在它之上做的新一代 API。

社区规模中等但稳定，2026 年仍在发版；文档是英文，中文资料只有零星博客。

在 0805 里它是延伸，用来把规则写成代码。建一个小 Python 包，profile 函数的参数是系列名和长度，2020 就是槽宽 6 毫米壁厚 1.8 毫米，3030 就是槽宽 8 毫米，配件函数有角码、T 型螺母、端盖、脚垫，木料函数按候选树种给出板厚和倒角。各模块的机架脚本 import 这个包，尺寸用变量，一改规格全部跟着变；输出 STEP 给 FreeCAD 做装配图，STL 给拓竹打印配件，顺手让脚本数一遍切割清单和螺母数量。定标改了槽宽，只改包里一行。
