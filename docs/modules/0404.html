阁楼仓库 · 模块 0404 · 木工间

沉浸式木工间！一台集尘器让我再也不用戴着口罩锯木头

台锯、工作台、法式挂条墙围成一个 U 形，木屑全部被一根管子吃掉。

⬜ 真实项目待设计 #动手主义#除尘系统#木工#法式挂条#精神领地

🎬 沉浸式想象

下午三点，阁楼斜窗的光正好落在工作台上，台面上一层薄薄的橡木粉像面粉。你推下台锯的开关，头顶那根黑色集尘管同时“呼”地醒过来，锯片划过木料，木屑还没落到桌上就被吸走了。切完关机，桌面还是干净的，只有一道新鲜的锯口在冒木头味。左边整面法式挂条墙，刨子、凿子、木工夹按高矮挂着，最下面一排是自己车的木槌。地面一条黄线围出安全区，鞋子一进来就自动开启新风。你把刚切好的木盒侧板拿到过道对光看一眼——这一刻比刷十条视频都爽。

✅ 设想方案清单

  1. 工作台 1.8×0.8m 榉木台面，带木工桌钳和狗洞，靠墙一侧装排插和风批充电位
  2. 台锯、带锯、刨床沿墙 U 形摆，每台机器接一根 100mm 集尘管到角落的旋风集尘器
  3. 集尘器加一个金属阀门联动：哪台机器开机，ESPHome 就自动打开哪路阀门
  4. 对着窗的墙做法式挂条（French cleat），手工具按使用频率高低分层挂
  5. 天花装一台空气过滤箱，24 小时低速转，粉尘 PM10 数值显示在 0211 中枢屏上
  6. 地面画黄色安全线，台锯周围 80cm 内不放任何杂物，长木料从过道方向进料
  7. 留一面“样板墙”贴不同木种的小方块 + 表面处理试片，选料时对着看

🔥 小红书灵感点

  • 动手主义热潮：木工间就是精神领地，做完一个盒子发帖“第一次把木头切直了”
  • 法式挂条墙是木工博主的标配，可拆可调，工具越多墙越好看
  • 日式木工房那种“台面永远干净”的松弛感，靠的是集尘 + 每次收工五分钟归位

⚠️ 避坑提醒

  • 集尘管别用软管走长距离，弯头一多风量掉光，直管 + 少弯才有用
  • 木工间和喷漆间一定要隔开，木屑飘进喷漆间就是一层砂纸面
  • 台锯周围别放脚轮柜，踢一下滚过来卡在推料路径上，是真的会受伤

💰 预算幻想

一次性约 ¥8,000～15,000（台锯 + 旋风集尘器 + 台面）；年度耗材与电费 ¥500 左右

纯拍脑袋的量级感，真实选型以各模块的设备电商选型阶段为准。
