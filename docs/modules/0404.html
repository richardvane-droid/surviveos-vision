🎬 沉浸式想象

下午三点，头顶轨道灯的光正好落在工作台上，台面上一层薄薄的橡木粉像面粉。你推下台锯的开关，头顶那根黑色集尘管同时“呼”地醒过来，锯片划过木料，木屑还没落到桌上就被吸走了。切完关机，桌面还是干净的，只有一道新鲜的锯口在冒木头味。左边整面法式挂条墙，刨子、凿子、木工夹按高矮挂着，最下面一排是自己车的木槌。地面一条黄线围出安全区，鞋子一进来就自动开启新风。你把刚切好的木盒侧板拿到过道对光看一眼——这一刻比刷十条视频都爽。

⚠️ 避坑提醒

Seeed-Studio/xiao-esphome-projects ★ 37 无中文

Seeed 官方的 XIAO + ESPHome 成品工程集：电能计量、土壤湿度、IoT 按钮、24GHz mmWave、W5500 以太网、2/6 路继电器

→ 0805 把全屋主控定在 XIAO，这是官方给的唯一一套现成 ESPHome 工程；0404 判断哪台机器开机、开哪路集尘阀，直接照它的电能计量和 6 路继电器工程改

这个仓库是矽递科技（Seeed Studio）官方维护的 XIAO + ESPHome 工程集，收的是能直接烧的成品工程而不是库：电能计量、2 路与 6 路继电器控制、土壤湿度、IoT 按钮、24GHz mmWave 生命体征与跌倒检测、W5500 有线以太网，每个工程一份 YAML 加一张接线图。

流程还是 ESPHome 那一套：YAML 声明输入输出，编译烧进 XIAO，板子上电自连 Wi-Fi，被 HomeAssistant 用原生 API 发现。官方工程省掉的是调参那几天——电流采样的校准系数、判定阈值的滤波窗口、继电器的上电默认态和防抖，都已经按板子实测过；改几行就是自己的设备，判断逻辑留在板上，断网不影响联锁。

仓库 37 星、无中文，但作为 0805 定标器件的官方一手工程，这件事上它是唯一的现成答案；中文接线说明在 Seeed Wiki 的 cn 站，ESPHome 主线的中文社区也很成熟。

在 0404 里它同时管两件事：一块 XIAO ESP32C6 照电能计量工程读六台机器电源线上的夹式电流传感器，谁超过 2A 就判它在工作；同一块板照 6 路继电器工程驱动集尘分路阀和集尘器启停，停机后延时 8 秒再关。机器本身的强电走原有开关，板子只做判断和低压侧驱动，别把主回路接到继电器模块上。

esphome/esphome ★ 11.7k 无中文（社区教程多）

用 YAML 配置文件给 ESP32 生成固件的开源系统，电流互感器、舵机、继电器、颗粒物传感器组件全是现成的

→ 哪台机器开机就开哪路阀门、粉尘超标调新风，都是一块 ESP32 上的 ct_clamp + servo + pmsx003 三个组件；本模块唯一的通用平台

ESPHome 是 Home Assistant 官方团队维护的 ESP32 固件生成系统，11.7k 星，写一份 YAML 就能编译出会读传感器、控继电器、驱动舵机并直连 Home Assistant 的固件。木工间的三件联动——开机开集尘、哪台开机开哪路阀门、粉尘超标调新风——都是几个输入触发几个输出，正是它擅长的事。

YAML 里声明板子、Wi‑Fi 和组件，编译后 USB 刷一次，以后 OTA 更新；设备通过原生 API 和 HA 直连，每个组件自动变成实体，本地逻辑在 Wi‑Fi 断掉时也照常执行。木工间用得上的组件都是现成的：ct_clamp 配 SCT-013 电流互感器读每台机器的电流，servo 组件驱动阀门舵机，switch 接集尘器的继电器或接触器，pmsx003 读 PMS5003 的 PM2.5 和 PM10，fan 组件调新风机转速。中文社区活跃，B 站教程多。

在 0404 里，一块 ESP32 放在东北角集尘器旁的配电箱里：台锯、带锯、砂光机的电源线各穿一只互感器，电流超过阈值即判定开机，打开对应舵机阀门并启动集尘器，全部关机后延时 15 秒再停；天花的 PMS5003 读数进 HA，超过阈值把过滤箱调到高速，并显示到 0802 中枢屏。坑是舵机阀门要用金属阀体和大扭矩舵机；互感器接 ADC 要加偏置电阻和采样电容，否则读数乱跳。

lairdubois/lairdubois-opencutlist-sketchup-extension ★ 583 界面有中文

SketchUp 木工插件，从 3D 模型自动生成零件清单、下料图、标签和成本估算

→ 画完木盒模型直接出切割清单和板材排料图，切之前就知道要多少料和怎么切

OpenCutList 是法国木工社区网站 Lairdubois 开发的 SketchUp 免费插件，583 星，在 SketchUp 扩展仓库里是木工类下载量最高的插件之一。它解决的问题是：在 SketchUp 里画好一件家具后，怎么自动知道要买多少板、每块零件多大、在一整张板上怎么排才省料。

它的原理是遍历模型里的组件，按材质自动归类成板材、方料、五金三类，读取每个组件的包围盒得到长宽厚，合并同尺寸零件生成零件清单；接着用装箱算法在设定的标准板材尺寸上做排料，考虑锯缝宽度和纹理方向，输出下料图；还能打印零件标签、估算成本和重量、生成爆炸图，把结果导出成 PDF 或表格。界面支持十三种语言且可以独立于 SketchUp 语言切换，有简体中文；社区有中文教程，项目仍在持续更新。SketchUp 免费网页版不能装插件，需要桌面版。

在 0404 里，它是切木头之前的最后一步：木盒、货架、A 字架先在 0204 设计工作台的 SketchUp 里画好，跑一遍 OpenCutList 得到零件清单和 18 毫米桦木多层板的排料图，打印出来贴在台锯旁，切一块划一块；零件标签也顺手打出来贴在半成品上，和 0402 的半成品暂存区对上。坑是模型里的每块板必须做成组件而不是散面，材质名要统一，否则清单会把同一种板算成两种。

FoxDotBuild/DustCollection ★ 5 无中文

木工房自动集尘方案：ESP32 控制集尘器继电器，电流传感器检测机器开机并联动舵机阀门

→ 只有 5 星，但 GitHub 上没有更知名的“机器开机 → 开对应阀门 → 启动集尘器”完整方案，电流检测加舵机球阀的思路和代码可以直接参考

DustCollection 是 FoxDotBuild 发布的木工房自动集尘小项目，只有 5 星，但它把这件事需要的三个部件——检测机器开机、打开对应阀门、启动集尘器——用最少的零件和几百行 Arduino 代码完整做了一遍，GitHub 上没有更知名的专门项目，所以它是最直接的现成参考。

它的架构分三块：一块 ESP32 做继电器主板，开一个 Wi‑Fi 热点，接收 Telnet 命令控制集尘器的接触器；若干块 ESP8266 做传感器端，每块贴在一台机器的电源线上，用霍尔电流传感器检测机器是否通电，一旦通电就向主板发开机命令并驱动一只舵机拉开自己这路的阀门，机器关闭后延时几秒再发关机命令，让管道里的木屑先吸干净；还有一块 ESP8266 做手持遥控，两个按钮手动开关集尘器。代码是 Arduino 风格，接线图和舵机阀门支架都在仓库里，没有中文资料。

在 0404 里，思路照搬，实现换成 ESPHome：主板和传感器端合并成一块 ESP32 放在集尘器旁的配电箱里，台锯、带锯、砂光机各走一只 SCT-013 互感器接 ct_clamp，舵机阀门用它的支架思路改成金属阀体，Telnet 换成 HA 原生 API，手持遥控换成 HA 面板和一只 Zigbee 按钮。坑是它的传感器端各自独立供电，用 ESPHome 合并后所有阀门舵机的线都要拉回一处，管路布置时先把线槽留出来。

Jack000/SVGnest ★ 2.6k 无中文 延伸

浏览器里跑的开源矢量排料工具：把一堆 SVG 零件用遗传算法塞进一张板子，减少边角料，激光和 CNC 都能用

→ 一张 18mm 桦木多层板要切出十几块盒子侧板和隔板，怎么摆最省？SVGnest 是排料算法的经典开源实现，打开网页就能试

SVGnest 是加拿大开发者 Jack Qiao 写的开源排料工具，纯 JavaScript 跑在浏览器里，2.6k 星，是开源二维排料领域被引用最多的项目。它要解决的问题是：把一堆不规则零件塞进有限的板材里，让浪费最少——这在工业上叫 nesting，商业软件动辄几万块，而它免费且开源了算法。

它的工作方式是几何加进化：输入一张 SVG，第一个闭合路径当作板材，其余路径当零件；它先算每对零件之间的无碰撞多边形，得到一个零件贴着另一个滑动时所有可行的位置，再用遗传算法反复尝试摆放顺序和旋转角度，每一代选出利用率最高的方案继续变异，几分钟就能收敛到一个不错的布局，支持零件内部的孔洞里再放小零件。全程在浏览器里用 Web Worker 并行计算，不上传任何文件。输出还是 SVG，直接送激光机或转成 CNC 的刀路。

生态上它有在线版 svgnest.com，作者后来又做了桌面版 Deepnest；项目代码多年没大改，但因为是算法参考实现，各语言的移植和改进版层出不穷，界面只有英文，中文资料以论坛帖子为主。

对 0404 来说它是延伸项目：木工间做 PSK 木盒时，侧板、底板、隔板全是矩形和带圆角的异形件，OpenCutList 管矩形排料很好，异形件就交给它。从 0204 设计台把零件轮廓导成一张 SVG，板材画成 1220×2440 的矩形，在浏览器里跑几分钟，把结果打印出来贴在台锯旁，或者导给 0307 那台三轴机直接铣。注意刀具直径要事先在零件轮廓上加偏移，它本身不管刀补。

Jack000/Deepnest ★ 1.1k 无中文 延伸

SVGnest 作者做的桌面版排料软件：Electron 打包，支持 DXF 导入、多张板材、零件数量和旋转步进设置，用 C++ 加速

→ 真要给一整批木盒排料，网页版 SVGnest 太慢也不认 DXF；Deepnest 是它的桌面进化版，设置零件数量和板材数量后一键排好

Deepnest 是 SVGnest 作者 Jack Qiao 做的桌面版排料软件，用 Electron 打包，核心几何计算改用 C++ 的 Minkowski 和加速，1.1k 星，Windows、macOS、Linux 都有安装包。它要解决的问题：网页版 SVGnest 不认 DXF、不能设零件数量、大批量跑得慢，Deepnest 把它做成能日常用的工具。

它的工作方式和 SVGnest 一脉相承：导入 SVG 或 DXF，左边列出识别到的零件，给每个零件填数量，指定哪一个是板材并填板材张数；设置零件间距、旋转步进（只允许 0 和 90 度，木纹就不会乱）；点开始后遗传算法在后台反复迭代，界面实时显示当前最好方案和利用率，觉得够好了随时停，导出成 SVG 或 DXF。C++ 算无碰撞多边形，速度比网页版快一个数量级。

生态上原仓库更新停滞多年，社区分叉 deepnest-next 在继续修 bug；界面只有英文，中文资料以创客论坛和视频为主。

对 0404 来说它是延伸项目：做一批十只 PSK 木盒，每只六块板，把 0204 设计台导出的 DXF 拖进来，每种板填数量 10，板材填 1220×2440 填 2 张，旋转只允许 0 和 90 度保证木纹一致，间距填锯缝 3 毫米，跑十分钟就知道两张板够不够。结果导成 DXF 给 0307 三轴机，或打印贴台锯旁按图切。它和 OpenCutList 分工：矩形直切用 OpenCutList，异形件用 Deepnest。
