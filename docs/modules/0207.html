地堡 · 模块 0207 · 影音室

地堡天生就是电影院，我只是把 98 寸电视挂上了梁下那面墙

没窗、够黑、够安静，这里的深夜场没人会敲门。

⬜ 真实项目待设计 #家庭影院#逃避间#氛围感拉满#沉浸式#深夜场

📐 它在哪、有多大

🎬 沉浸式想象

晚上九点，你按下墙上那个铜色按钮，地堡的模拟阳光从黄昏慢慢暗到零，梁下那块 98 寸电视亮起来，220 宽，几乎占满了隔墙。你窝进沙发里，脚踩在 180×180 的毛绒地毯上，手边是一杯温的黑咖啡。片头音乐一响，你能感觉到低音从地板传上来，是那种胸口发麻的震动。四面没窗，没有窗帘漏光，也没有人会在这时候敲门。这是你一周里最像“逃避间”的两小时。

✅ 设想方案清单

  1. 南侧梁下隔墙（地堡这一侧）挂 98 寸电视，宽 220，梁底 2400 以下正好放得下，走线埋进隔墙
  2. 座位就是正对电视的 140 沙发，前面 180×180 地毯上再扔两个懒人靠垫，躺着看第二场
  3. 5.1 声道：主音箱借用 0208 的大柏林分列电视两侧，环绕装两侧墙高处，低音炮塞在电视下矮机柜旁
  4. 隔墙两侧做吸音软包 + 深灰绒布，天花板刷哑光黑，把电视的反光全部吃掉
  5. 一键“观影模式”：0201 落日 → 电视开机 → 功放上电 → 门口留 5% 夜灯
  6. 沙发扶手嵌一个杯托和一个无线充，手机永远在手边但不用拿起来
  7. 东南角门口做一块小黑板，手写“今晚放映：××”，像老电影院的排片牌

jellyfin/jellyfin ★ 54k 界面有中文

免费开源的媒体服务器，管理和串流自己的影视库，无账号无云端，2026 年 6 月 10.11.11 版仍在更新

→ 片库放在 0802 的 N100 小主机里，电视、Kodi 和手机都从它拉片，排片牌数据和观影场景的播放状态也从它读

Jellyfin 是 2018 年从 Emby 闭源后分叉出来的开源媒体服务器，54k 星，是自托管影视库这个品类里星最多的项目。硬盘里攒了几百部电影和剧，想像 Netflix 一样带海报、进度、多设备续播地看，又不想把片库交给任何云，就是它。

它的架构是一台服务器加一堆客户端：服务器用 C# 写，跑在任何 Linux 小主机或 Docker 里，扫描你指定的目录，从公开数据库抓取海报、演员和字幕信息，按需转码或直接推流；客户端有网页、安卓、iOS、电视端和 Kodi 插件，播放进度在所有设备间同步。开放的 REST API 让家庭自动化能查“正在播什么”。界面有简体中文，NAS 圈教程遍地都是；仍每月发版，2026 年 6 月到 10.11.11。

在 0207 里它是片库本体：装在 0802 那台 N100 小主机上，硬盘挂在同一台机器，98 寸电视用自带的 Jellyfin 应用直接播 4K 原盘不转码；HA 的 Jellyfin 集成把它变成 media_player 实体，观影场景一按，电视开机、功放上电、灯光落日，暂停时灯自动回到 20%。门口那块“今晚放映”小黑板的数据也可以从它的 API 读，做成 0802 大屏上的排片牌。坑是 N100 核显解码 HEVC 要打开 QSV 硬解并给容器挂载 /dev/dri，否则一转码就卡。

xbmc/xbmc ★ 21.2k 界面有中文

Kodi，2002 年起步的老牌开源家庭影院和媒体中心软件，十英尺界面、遥控器操作、插件生态庞大

→ 电视自带应用不够用时，投影或电视后面挂个小盒子跑它，本地片库、遥控和 HA 观影场景联动都有现成插件

Kodi 的前身是 2002 年给初代 Xbox 写的媒体中心 XBMC，21.2k 星，是开源家庭影院软件里资格最老、生态最大的一个。它把一台电脑或电视盒变成“坐在沙发上用遥控器操作”的媒体中心：十英尺界面、海报墙、按遥控上下左右就能看完一部电影。

它是一个本地播放器加插件平台：核心用 C++ 写，内置解码和硬件加速，能直接播本地硬盘、NAS 共享和网络流；插件扩展内容，Jellyfin、字幕站、直播源都有插件；界面有简体中文。它跑在 Linux、安卓、树莓派和 LibreELEC 上，红外、CEC 和手机遥控都支持。对家庭自动化它开放 JSON-RPC 接口，Home Assistant 有官方 Kodi 集成，能读播放状态、暂停、切片、发通知到屏幕上。维护二十多年，每年一个大版本，中文教程很多。

在 0207 里它是电视自带应用的升级方案：98 寸电视内置的 Jellyfin 应用足够时不需要它；想要更好的字幕、音轨切换和杜比全景声直通，就在电视后面挂一台 N100 或树莓派 5 跑 LibreELEC 加 Kodi，用 Jellyfin 插件同步片库和进度，HDMI 直连功放。HA 的 Kodi 集成把它变成 media_player，观影场景从它读“播放 / 暂停”控制 0201 灯光和幕布跟色灯。坑是 CEC 遥控三方抢控制权，只让 Kodi 盒子当 CEC 主设备。

hyperion-project/hyperion.ng ★ 3.8k 界面有中文

开源氛围灯软件，抓取画面边缘颜色实时驱动屏幕四周的 LED 灯带，支持 HDMI 采集卡和 WLED 等几十种灯

→ 98 寸电视背后加一圈灯带跟着画面变色，地堡全黑环境下沉浸感翻倍，输出直接走 WLED 协议

Hyperion 是 2013 年从树莓派社区长出来的开源氛围灯项目，hyperion.ng 是它的新一代重写版，3.8k 星。它做的事就是飞利浦电视 Ambilight 那套“流光溢彩”：实时分析画面边缘的颜色，让屏幕背后的 LED 灯带同步发光，画面里的火焰会把整面墙染红，深空场景则只剩一点蓝。在全黑的房间里，这圈光让 98 寸屏显得更大，眼睛也不累。

它的流水线分三段：输入端用 HDMI 采集卡（USB 采集棒即可）抓电视信号，或者直接抓 Kodi 和树莓派自身的画面；中间的处理器把画面按灯珠位置切成几十个区域算平均色，做黑边检测、平滑和亮度补偿；输出端支持几十种设备，WLED、Adalight、WS281x 直驱、Hue 都行。全部通过网页配置，灯珠位置在示意图上用鼠标画，网页界面有中文翻译；项目持续维护。

在 0207 里它跑在 0802 那台 N100 上：电视 HDMI 信号经功放分出一路进 USB 采集卡，Hyperion 算色后用 WLED 协议驱动电视背后那圈 WS2814 灯带（正好复用 0202 那种 WLED 控制器），观影场景开始时由 HA 打开 Hyperion 的抓屏，暂停或结束时关掉恢复 0201 灯光。坑是采集卡要选 4K 输入降 1080p 输出的，HDR 片源要在 Hyperion 里开色调映射，否则颜色发灰。

Radarr/Radarr ★ 14.3k 界面有中文 延伸

电影收藏管理器：维护想看清单，自动从 Usenet 和 BT 索引器找片、下载、重命名、入库，和 Jellyfin 无缝衔接

→ 影音室每周两小时的排片要有片源，Radarr 把想看清单变成自动到货的片库，Jellyfin 只管播放

Radarr 是从 Sonarr 分叉出来专门管电影的项目，C# 写成，14.3k 星，属于所谓 *arr 家族。它要解决的问题是：想看的电影一部部手动找资源、下载、改名、放进对的文件夹太累，它把整条流水线自动化。

它的工作方式是：你把想看的电影加进库（可以从 IMDb 榜单或 Trakt 列表批量导入），设定质量档位比如 1080p 蓝光或 4K；Radarr 定时去配置好的索引器（通过 Prowlarr 统一管理）搜索，找到符合要求的就推给下载器（qBittorrent、Transmission、SABnzbd）；下载完成后按命名模板重命名、移到媒体库目录、配合 Bazarr 下字幕、通知 Jellyfin 刷新库。出了更好的版本它还会自动换掉。网页界面响应式，Docker 部署。

生态成熟，2025 年后持续更新，界面翻译含简体中文，中文 NAS 圈的教程和 Docker 模板极多。

对 0207 它是延伸的片源管道：东南角小黑板上今晚放映的片名从哪来？在 Radarr 里维护一个想看清单，设 1080p 以上，它自动到货进 Jellyfin 的库；HomeAssistant 通过 Radarr 的 API 拿到最近入库列表，观影模式按钮按下时在 0802 大屏或电视上弹出本周新到的三部让你选。注意版权和索引器合规是你自己的事，另外 98 寸电视看 4K 原盘要有硬解能力，机顶盒选带 HDR 直通的。

Sonarr/Sonarr ★ 16.1k 界面有中文 延伸

剧集自动化管理器：订阅一部剧后自动追新集、按季整理、重命名、升级画质，Radarr 的亲兄弟

→ 追剧和看电影是两种节奏，Sonarr 让订阅的剧每周自动到货，影音室里周五那集永远已经在库里等着

Sonarr 是 2010 年从 NzbDrone 改名而来的剧集管理器，C# 写成，16.1k 星，是整个 *arr 家族的祖宗。它要解决的问题是：追剧要记得每周几更新、去找资源、命名成播放器认得的格式、放进对应的季文件夹，它把这些全接管。

它的工作方式是：你订阅一部剧，选要哪些季、什么质量档位；Sonarr 从 TheTVDB 拉剧集元数据和播出时间表，到点就去索引器搜新一集，找到符合要求的推给下载器，完成后按剧名 S01E05 这样的模板重命名、移进媒体库、通知 Jellyfin 刷新。它有日历视图看本周哪些剧更新，有质量配置文件决定是否用更好的版本替换旧文件，有多季批量补全和缺集搜索。界面和 Radarr 几乎一样，两者共用 Prowlarr 的索引器和同一个下载器，Docker 部署。

生态成熟，2025 年后 v4 持续更新，界面翻译含简体中文，中文 NAS 教程一般把它和 Radarr 一起讲。

对 0207 它是延伸中管剧的那一半：电影走 Radarr，剧走 Sonarr，两个容器共用同一套索引器和下载器，媒体库分成电影和剧集两个目录给 Jellyfin。它的日历 API 可以进 HomeAssistant，每周五早上 0802 大屏提示今晚有哪集更新，观影模式按下时电视直接停在那部剧的最新一集。注意剧集文件多，硬盘要预留空间并设自动删除看过的旧集，别让影音室的存储被追剧撑爆。

HandBrake/HandBrake ★ 23.5k 界面有中文 延伸

跨平台开源视频转码器：把任意来源的视频压成 H.264、H.265、AV1 的 MP4 或 MKV，带硬件加速和预设，图形界面加命令行

→ 98 寸电视和手机、iPad 需要的不是同一个文件，把原盘转成电视直接硬解的 H.265 和小屏的 720p，HandBrake 是最顺手的批量转码工具

HandBrake 是 2003 年起步的开源视频转码器，23.5k 星，三大桌面平台都有图形界面，2026 年发布了 1.11 版。它要解决的问题是：视频格式和播放设备的组合太多，需要一个工具把任何来源压成指定设备能直接播的文件，并把复杂的编码参数藏在预设后面。

它的工作方式是：输入一个文件或整张光盘目录，选一个预设（通用 1080p30、Apple 设备、或按质量的 HQ 系列），需要的话再调编码器、恒定质量值、分辨率、裁边、音轨和字幕，点开始就转码。编码器有 x264、x265、SVT-AV1 软件编码，也支持英特尔 QSV、英伟达 NVENC 和苹果 VideoToolbox 硬件加速；能批量排队，命令行版 HandBrakeCLI 适合写脚本，字幕能烧进画面也能保留成软字幕。

生态成熟，2025 年后仍每几个月一个版本，界面翻译含简体中文，中文教程非常多。

对 0207 它是延伸中的加工车间：Radarr 和 Sonarr 到货的文件格式五花八门，98 寸电视的机顶盒最省心的是 H.265 MKV 硬解，手机和 iPad 在外面看要一份 720p；写一个脚本用 HandBrakeCLI 在 0802 的服务器上夜里把新入库的文件按两套预设各转一份，Jellyfin 里就不再需要实时转码，服务器也不用配显卡。注意没有硬件加速时一部两小时的片要跑好几个小时，先试英特尔核显的 QSV，质量值 22 左右肉眼看不出差别。
