暖村木屋 · 模块 0101 · PSK 主产品展示

谁懂啊！一张信用卡大的生存卡，我给它开了个博物馆级展台

左边一张收起态的 PSK 卡，右边是它展开后的十来件小件，一收一开摆在同一块托盘上。

📐 它在哪、有多大

在木屋北墙中段偏东、0102 作品展示墙正下方，一块 ≈135×35cm 的挂墙展台，台面高 900 和西侧吧台齐平，离地 200 以上是薄抽屉；左手挨着吧台设备带，右手是梯子床。

🎬 沉浸式想象

推开木屋的门，先闻到松木和机油的味道。北墙上、九宫格作品墙正下方，那块胡桃木展台从墙里悬挑出来，托架是我自己刨的。台面中央一块黑胡桃托盘，左边躺着收起态的一张卡，85.6×54，比一枚硬币还薄；右边是它展开后的十来件小件，按爆炸图排开：火石条、锯齿、开瓶口、防水火柴、一圈凯夫拉线。梁底那盏 3000K 射灯压到很低的角度，几乎贴着台面掠过去，每一道刻痕、每一个缺口都被影子拉出厚度，不然这么薄的东西平放着根本看不见。旁边立着一块能翻下来的放大压片，你俯身，指甲盖大的火石槽一下变成一个坑。铜牌被灯照得发亮：PSK Card No.1。西南角的柴火炉在噼啪，你顺着指槽把卡抠起来掂了掂，想摸就摸。

✅ 设想方案清单

  1. 胡桃木挂墙展台 135×35cm 悬挑在北墙、作品墙正下方，台面高 90cm 和吧台齐平，前低后高 12 度
  2. 台面中央嵌一块 30×20cm 黑胡桃托盘，左边一张收起态的卡，右边十来件小件按爆炸图排开
  3. 梁底射灯改低角度掠射，光几乎贴着台面走，靠影子把刻痕、开瓶口、火石槽的厚度打出来
  4. 毛毡卡槽改薄到 1.5mm 只压四边，槽口开一个 18mm 的指槽，手指一按卡就翘起来
  5. 托盘右后角立一块可翻的三倍放大压片，翻下来正对卡面，凑近看刻痕和刃口
  6. 黄铜铭牌改刻 PSK Card No.1 与年份，压在托盘左前角，被掠射光照得发亮
  7. 台面下方那层薄抽屉改放历代原型卡，一张一格，台上这张看腻了就换一张
  8. 展台前脸嵌一块 7 寸小屏，滚动播放这张卡从收起到展开的过程和野外实测

🔥 小红书灵感点

  • 痛屋思路：整间木屋就是我的 PSK 痛屋，这块展台是祭坛，一进门先看到那张卡
  • 小红书博物馆打卡风：一件展品、一束低角度光、一块小铜牌，低成本高质感
  • 数码博主的拆机爆炸图审美：十来件小件一件件摊开排，放在一张卡旁边更有冲击力

⚠️ 避坑提醒

  • 射灯别从正上方直打，卡太薄一打就是一片惨白，只有低角度掠射才有刻痕的影子
  • 毛毡槽别切深，超过 2mm 卡就陷进去抠不出来，一定要留指槽，别用镊子去撬
  • 冷白光别用，5000K 一打卡片立刻变五金店样品；展台也别超 35cm 深，走路撞胯

Screenly/Anthias ★ 3.7k 无中文

树莓派数字标牌系统，网页后台排播放表，循环播视频、图片和网页，专为无人值守的展示屏设计

→ 展台前脸那块 7 寸小屏跑它：网页后台传视频、排播放表，插电即放不用人管，HA 还能调 API 切内容

Anthias 是 Screenly 公司维护的开源数字标牌系统，前身叫 Screenly OSE，从 2012 年起就是树莓派做展示屏的标配，3.7k 星，2025 年重启活跃开发，2026 年 5 月又发了新版。它解决的问题很朴素：一块屏、一台小电脑，插电就循环播放你排好的内容，不需要人守着。

架构分两层。管理端是跑在树莓派上的 Django 网页后台，你在手机或电脑浏览器里上传视频、图片或填一个网址，设定每条素材的播放时长、生效时段和顺序，形成一张播放表；播放端叫 Viewer，用 WebView 加硬件解码把素材全屏铺满，断电重启后自动接着播。整套用 Docker 打包，树莓派 3 到 5 和 x86 小主机都支持，7 寸官方屏免驱。

生态上它有 REST API，可以从外部改播放表、切资源，Home Assistant 用 rest_command 就能调。文档是英文，没有中文版，但 B 站有旧版 Screenly OSE 的搭建教程，思路一样。

放进 0101，它就是展台前脸那块 7 寸屏的全部软件：树莓派藏在展台抽屉后，屏排三条素材，卡片展开顺序的图文、野外实测视频、PSK Card 的 logo 待机画面。人靠近时 HA 调 API 切到实测视频，离开五分钟回到待机，晚上十一点后黑屏省电。坑在树莓派软解 1080p 会掉帧，视频预先压成 720p 的 H.264 就顺了。

EverythingSmartHome/everything-presence-lite ★ 293 无中文

基于 ESPHome 的毫米波人体存在传感器，LD2450 雷达带目标坐标与照度，直接接入 HomeAssistant

→ 展台射灯人靠近自动亮就靠它，毫米波比红外灵敏，站着不动也不会灭灯，还能画一个只覆盖展台前的检测区

Everything Presence Lite 是英国智能家居博主 Everything Smart Home 设计的开源人体存在传感器，293 星，硬件在自家商店卖，固件与 ESPHome 配置全部开源，是 HA 圈子里最出名的毫米波存在传感器之一，2025 年后仍在更新。它解决的是红外传感器的老毛病：人坐着不动就当没人，灯一会儿就灭。

核心是一块 ESP32 模组外加海凌科 LD2450 24GHz 毫米波雷达和一颗照度传感器。雷达测的是微动，呼吸的细微位移都能捕捉，最多同时跟踪三个目标的坐标；固件把目标位置、照度以及最多四个自定义检测区原生上报给 HA，仓库附带一个网页工具，拖框画出检测区和排除区再写回设备。

它就是标准 ESPHome 设备，HA 里自动发现；社区还有 CO2 版和无蓝牙版的配置分支。文档和视频都是英文，B 站有搬运讲解。

放进 0101，它贴在展台上方的梁底，正对北墙前一米的那块地板，画一个 1.5 米乘 1 米的检测区，只要有人站到展台前，HA 自动化就把 3000K 射灯从 10% 拉到 100%，并让侧屏切到实测视频；人离开 30 秒后灯缓缓回落。照度传感器顺便当白天判据，南窗光够时不亮灯。坑在雷达会穿透薄木板，检测区要画准，否则你在吧台坐着它也会亮。

esphome/esphome ★ 11.7k 无中文（社区教程多）

用 YAML 配置把 ESP32 / ESP8266 变成 Home Assistant 原生设备的固件生成器，几百种传感器与执行器现成组件

→ 射灯的 PWM 调光节点和照度传感器都用它写几十行 YAML 生成固件，BH1750、MOSFET 调光、LD2410 都是自带组件

ESPHome 是 Home Assistant 官方团队 Nabu Casa 维护的固件生成工具，11.7k 星，2018 年由 Otto Winter 创建，每月发版，是 HA 生态里做自制传感器和执行器的默认答案。想让一块 ESP32 上报温度或调光，不必写 C++，写几十行 YAML 声明引脚和组件，它就编译出固件并无线刷写。

原理是把声明式配置转成 C++：你在 YAML 里写 sensor、light 等块，ESPHome 拼装组件源码交给 PlatformIO 编译，设备开机后通过原生 API 与 HA 加密直连，实体自动出现，断网时本地自动化照样跑。它支持 ESP32 全系、ESP8266、RP2040，内置几百个组件，从 BH1750 照度、MAX6675 热电偶到 LD2410 雷达、PWM 调光都有现成写法。

社区极大；官方文档只有英文，但 B 站、CSDN 的中文教程很多，参数名一看就懂。

放进 0101，它负责两件小事：一块 ESP32-C3 通过 MOSFET 对 24V 的 3000K 射灯做 PWM 调光，暴露成 HA 里的一个可调光灯；同一块板再挂一颗 BH1750 读展台环境照度，作为白天不亮灯的判据。注意 PWM 频率设到 1kHz 以上，手机拍视频才不出条纹。

photoprism/photoprism ★ 40.1k 界面有中文 延伸

Go 语言写的自托管 AI 相册：TensorFlow 自动打标签、人脸识别、地图、按镜头和相机筛选，一条 Docker 命令就起

→ PSK 卡每一代的产品照、细节照、野外实测照都堆在硬盘里，需要一个能按型号和场景秒找的产品图库给展台小屏和视频剪辑喂素材

PhotoPrism 是德国 PhotoPrism UG 团队做的自托管 AI 相册，用 Go 写后端、Vue 写前端，40.1k 星，是自托管照片圈里最常被推荐的方案之一。它要解决的问题是：照片越来越多，但没人愿意把私人照片交给云相册，也没人愿意手工给几万张图打标签。

它的工作方式是索引而不是导入：把照片目录只读挂进 Docker 容器，后台扫描一遍就生成缩略图和数据库，原文件一根手指头都不碰。扫描时 TensorFlow 模型给每张图打上物体和场景标签，人脸聚类、GPS 反查地名、相机和镜头型号都进索引，再配合 RAW 转换和视频转码。前端是一个响应式网页，手机、平板、电脑都能用，搜索栏里可以直接写 lens:iphone year:2024 这样的查询。

生态方面它有官方 Docker Compose、群晖和树莓派安装说明，PhotoSync 之类的手机备份 App 原生支持它；界面自带简体中文，中文安装教程也多。项目靠订阅和赞助维持，2025 年之后依然每月出版本。

对 0101 来说它是延伸项目：展台小屏要滚动播放这张卡的展开过程和实测视频，素材从哪来？把这些年拍的 PSK 产品照、车床加工照、山顶实测照全部索引进 PhotoPrism，给每一代卡建一个相册，用标签区分产品照、细节照、野外照。剪视频时按标签一搜就出来，展台小屏的待机画面也可以直接指向某个相册的分享链接。注意机器：AI 索引第一次跑很吃 CPU，放在 0802 的家庭服务器上夜里跑就行。

mrdoob/three.js ★ 115k 有中文文档站 延伸

浏览器里的 3D 引擎标杆：WebGL/WebGPU 渲染、glTF 加载、轨道控制器，几十行代码就能在网页里转着看一个模型

→ PSK 卡和它展开后的小件本来就是 3D 建模出来的，把 glTF 放进网页就能在展台小屏和手机上转着看爆炸图，比拍视频更直观

three.js 是 Ricardo Cabello（mrdoob）在 2010 年发起的 JavaScript 3D 库，115k 星，几乎是网页 3D 的代名词。它要解决的问题是：浏览器原生的 WebGL 太底层，画一个立方体都要写几百行着色器；three.js 把场景、相机、灯光、材质、几何体封装成对象，像摆积木一样搭 3D 场景。

它的流程是：创建 Scene，放进 Mesh（几何体加材质）和 Light，用 PerspectiveCamera 看，再由 WebGLRenderer 或新的 WebGPURenderer 每帧渲染到 canvas 上。模型一般用 glTF 格式，GLTFLoader 一行加载，OrbitControls 加上去就能用手指旋转缩放，PBR 材质配一张 HDR 环境贴图，金属和塑料的质感就出来了。

生态极大：官方文档有简体中文版，示例几百个，中文书和 B 站课程成体系，2025 年后仍是每月一个版本。

对 0101 它是延伸玩法：PSK 卡的卡身和展开后那十来件小件本来就有 CAD 模型，从 FreeCAD 导出 glTF，写一个百来行的网页放在展台前脸那块 7 寸小屏上，人走近时 HomeAssistant 把小屏切到这个页面，卡身缓慢翻面、小件按爆炸图拉开，点一件弹出名字和用途；扫铜牌旁的二维码手机上看同一页。注意模型要减面，树莓派跑不动原始 CAD，用 Blender 抽稀到两三万面。
