地堡 · 模块 0209 · 藏宝阁

床下 1.5×2m 密室：推开帆布滑门，是我的秘密书房

40cm 的帆布滑门一推，里面是一整面书格、一张写字台，和一墙不给人看的海报。

🚧 真实设计进行中 #秘密基地#精神领地#痛屋#书墙#海报墙

📐 它在哪、有多大

地堡西北角那张 200×120 架空床的床下：床板 1750、床下净高 1700，围出 1.5×2m 的密室，2m 的长边南北向——西侧长墙贴既有结构做连续书格，东侧长墙靠南那一端开一道 40cm 宽的帆布滑动门（正对东侧沙发方向），北端 1.5m 短墙整面留给写字台；南边紧挨着双层衣架 120×60。

🎬 沉浸式想象

40cm 宽的帆布滑门一推，我侧身进去，门一带上，地堡就关在外面了。1.5×2 米，净高 1.7 米，坐直了抬头还剩一大截——第一次有一间不用弯腰的密室。左手边整面长墙是贴着既有结构做的连续书格，一格一格全是最近在翻的书，伸手就能抽。尽头一张 1.5 米宽的写字台，坐进人体工学椅，腰被稳稳托住。头顶那圈洗墙灯带 360 度绕着走，2700K 的光贴着墙往下淌，书脊和海报一层层亮起来，没有一盏直射眼睛。台角那套瓷银茶器就那么明放着，银壶泛出旧旧的亮。抬头是海报墙：张岱、沈复、陶渊明、李渔的句子，几张电影海报，还有我自己聊天里截的金句，像一群古人跟我同桌。没有屏幕，没有提示音。我拉开椅子坐下，写字。

✅ 设想方案清单

  1. 架空床板 1750、床下净高 1700，床下围出 1.5×2m 的密室，宽度比 120 的床板往东多吃 30cm
  2. 门只做一道 40cm 宽的帆布滑动门，开在 2m 长墙上离写字台最远的那一端，侧身进出
  3. 另一面长墙贴既有结构做一整排浅书格，只放常翻的书，尽端留一格塞铁皮宝箱
  4. 家具直接上 1.5m 标准写字台 + 人体工学椅，椅子总高挑 ≤130cm，抬头不顶床板
  5. 顶部一圈 360° 环绕 LED 洗墙灯带，2700～3000K、双路供电，专洗书格和海报墙
  6. 瓷银茶器就明放在写字台一角，不做收纳盒，磕碰和氧化都提前认了
  7. 海报墙还是三类：名言（张岱、沈复、陶渊明、李渔）、电影海报、自己的对话金句
  8. 不额外装通风装置，只在顶角挂一颗 CO2 传感器兜底，超 1200ppm 就推送提醒开门

⚠️ 避坑提醒

  • 净高只有 1700，人体工学椅头枕和气压杆一升就顶床板，买之前先量总高

wled/WLED ★ 18.7k 无中文

ESP32 上最流行的灯带控制固件，网页和 App 直接控，250 个预设、定时、洗墙渐变等上百种效果，HomeAssistant 自动发现

→ 顶部那圈 360° 环绕洗墙灯带刷它，书格侧和海报墙侧分两路，迎接 / 写字 / 收工三个预设，手机上直接调亮度和色温

WLED 是奥地利开发者 Aircoookie 从 2016 年开始写的 ESP32 / ESP8266 灯带固件，18.7k 星，是 GitHub 上最流行的灯光固件。一根几十块钱的灯带接上一块 ESP32，刷完固件就是一盏能手机调、能被家庭自动化接管的智能灯。

固件内置网页服务器：手机打开网页就能选颜色、调亮度、从一百多种效果里挑，把状态存成预设，最多 250 个；内置定时器按时间或日出日落切预设。对外它开放 JSON 和 MQTT 接口，Home Assistant 有官方集成，自动发现后每个 WLED 设备是一个灯实体，预设是一个下拉选项。支持 WS2812、SK6812、CCT 等各种灯带，可分段控制。社区极大，文档英文，中文教程和 B 站视频非常多。

在 0209 里它管顶部那圈 360° 环绕洗墙灯带：两块 ESP32-C3 各驱动一路 CCT 或 WWA 暖白灯带，一路洗西侧那面连续书格，一路洗写字台上方的海报墙，藏在顶部灯槽里，色温压在 2700～3000K。存三个预设：迎接是滑门一推两路都到 40%，写字是书格侧 25%、海报墙侧 60%，收工是 5% 的余光；HA 按滑门磁簧和座位存在传感器切预设。坑是洗墙灯带离墙面要留 8～10cm，不然打出一排扇形亮斑；这间密室是双路供电，两路灯带别接在同一个电源上，跳一路还剩一路能看见门。

FastLED/FastLED ★ 7.4k 无中文

Arduino 上最常用的 LED 灯光动画库，支持 50 多种单片机平台和几乎所有可寻址灯珠，3.10 版

→ 想给洗墙灯带写一段十几秒的长渐变或收工余晖时用它，比 WLED 自由；它也是 WLED 效果引擎的底层参考

FastLED 是 2012 年由 Daniel Garcia 和 Mark Kriegsman 创建的 Arduino LED 库，7.4k 星，是可寻址灯珠圈里资格最老、用得最广的动画库，2025 年仍密集更新到 3.10 版。想让一串 WS2812 按自己的想法闪，时序、颜色空间和性能它全包，你只管写“第几颗灯什么颜色”。

它的核心是一个 CRGB 数组加一个 show 函数：循环里改数组里每颗灯的颜色，调用 show，库按灯珠型号的精确时序把数据推出去。上面叠一层工具：HSV 色彩、调色板、噪声函数、淡入淡出，几行代码就能写出烛光、火焰、星空、流星，示例里都有现成的。支持 50 多种平台，从 ATtiny 到 ESP32 和树莓派 Pico。文档英文，中文 Arduino 教程几乎都会讲到它。

在 0209 里它是 WLED 不够用时的下一步：密室里不要跑马灯那种炫技，要的是慢——滑门推开时书格从尽端一格一格亮过去，收工时光像退潮一样从海报墙上撤走，这种十几秒的长渐变用内置效果很难调细，就在同一块 ESP32-C3 上用 FastLED 自己写，滑门磁簧直接触发效果切换，再用 MQTT 把状态接回 HA。坑是 WiFi 会打断灯珠时序造成闪一下，用 RMT 驱动或者把灯效放到另一个核心跑。

esprfid/esp-rfid ★ 1.5k 无中文

ESP8266 / ESP32 上的 RFID 门禁固件，支持 RC522、PN532、Wiegand 读卡器，带网页管理、用户名单、日志和 MQTT，2024 年 2.0 版

→ 书格尽端那个铁皮宝箱加一把 RFID 小锁，刷卡才开，秘密基地的仪式感就有了；网页里管卡、看日志，MQTT 报给 HA

esp-rfid 是 2017 年由土耳其开发者 Ömer Şiar Baysal 发起的开源门禁固件，1.5k 星，2024 年 11 月发了 2.0 版，是 GitHub 上最完整的 DIY RFID 门禁方案。想给一扇门或一个柜子装“刷卡才开”的电子锁，它只需要一块 ESP8266、一个二十块钱的 RC522 或 PN532 读卡模块和一个电磁锁或舵机。

固件内置网页管理界面：加卡、删卡、给每张卡设有效期和可开的时段，最多一千个用户；每次刷卡记一条带时间戳的日志，NTP 对时；读卡器支持 RC522、PN532、RDM6300 和 Wiegand 接口；输出是继电器，可设开锁时长。对家庭自动化它有 MQTT：每次刷卡把卡号和结果发出去，也能远程开锁、远程加卡。文档英文，硬件图和 PCB 开源。

在 0209 里它给藏宝阁加一道仪式：滑门内侧的门框上贴一块 PN532 读卡板，书格尽端那个铁皮宝箱里塞一个小舵机锁，随身带一张旧公交卡或一枚 NFC 戒指，侧身进门时顺手在门框暗处一刷，宝箱咔哒一声弹开。MQTT 把刷卡事件报给 HA，正好当进入信号，触发 WLED 的迎接预设。坑是 RC522 读 13.56MHz 卡距离只有两三厘米，藏在木饰面板后面要贴着板背；舵机动作瞬间电流大，和读卡板共用那路电源时留 1A 余量。

延伸阅读 借这个模块顺手学一遍的热门项目

和本模块的关系没上面那么直接，但都是 GitHub 上值得整个看一遍的经典项目；每条最后一段写了在这里能怎么用。

usememos/memos ★ 62.5k 界面有中文 延伸

自托管的轻量笔记流：像发微博一样随手记一条，Markdown、标签、图片，Go 单文件部署，数据全在自己手里

→ 海报墙那三类内容——名言、电影、对话——先在手机上随手记进 memos，攒够一批再挑出来打印上墙

memos 是 Steven（boojack）在 2021 年发起的开源笔记项目，Go 后端加 React 前端，62.5k 星，作者来自中文社区。它要解决的问题是：想记的东西大多是一两句话或一张截图，传统笔记软件的文件夹和标题让人懒得打开；它把笔记做成一条条时间流，像发微博一样记，像刷微博一样翻。

它的工作方式极简：一个二进制或一个 Docker 容器，数据存在 SQLite（也可以 MySQL、PostgreSQL）里，网页界面顶部一个输入框，写 Markdown、加标签、贴图片、按回车就是一条 memo；左侧按标签和日期筛选，热力图显示每天记了几条，memo 可以设公开分享链接，也能置顶和归档。它有完整的 API，社区做了 iOS、安卓、浏览器插件和 Telegram 机器人，Obsidian 也能同步。它刻意不做的事也很明确：没有文件夹、没有富文本、没有协作，专注于快速捕捉。

社区非常大，2025 年后依然每月一个版本，界面自带简体中文，中文用户和教程占了很大比例。

对 0209 它是延伸的收集箱：海报墙的素材——读到的一句话、电影里的一句台词、聊天时截下的一段对话——随手记进 memos，标签分名言、电影、对话三类，正好对应墙上的三个区；名言大多来自张岱《陶庵梦忆》、沈复《浮生六记》、陶渊明《归园田居》和李渔《闲情偶寄》。每季度按标签筛一遍，挑出来的用打字机字体打在牛皮纸上贴上去，换下来的按日期收进铁皮宝箱。注意它是收集不是展示，密室里不放屏幕，最终上墙的必须是纸。

ankitects/anki ★ 30.4k 界面有中文 延伸

间隔重复记忆卡片软件：算法按遗忘曲线安排复习，桌面、手机、网页同步，卡片模板可自定义，插件生态庞大

→ 墙上那些名言看多了就视而不见，做成 Anki 卡片每天在写字台前翻五分钟，才真的记进脑子

Anki 是 Damien Elmes 在 2006 年开始写的间隔重复软件，Python 加 Rust 重写核心，30.4k 星，是背单词和医学生记知识点的标准工具。它要解决的问题是：人记东西会遗忘，复习太早浪费时间、太晚就忘光；间隔重复算法在你快要忘的那一刻把卡片再拿出来。

它的工作方式是：卡片由笔记生成，笔记是字段（正面、背面、来源），模板决定怎么渲染成卡片，可以有图片、音频、公式；每天打开它会给你今天该复习的卡片，看完正面回忆背面，按记不住、困难、良好、简单四个按钮打分，算法（现在默认是 FSRS）据此算下一次出现的间隔，从一天到几年。数据是本地 SQLite，通过 AnkiWeb 同步到手机的 AnkiMobile 和安卓的 AnkiDroid，也可以自托管同步服务器。插件用 Python 写，几千个，从自动配图到统计热力图都有。

生态极大，2025 年后仍是每两个月一个版本，界面自带简体中文，中文用户群和教程非常多。

对 0209 它是延伸的记忆环节：海报墙上的名言、电影的导演和年份、对话里那些当时打动你的话，做成一个叫藏宝阁的牌组，正面是上半句或电影海报缩略图，背面是下半句或出处。每天推开滑门、坐进人体工学椅之后，先用手机上的 AnkiDroid 翻五分钟，离线可用，床下信号差也没关系，出去有网了再同步。注意卡片别做多，一面墙十来张就够，Anki 的价值在坚持不在数量。

koreader/koreader ★ 29.5k 界面有中文 延伸

电子墨水阅读器上的开源阅读软件：Kindle、Kobo、PocketBook 都能装，支持 EPUB、PDF、DjVu，排版和字典功能远超原厂

→ 书格里只放常翻的纸书，更长的书单塞进一台刷了 KOReader 的旧 Kindle，洗墙灯下看，电池撑几周

KOReader 是 2011 年从 Kindle 越狱社区长出来的开源阅读软件，Lua 写成，29.5k 星，能装在 Kindle、Kobo、PocketBook、reMarkable 和安卓上。它要解决的问题是：电子墨水阅读器的原厂系统功能少、格式挑、排版不能细调，而这些机器的硬件其实很好。

它的架构是一个 Lua 框架加两个渲染引擎：MuPDF 负责 PDF 和 DjVu，crengine 负责 EPUB、FB2、MOBI 这类可重排格式。打开一本书后可以调字体、行距、边距和竖排，PDF 能重排和裁边；内置 StarDict 词典、维基百科查询和翻译，阅读统计能画出每天读了多久，书籍和进度可以通过 Calibre、OPDS 和自建的同步服务器同步。安装是把文件拷进设备并接管启动，各机型有详细步骤。

社区活跃，2025 年后仍是每月一个版本，界面自带简体中文，中文用户很多，繁简竖排支持是它的强项之一。

对 0209 它是延伸的阅读设备：那面连续书格进深只有 180mm，放得下的都是最近常翻的几十本，更长的书单交给一台闲鱼买的旧 Kindle，刷上 KOReader 摆在台角，洗墙灯照着看，电池撑三四周。书从 0303 的 Calibre 库通过 OPDS 拉进去，床下 WiFi 弱，走出滑门再同步进度；海报墙上那些名言的出处——整本书——就在这台机器里。铁皮宝箱里的旧手机也可以装安卓版当备用。注意 Kindle 越狱只对老固件容易，买二手前先查型号和固件版本能不能越狱。
