🎬 沉浸式想象

晚上十点，模拟阳光已经熄了，工作台上只剩屏幕的光和一盏 2700K 的台灯。左屏是 HomeAssistant 的全屋状态，中屏开着 0601 草地的滴灌图纸，右屏是切片软件正在算一个新的 PSK 内衬。屏幕上方那条西墙贴满了 A3 图纸——木屋剖面、地堡风管走向、钓台顶棚草图，用麻绳和木夹子挂着，像案件调查墙。你抬头看了一眼墙上靠天花板的空白区域，那是留给 07 钓台的。桌角的杯子里咖啡已经凉了，手边的笔记本上写着：“明天先测风管噪音。”

✅ 设想方案清单

  1. 160×80 的胡桃木整板工作台（0008 给的 80×160 那块位置，靠西墙），支架用黑色方管，桌下走线槽把所有线藏干净
  2. 34 寸带鱼屏居中 + 两块 27 寸竖屏，弧形排列刚好铺满 160 宽的桌面，正好包住一个人的视野
  3. 屏幕上方到天花板那条 ≈1.2m 高的西墙钉软木板，麻绳 + 木夹子挂 A3 图纸，按区域 01～07 分栏
  4. 桌面南端留 ≈30cm 空位放0305 那台自建 Voron 出的样件和 PSK 零件，边看边摸
  5. 台灯用 2700K 可调，夜里跟 0201 落日场景联动，桌面光跟着一起暗
  6. 桌下装一块 ESPHome 按键板：一键切换“设计模式”，灯、音乐、屏幕全部就位
  7. 抽屉里固定一套画图工具：比例尺、针管笔、卷尺、方格本，随时手绘草图

FreeCAD/FreeCAD ★ 32.2k 有中文文档站

免费开源的参数化 3D 建模软件，2026 年已到 1.1 版，带建筑 BIM、零件、装配和图纸工作台，界面和 wiki 都有中文

→ 画木屋剖面、地堡风管走向和 PSK 零件都用它，一套软件从房子画到打印件，图纸墙上的 A3 图也从它出

FreeCAD 是 2002 年起步的开源参数化 3D 建模软件，32.2k 星，2024 年底发布 1.0 版后彻底甩掉了“能用但难用”的名声，2026 年已到 1.1.1。想认真画一栋房子、一根风管、一个打印件，商业 CAD 要么贵要么绑云，它免费、本地、格式开放。

它的核心是参数化建模：你画的每一步都存成一棵有历史的树，改早期一个尺寸，后面所有特征跟着重算。功能按工作台划分——Part Design 画零件，Sketcher 画带约束的草图，BIM 工作台画墙、门窗、楼板和管线，TechDraw 从模型生成带尺寸标注的二维图纸，还能导出 STEP、DXF、IFC 和 STL。1.0 版解决了困扰多年的拓扑命名问题。

生态上有大量插件，社区论坛活跃；界面有简体中文，官方 wiki 有中文翻译，B 站教程很多。

在 0204 里它是中屏的主角，也是这面图纸墙的源头：木屋和地堡先在 BIM 工作台按 0008 的实测尺寸建一个总模型，各模块的风管、滑轨、货架都作为子对象往里加；要打印的 PSK 内衬和 0210 的斜滑轨导轨用 Part Design 画完直接导 STL 给右屏的切片软件；每个模块画好后用 TechDraw 出一张 A3 图纸打印挂上墙。坑是学习曲线仍陡，先用 Part Design 画几个小零件再上 BIM，模型按区域拆文件用链接引用。

bambulab/BambuStudio ★ 5k 有中文文档站

拓竹官方开源切片软件，基于 PrusaSlicer 分支，也能给别家机器出 G-code，界面和 wiki 都有中文

→ 右屏跑的就是它：PSK 内衬和 0210 的斜滑轨导轨在这里切片，导出的 G-code 交给 0305 那台自建 Voron

Bambu Studio 是深圳拓竹科技的官方切片软件，5k 星，2022 年随 X1 打印机一起发布，代码基于 PrusaSlicer 分支，底子是开源社区打磨十几年的切片引擎。它把 3D 模型变成打印机能执行的 G-code，并把多色、联网打印做成一键。

工作流程是：导入 STL 或 STEP，放到打印床上，选打印机、材料和层高质量预设，点切片，软件把模型切成层、算出路径、生成支撑和填充，预览每一层的走线和时间估算。特色是预设极细，每种官方线材都有调好的参数；一键联网打印和 AMS 自动换料只对拓竹自家机器生效，给别家机器可以自定义机型后导出 G-code。

代码持续更新，界面有简体中文，官方 wiki 有中文站，B 站教程海量；社区还有更开放的分支 OrcaSlicer，0305 用的就是那一支。

在 0204 里它常驻右屏，作用是切片和逐层预览这一段：FreeCAD 导出的 STL 拖进来，PSK 内衬用 PETG 预设、0210 的斜滑轨导轨用 PLA 高强度预设，切完导出 G-code，扔进 0305 那台自建 Voron 的 Klipper 队列，进度回到左屏的 HA 卡片。坑是它的一键直发和摄像头只认拓竹机器，自建机要先在软件里建一个自定义机型、把喷嘴和打印体积填对，再把起始 G-code 换成 Klipper 那套；工作台南端那 30cm 就是放刚打出来的样件的。

shmuelzon/home-assistant-floor-plan ★ 1.1k 无中文

Sweet Home 3D 插件，把 3D 户型按每盏灯分别渲染，再生成 HomeAssistant 的 picture-elements 平面图面板

→ 在 Sweet Home 3D 里画完全屋，一键导出带灯光状态的 3D 平面图给 0802 大屏和左屏用，不用手工抠图

home-assistant-floor-plan 是以色列开发者 shmuelzon 写的 Sweet Home 3D 插件，1.1k 星。它解决 HA 玩家的老痛点：都想要一张“会亮灯的 3D 户型图”当仪表盘，但传统做法要给每盏灯单独渲染，再手写几十行 YAML 叠图，一改户型就全部重来。

它的原理是把这件事自动化：你在免费开源的 Sweet Home 3D 里画好房子、放好家具和灯，把每盏灯和 HA 的实体名对上；插件就逐一渲染“只开这盏灯”的图，加上全暗的底图，最后生成一份 YAML，用 CSS 混合、房间遮罩或整图替换三种模式之一，让 HA 按实体状态把对应的亮灯图叠上去。传感器、开关也能放上去变成可点图标。渲染用 Sweet Home 3D 自带的光追引擎。

项目持续更新，文档英文，但 Sweet Home 3D 本身有中文界面。

在 0204 里它是“图纸到大屏”的最后一步：木屋和地堡先在 Sweet Home 3D 里按 0008 尺寸画一遍（比 FreeCAD 快得多，只求像不求准），把 0201 南光灯、0202 灯箱、0207 电视、0209 帐篷小灯都对上 HA 实体，导出后放进左屏的 HA 仪表盘和 0802 大屏。坑是灯多了渲染组合会爆炸，用 CSS 混合模式并把同场景的灯合并成一个实体；地堡无窗，环境光要调到零。

延伸阅读 借这个模块顺手学一遍的热门项目

excalidraw/excalidraw ★ 131k 界面有中文 延伸

手绘风格的虚拟白板：矩形、箭头、文字、图库，端到端加密协作，可嵌入网页，导出 SVG 和 PNG

→ 工作台西墙那面图纸墙需要一张能随手改的全屋系统图，Excalidraw 的手绘风和本站铅笔风一脉相承，画完导出就能钉上墙

Excalidraw 是 Vjeux（Christopher Chedeau）等人在 2020 年做出来的开源白板，131k 星，是 GitHub 上星数最高的画图工具。它要解决的问题是：正经的绘图软件太重、画出来太正式，而白板讨论需要的是几秒钟画出一个看起来像草图的方框和箭头。

它是纯前端应用，React 加 TypeScript，画布上只有矩形、圆、菱形、箭头、线、文字、自由笔和图片这几种元素，全部用 rough.js 渲染成手绘风格。数据是一个 JSON 场景文件，可以保存到本地、导出 PNG 和 SVG，也可以把场景嵌进 PNG 里下次拖回来继续编辑。协作走端到端加密的房间链接。它有巨大的图库可以拖进现成图标，还能作为 npm 包嵌进自己的网页。

生态极大，2025 年后仍每周有提交，界面有简体中文，浏览器打开 excalidraw.com 就能用，也可以 Docker 自托管。

对 0204 它是延伸的画图纸工具：西墙软木板上那些 A3 图纸——木屋剖面、地堡风管走向、钓台顶棚——在正式的 CAD 之前先用 Excalidraw 画草图，每个区域一个文件，01 到 07 分栏和软木板上的分栏一致。特别适合画全屋系统图：传感器、HA、大屏、鸭子的数据流向用箭头一连，导出 A3 打印钉上墙；改了就重打，旧的按日期收进抽屉。它也能嵌进 0802 大屏当一块可编辑的系统图。注意手绘风只是风格，尺寸标注它不擅长，带尺寸的还是去 FreeCAD。

jgraph/drawio ★ 7.9k 界面有中文 延伸

diagrams.net 的前端源码：正规的流程图、网络图、平面图工具，图形库巨大，可以离线用、自托管、嵌进 Confluence 和 VS Code

→ 风管走向、电路接线、网络拓扑这些需要正规符号和精确对齐的图，Excalidraw 太随意，draw.io 有现成的 HVAC、电气和网络图形库

draw.io（现在叫 diagrams.net）是英国 JGraph 公司维护的开源画图工具，7.9k 星，2005 年就有前身，是浏览器里最完整的免费流程图软件。它要解决的问题是：Visio 贵而且只在 Windows 上，工程师需要一个免费、离线可用、图形库齐全的正规画图工具。

它是纯 JavaScript 客户端应用，画布基于 mxGraph 图形引擎，图形库覆盖流程图、UML、网络拓扑、电气符号、平面图和家具、甚至 HVAC 风管；元素能吸附对齐、自动布局，连线可以走正交折线自动避让。文件是 XML，可以存成 .drawio 或嵌进 PNG 和 SVG，桌面版是 Electron，网页版可以 Docker 自托管，还有 VS Code 插件，Git 里存 .drawio 文件看 diff 也方便。

生态成熟，2025 年后仍是每月一个版本，界面翻译含简体中文，中文教程和模板很多。

对 0204 它是延伸中和 Excalidraw 分工的那一个：草图归 Excalidraw，正规图归 draw.io。0203 那圈 Φ100 风管四个出风口的走向、0201 滑轨的接线和限位、全屋 MQTT 和网络拓扑、储藏室钢架的平面布置，都用它的 HVAC、电气和平面图库画，尺寸对齐精确，导出 PDF 打 A3 钉在软木板对应的分栏里。桌面版装在工作台的中屏，文件和 FreeCAD 模型放同一个仓库做版本管理。注意它的平面图库是英制家具尺寸，画地堡平面时先把网格设成 100mm。
