谁懂啊！家里多了一只会自己走门串户的 AI 小鸭子，一整个爱住

一只 25 厘米高的双足电子鸭，在木屋、地堡和阁楼之间自己走，是全屋系统长出来的那张脸。

📐 它在哪、有多大

没有固定驻留的房间，这正是它被放进 08 虚拟空间的原因：白天在木屋吧台脚边、地堡地毯上和阁楼工具台旁之间走动，靠木屋暗门底下和地堡门下各一条 12cm 通道、阁楼楼梯口一段小坡道串起三个空间；三个房间各有一个充电小窝，默认回地堡沙发旁那个。（0008 未定位，设想落位）

🎬 沉浸式想象

早上七点，你在木屋吧台边磨豆子，听见地堡那边“嗒、嗒、嗒”一串小碎步——鸭子从暗门底下钻过来了，站在吧台脚边仰头看你，两只眼睛的 LED 眨了一下。你问它：昨晚雨水罐接了多少？它歪了一下头，胸口的小圆屏跳出“+310L”，然后用一种有点欠揍的语气说：够草地喝一个星期。你笑了一下，它也跟着晃了晃身子。中午它自己走回地堡充电，下午你在阁楼打印零件，它顺着楼梯口的坡道蹭上来，蹲在工具台旁边看你，偶尔把你随口说的一句“记得买 M3 螺丝”记进清单。它不干活，它只是在。这个房子里唯一会主动找你的东西，是它。

✅ 设想方案清单

  1. 用 Pollen Robotics 的开源 Microduck 方案做底子：15 个舵机的双足小鸭，25cm 高、约 800g，走路靠强化学习训练出来的步态策略
  2. 语音大脑走小智（xiaozhi-esp32）那套：本地唤醒 + 云端大模型对话，只回答一个人的问题，不联网广播
  3. 胸口一块 1.28 寸圆屏当表情和数据窗，眼睛用两颗 RGB LED，情绪状态跟 HomeAssistant 里的全屋状态联动
  4. 地堡门下留一条 12cm 高的鸭子通道，木屋暗门底下也留一条，阁楼楼梯口做一段 15° 的小坡道，让它能在三个空间之间自己走
  5. 每个房间放一个充电小窝（无线充电板 + 反光标记），电量低于 20% 自己回最近的窝
  6. 它是 0802 的移动分身：问它任何模块的数据，它去 HomeAssistant 查了用嘴说；也是 0801 的记录员，随口一句“这个放阁楼第三箱”它就记
  7. 外壳自己用拓竹打印，换季换羽毛：冬天毛绒罩，夏天透气壳，表面一定要经得起摔

🔥 小红书灵感点

  • 小红书上「桌面 AI 宠物」热帖的做法：不追求功能多，追求眼神和小动作，眨眼、歪头、抖一下比说话更让人上头
  • 「家的丰容计划」话题：家里要有一个会动、会回应的东西，让空间有生命感——鸭子就是这座园子的丰容
  • 「精神领地」调性：它只认一个人，别人对它说话它装没听见，这是一只有边界感的鸭

⚠️ 避坑提醒

  • 双足机器人摔一次舵机就可能报废，前三个月一定要在地毯区训练，别一上来就下楼梯
  • 麦克风离舵机太近全是电机噪音，语音识别会崩——麦阵放头顶，舵机放身子里，中间垫一层泡棉
  • 别让它 24 小时在线监听，设个物理静音拨杆，不然你会开始防着自己家的鸭子

pollen-robotics/microduck ★ 7.6k 无中文

Pollen Robotics / Hugging Face 的开源双足小鸭机器人：RK3566 主控、15 个舵机、50Hz 控制环，走路靠 MuJoCo + PPO 训练出的 ONNX 步态策略

→ 就是市面上那只“AI 电子鸭”的开源本体，机械、电控、步态策略全开源，$399 套件可以直接买或自己打印

Microduck 是法国 Pollen Robotics 与 Hugging Face 联合推出的开源双足小鸭机器人，2026 年上半年发布，$399 的套件价和 7.6k 星让它成了“AI 电子鸭”这个品类的开源本体。它要解决的问题很直接：把一台会走路、会表达情绪的桌面机器人做到普通人买得起、打印得出、改得动，硬件图纸、电控代码和步态策略全部开源。

工作原理是“仿真里学走路，真机上跑策略”：先在 MuJoCo 里用 PPO 强化学习训练步态，用域随机化让策略容忍真实世界的摩擦和惯量差异，再把网络导出成 ONNX 放进机身的 RK3566 主控。主控以 50Hz 读 IMU 姿态、算出十五个总线舵机下一拍的目标角度；走路、蹲下、起身、抓握是一条条独立策略，由 robotd 守护进程切换。整机约 800 克、25 厘米高。

仓库自带九条已训练技能、摄像头守护进程和 Python SDK，配套 microduck_rl 开放训练环境，社区还有用大模型串技能的 quackd。文档只有英文，但 B 站和小红书上已有不少中文复刻笔记。

放进 0803 里它就是鸭子的身体：机械电控照套件来，自己要做三件事——在 microduck_rl 里加上暗门下 12cm 通道和阁楼坡道的地形重训低头慢步与前倾步态、换一个带四麦阵列和 ESP32-S3 语音板的自制头壳、写一个按反光标记巡游回窝的小状态机去调它的技能。最大的坑是摔：前三个月只在地毯区训练，舵机多备两个。

pollen-robotics/microduck_rl ★ 2k 无中文

Microduck 的官方强化学习训练环境：mjlab（MuJoCo Warp）+ PPO + 域随机化，导出 ONNX 步态策略

→ 想让它学会上阁楼那段小坡道和地堡门下的通道，得在这里加地形重新训一遍步态

microduck_rl 是 Microduck 的官方强化学习训练仓库，由 Pollen Robotics 维护，2k 星，基于 mjlab（MuJoCo Warp 的 GPU 并行仿真）加 PPO 算法，定位很明确：主仓库负责机器人的身体和运行时，这里负责教它怎么动。它解决的是双足机器人最难的一环：仿真里训出来的步态放到真机上就摔。

它的流程是：定义任务（走路、起身、踢腿、轮滑等十几种）→ 在 4096 个并行环境里用 PPO 训练，50Hz 控制频率与真机一致 → 域随机化把摩擦、质量、舵机电压、齿隙（每关节 ±1°）等参数打散，再用 BAM 舵机模型把真实电机特性搬进仿真 → 导出 ONNX，观测归一化直接烤进计算图，机身上的 robotd 加载即用。要一块 CUDA 显卡，基础步态一两个小时能训出能用的版本。代码 Apache 2.0。README 只有英文，中文只有零散的复现笔记。

在 0803 里它是鸭子学新路的地方：地堡门下 12cm 通道要一条低头慢步策略，阁楼楼梯口 15° 坡道要一条前倾爬坡策略，都得在这里新建地形、改奖励函数重训。训完先在地毯上试，摔两次再上木地板。坑是显卡：Mac mini 训不了，要么借一台带 4090 的机器，要么租几小时云 GPU 把 ONNX 拿回来。

apirrone/Open_Duck_Mini ★ 3.9k 有中文文档站

Microduck 的前身：仿迪士尼 BDX 机器人的迷你双足鸭，约 42cm 高、BOM 400 美元以内，STL 与 BOM 全开源

→ 更大更便宜的替代路线，打印件、BOM 表和舵机选型都有现成清单，还有中文文档

Open Duck Mini 是 Antoine Pirrone 发起的开源项目，目标是做一只迷你版的迪士尼 BDX 机器人，整机 BOM 控制在 400 美元以内，3.9k 星，也是 Microduck 的直接前身。它解决的问题是一个人在家能不能从零造一只会走的双足鸭，答案是能。

它的路线和 Microduck 一致但更开放：v2 版约 42cm 高，主控是树莓派 Zero 2W，舵机是 Feetech 总线舵机，仿真在 MuJoCo，训练和运行时各有配套仓库，两份训好的 ONNX 步态直接给了。所有打印件的 STL、BOM 表格、打印指南和装配说明都在仓库里，Discord 社区很活跃，近 500 个 fork。中文方面，README 链了一份社区维护的飞书中文文档，B 站有完整复刻系列。

在 0803 里它是备用路线和参考书：如果 399 美元的 Microduck 套件缺货或想要更大一只，就照它的清单自己打印和采购；更重要的是它的打印件和舵机选型经验：外壳怎么分件才好换季换羽毛、哪些舵机耐摔，都可以直接抄。注意它比 Microduck 高 17cm，钻不过 12cm 的鸭子通道，要走这条路线就得把门下净空改成 45cm 以上。

78/xiaozhi-esp32 ★ 29.6k 官方中文 README

小智：ESP32-S3 上的 MCP 语音聊天机器人，离线唤醒、接 Qwen / DeepSeek 等大模型，能通过 MCP 控制设备

→ 鸭子的嘴和耳朵直接用它：本地唤醒 + 大模型对话，MCP 那层正好接 HomeAssistant 去查全屋数据

小智（xiaozhi-esp32）是虾哥（78）发起的开源语音聊天机器人固件，跑在 ESP32-S3 上，29.6k 星，是国内最火的 AI 硬件开源项目，README 本身就是中英双语，支持 138 种开发板。它解决的问题是：用几十块钱的板子做一个能听、能说、有表情的 AI 伙伴，而且能控制真实设备。

它的链路是：麦克风阵列采音 → ESP-SR 离线唤醒词和回声消除 → 音频经 WebSocket 或 MQTT+UDP 送到服务端 → 服务端做语音识别、接 Qwen / DeepSeek 等大模型、合成语音 → 语音回到板子播放。关键是 MCP：设备端 MCP 把喇叭、LED、舵机、GPIO 暴露成工具让大模型调用，云端 MCP 又能接外部服务。默认连 xiaozhi.me，也可以自建服务端，中文教程遍地都是。

在 0803 里它是鸭子的嘴和耳朵：头壳里塞一块 ESP32-S3 加四麦板，胸口 1.28 寸圆屏就是它的表情屏，两颗 RGB 眼睛用设备端 MCP 暴露给大模型控制情绪。全屋数据问答走自建服务端上的 MCP 客户端接 HomeAssistant 的 MCP Server，问雨水罐就去查实体；随口一句记得买 M3 螺丝写进 HA 的待办实体再同步到 0801。注意麦阵放头顶、舵机放身子、中间垫泡棉，否则电机噪音会把识别率打穿；再加一个物理静音拨杆。
