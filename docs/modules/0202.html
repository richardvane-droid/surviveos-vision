地堡 · 模块 0202 · 卫生间灯箱系统

无窗卫生间怎么活？我把整个天花板做成了一块天空

1000W 灯箱 + 六面镜光箱，无窗小间里刷牙也像在露台上晒晨光。

✅ 真实三阶段已完成 #无窗卫生间#酒店感#去家务化#晨间仪式感

📐 它在哪、有多大

地堡东北角的卫生间，≈1.65×1.25m、≈2㎡，北墙和东墙都是外墙但无窗；灯箱嵌在这块小天花板正中，门开向沙发北侧那条走道，南邻储藏室（0210）。

🎬 沉浸式想象

七点整，你推开卫生间的门，天花板那块 1m 见方的灯箱已经提前 5 分钟亮到了“晨浴”档——不是浴霸那种惨白，是被镜面反复弹过之后的软光，从头顶、从两侧镜墙一起包过来，脸上没有一点阴影。淋浴间的雾气往上飘，被光一打像一团发亮的云。你伸手摸墙，暖的——排风在后面轻轻转，镜子一点都不起雾。刷牙的时候你看着镜子里的自己，皮肤居然是有血色的。这个瞬间你会忘了这间 2 平米的小房间连窗都没有。

✅ 设想方案清单

  1. ≈2㎡ 的小卫生间天花板几乎整块嵌 1.0×1.0m 灯箱：1000W 浴霸灯 + 亚克力柔光板，四周留 5cm 出光缝当“天光缝”
  2. 洗手台三面镜 + 顶面镜 + 两侧壁镜，做成六面镜光箱，光被弹到没有死角
  3. 灯箱分三档：晨浴 5000K 全亮 / 日常 4000K 60% / 夜起 2200K 5%，人体感应自动切
  4. 一层原有下水口位置定死，淋浴、洗手盆和 0203 冷凝水都汇到一台小提升泵再进下水，泵藏在马桶后的检修柜里，柜门做磁吸镜面，检修时一拉就开
  5. 镜子背面贴电热除雾膜，跟灯箱联动，开晨浴档就同步加热
  6. 淋浴角顶上再做一块 40×40 小灯箱，跟主灯箱同步，洗澡时头顶也是亮的
  7. 排风扇接湿度传感器，湿度 70% 以上自动开，20 分钟后自动停

🔥 小红书灵感点

  • “去家务化卫生间”：全部壁挂、零地面杂物，灯光一亮地面干干净净很出片
  • “酒店感洗漱台”：两边镜子加暖光灯带，小红书爆款的“化妆间光线”直接搬过来
  • “晨间仪式感 vlog”：灯箱亮起来的那 5 秒可以当每天的开场镜头

⚠️ 避坑提醒

  • 1000W 灯箱很热，亚克力板要留散热缝，不然夏天变蒸笼
  • 六面镜好看但清洁量翻倍，水渍一多就变“脏光箱”，除雾膜一定要装
  • 污水提升泵一定留检修口和报警，堵了不是小事
