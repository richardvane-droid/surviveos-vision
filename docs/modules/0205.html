地堡 · 模块 0205 · 生态鱼缸

木屋吧台上那口 80 公分的生态缸，是隔壁地堡借来的“窗”

坐在吧台台面上的生态缸，不用换水，隔着一道墙给无窗地堡当活风景。

⬜ 真实项目待设计 #生态缸#吧台鱼缸#和植物一起住#精神角落#自然生活

📐 它在哪、有多大

缸体不在地堡：它坐在隔墙木屋一侧的北墙吧台台面上（吧台矮柜 900 高，缸在台面东段、照片墙正下方，≈80cm 宽），过滤桶和补水泵藏在台面下的矮柜里；只有探头数据线穿过隔墙接进地堡的 0802 大屏。

🎬 沉浸式想象

你从地堡的暗门钻进木屋，第一眼看到的不是柴火炉，是吧台东头那块发着绿光的长方形。80 公分的缸坐在 900 高的吧台台面上，上方是照片墙，左边挨着咖啡机，边框做成老式窗框，水草在缸里像被风吹过的草地一样慢慢摆，一群宝莲灯从莫斯石后面钻出来又钻回去。台面下矮柜里的过滤在“呼吸”，气泡一串串往上冒，声音比任何白噪音都好听。晚上关掉木屋大灯，只剩缸里那盏水草灯，整面北墙都是淡绿的波纹。你坐在吧台凳上看了半小时，什么也没想。

✅ 设想方案清单

  1. 800×400×500mm 超白缸坐在木屋北墙吧台台面东段（隔墙木屋侧，0008 给的位置），前面做旧木窗框收边
  2. 水陆缸布景：左边沉木上长苔藓和蕨类，水里铺莫斯石和矮珍珠，做一小片“水下草原”
  3. 养 20 条宝莲灯 + 几只黑壳虾 + 一条小清道夫，鱼小密度低，生态自己转
  4. 过滤桶和补水泵藏在台面下 900 高的吧台矮柜里，自动补水接 0603 雨水系统过滤后的软水
  5. 水草灯用 ESPHome 控制日出日落曲线，跟隔壁地堡的 0201 模拟阳光同一份时间表
  6. 缸角装温度 / pH / TDS 三探头，数据线穿隔墙汇到地堡的 0802 大屏，异常推送
  7. 吧台前放一张高脚凳，专门用来“发呆”

🔥 小红书灵感点

  • “吧台鱼缸当风景”：小红书上很多人把小缸放在吧台或书桌一角，比手机更耐看
  • “水陆缸/雨林缸”热潮：缸上半截养苔藓和小蕨，木屋吧台边的湿度反而是加分项
  • “精神角落”：缸前一张高脚凳一盏灯，这是木屋里最不“生存”的角落

⚠️ 避坑提醒

  • 80 公分缸满水也有 160kg 上下，吧台矮柜的台面和柜体先加固，别信“台面挺结实”
  • 手提水桶换水麻烦，自动补水和溢流一定做，不然每周提水桶会想放弃
  • 水草灯太亮长绿藻，前两个月别贪亮，慢慢往上调

Seeed-Studio/grove.py ★ 166 无中文

Seeed 官方的 Grove 模块 Python 库：在树莓派这类嵌入式 Linux 上用几行代码读写 Grove 的 I2C、模拟、数字和 PWM 接口模块

→ 0805 把全屋 DIY 器件基准定在 XIAO 加 Grove，这是 Grove 在 Linux 侧的官方读法；鱼缸三探头先在树莓派上用它调通标定

grove.py 是矽递科技官方维护的 Python 库，给出的是 Grove 生态在嵌入式 Linux 上的读法。Grove 是 Seeed 那套统一的四线接口，一根扣线把模块接到底板，不用面包板也不用焊接；这个库把每一种 Grove 模块封成一个类，树莓派或者 Jetson 上装好之后，几行代码就能拿到读数。

底层它把 I2C、模拟、数字和 PWM 四类接口抽成统一的 adc 与 gpio 封装，上层再按模块分文件：温湿度、光照、TDS、超声测距、继电器、OLED 屏各一个类，每个文件都能单独运行当自测程序。安装只要一条 pip 命令，仓库里附了每个模块的接线图和示例输出，调不通的时候先跑官方示例，就能分清是硬件问题还是代码问题。

说明只有英文，但 Seeed Wiki 上每个 Grove 模块都有中文页，接线图一致。仓库更新不快，胜在稳定，是 Grove 模块在 Linux 侧事实上的标准库。

生态缸这边它管两件事。一是调探头：温度、pH、TDS 三路先接在树莓派上，用它的示例把读数跑通、做出标定曲线，确认量程和采样间隔之后，再把同样的读法搬到吧台矮柜里那块 XIAO ESP32C6 的 ESPHome 配置。二是补 reef-pi：reef-pi 本身跑在树莓派上，缺的模块用这个库写成脚本挂上去就行。坑是 pH 电极信号极弱，走线要离水泵电源线远一点。

esphome/esphome ★ 11.7k 无中文（社区教程多）

用 YAML 配置 ESP32 / ESP8266 传感器和控制器并接入 HomeAssistant 的系统，Nabu Casa 官方维护

→ 水草灯的日出日落 PWM 曲线、补水阀、探头盒全跑在一块 ESPHome 板上，数据线穿隔墙进 0802 大屏

ESPHome 是 2018 年由 Otto Winter 发起、现由 Home Assistant 母公司 Nabu Casa 维护的开源项目，11.7k 星。它让一块 ESP32 读传感器、控继电器并接进家庭自动化这件事不再需要写代码：一份 YAML 声明“接了一颗温度探头、一路 PWM 灯、一个继电器”，它就自动生成固件、编译并无线刷写。

流程是在 HA 的 ESPHome 插件里写 YAML，编译推到板子，板子用原生 API 和 HA 直连，每个传感器、开关、灯自动变成实体。内置上千个组件，从 DS18B20 水温探头、ADC 模拟量、PWM 输出，到 time 定时触发、阈值判断、滑动平均滤波，都是本地逻辑，断网照跑。生态是 ESP 圈最大的，每月一版；官方文档只有英文，中文教程和视频极多。

在 0205 里它是鱼缸的整个控制层，一块 ESP32 就够：水草灯接 PWM 输出，用 time 触发器每天按时间表跑一条日出日落曲线，时间表直接引用 0201 模拟阳光那份，缸和地堡同一个太阳；补水阀用继电器，液位浮子低了就开、满了就关，阈值在板上本地判断；温度、pH、TDS 三探头的读数每分钟报给 HA，数据线穿隔墙进 0802 大屏。坑是 pH 和 TDS 探头都怕互相干扰，两颗探头不能共地，要用隔离模块或分时供电；板子放在吧台矮柜里要防潮，探头线走缸角一根 PVC 管进水。

reef-pi/reef-pi ★ 435 无中文

基于树莓派的开源水族箱控制器，管灯光日出日落、温控、pH、滴定、自动补水和定时器，带网页仪表盘

→ 自动补水、溢流保护和水草灯日出日落曲线都有现成模块，它的事件表设计直接拿来当 ESPHome 时间表的蓝本

reef-pi 是印度裔工程师 Ranjib Dey 从 2017 年开始写的开源水族箱控制器，435 星，是 GitHub 上最完整、维护最久的 DIY 鱼缸控制器，原本面向海水珊瑚缸，淡水草缸同样适用。商业鱼缸控制器动辄几千块还绑 App，它用一块树莓派加几块扩展板做出同样的东西。

它用 Go 语言写后端、React 写网页前端，跑在树莓派上，把功能拆成一个个模块：温度模块读 DS18B20 并控加热棒和风扇；灯光模块给 PWM 驱动板输出一条 24 小时曲线，做日出日落；ATO 自动补水模块读浮子开关控补水泵，带超时保护防止泵空转；pH 模块读探头做记录和报警；滴定模块控蠕动泵；定时器模块按 cron 开关任何设备；还有摄像头拍照和邮件推送。所有模块共用一套“输入 / 输出 / 任务”抽象。2022 年 6.0 版加了 ESP32 作为远程 IO 的支持。文档英文，中文资料少。

在 0205 里，它有两种用法。轻量用法是当蓝本：照它的灯光曲线、ATO 超时保护和定时器设计，用 ESPHome 在一块 ESP32 上复刻，省掉一台树莓派。重量用法是直接跑一台：吧台矮柜里放一块树莓派 Zero 2 和它的 PWM 板，缸的所有东西归它管，再通过 MQTT 把状态交给 HA。坑是它的 ATO 一定要设最大补水时长，浮子卡住时不至于把 0603 的雨水全抽进缸里。

TheRealFalseReality/aquapi ★ 97 无中文

基于 ESPHome 和 HomeAssistant 的开源鱼缸监测与自动化控制器，用 Atlas Scientific EZO 探头测 pH、EC、温度，2026 年仍在更新

→ 温度、pH、TDS 三探头的接法和 ESPHome 配置直接照抄，数据天然进 0802 大屏；星少但它就是这个需求的唯一现成答案

AquaPi 是美国鱼友 TheRealFalseReality 做的开源鱼缸监测器，97 星，口号是“鱼缸遇上智能家居”。它没有自己写软件，而是把 ESPHome 和 Home Assistant 直接当鱼缸控制器用：一块 ESP32、几颗探头、一份 YAML，鱼缸数据就出现在 HA 里。它是把“ESPHome 做鱼缸”走得最完整的项目，2026 年 6 月还在发新版，鱼友论坛上有人卖它的成品板。

硬件上它围绕 Atlas Scientific 的 EZO 探头电路：pH、电导率（换算 TDS）、溶氧、ORP、RTD 水温都是 I2C 接口的小模块，ESPHome 有原生的 ezo 组件，YAML 里几行就能读；再加 DS18B20 水温、红外液位传感器和漏水传感器。探头校准做成了 HA 里的按钮。仓库有接线图、外壳打印件和完整 YAML，文档英文。

在 0205 里它就是缸角那个探头盒：温度、pH、TDS 三颗探头照它的接法接在一块 ESP32 上，YAML 直接抄再删掉用不上的溶氧和 ORP，校准按钮保留；数据线穿隔墙接进 0802 大屏，pH 或 TDS 一小时内变化超过阈值就用 HA 的 statistics 传感器触发推送。坑是 EZO 电路一颗一两百块，想省钱可用国产 pH 模块但校准要自己做；探头 BNC 头怕潮，盒子留在水面以上。

opencv/opencv ★ 89.3k 无中文（社区教程多） 延伸

计算机视觉的标准库：图像处理、特征检测、目标跟踪、相机标定、DNN 推理，C++ 核心带 Python 绑定

→ 缸角三探头只知道水好不好，不知道鱼好不好；一个摄像头加 OpenCV 数宝莲灯还剩几条、有没有趴缸，是最直接的鱼况传感器

OpenCV 是英特尔在 1999 年发起、现在由 OpenCV 基金会维护的计算机视觉库，89.3k 星，2026 年发布了 5.0，几乎所有做视觉的人都从它开始。它要解决的问题是：把图像当成矩阵来处理的那些基础算法——滤波、阈值、边缘、轮廓、光流、特征点、相机标定——不该每个人重写一遍。

它的核心用 C++ 写，Python 绑定 cv2 是最常用的入口：读一帧图像成 NumPy 数组，一路函数调用下去，比如高斯模糊去噪、转 HSV 按颜色阈值分割、findContours 找轮廓、按面积过滤得到目标、再用背景减除或光流跟踪运动。DNN 模块能直接加载 ONNX 和 TensorFlow 模型做检测和分类，VideoCapture 读摄像头和 RTSP 流。它跑在树莓派、手机、桌面和 GPU 上，2025 年后每几个月一个版本。

生态是视觉界最大的，README 是英文，但中文书、教程和课程数量惊人，国内高校课程几乎都用它。

对 0205 它是延伸里最有意思的一个玩法：缸前上方架一个小摄像头对着缸体，树莓派上跑一段几十行的 Python：背景减除分出游动的鱼，按宝莲灯那条蓝红色带的 HSV 范围过滤，轮廓计数得到当前可见鱼数，连续几分钟计数明显下降或某个轮廓长时间不动就推送到 0802 大屏提醒查看。同一个摄像头还能做延时摄影记录水草长势，配合水草灯的日出日落曲线定时抓拍。注意缸壁反光和水面波纹会干扰，摄像头加偏振镜、抓拍时机避开补水泵工作。

micropython/micropython ★ 22.1k 无中文（社区教程多） 延伸

跑在单片机上的精简 Python：ESP32、树莓派 Pico、STM32 都支持，REPL 交互式改代码，机器控制不用编译

→ 鱼缸的补水、喂食、灯光曲线这类小逻辑，用 MicroPython 在 ESP32 上边试边改，比每次改 ESPHome YAML 重新刷固件快得多

MicroPython 是 Damien George 在 2013 年通过 Kickstarter 发起的项目，22.1k 星，把 Python 3 的核心语法和标准库压缩到几百 KB，跑在只有几十 KB 内存的单片机上。它要解决的问题是：单片机开发长期只有 C，改一行要编译、烧录、重启；它让人在串口里直接敲 Python，立刻看到结果。

它的工作方式是：固件刷进 ESP32、树莓派 Pico 或 STM32 之后，芯片上跑一个 Python 解释器，串口连上就是 REPL，脚本以文件形式存在芯片的小文件系统里，开机自动跑 main.py。machine 模块管 GPIO、PWM、I2C，network 管 Wi-Fi，还有 asyncio 和 umqtt，一次改动几秒钟就生效。

生态很大，2025 年后仍是每几个月一个版本，README 英文，但中文教程、B 站课程和国产开发板的 MicroPython 文档非常多。

对 0205 它是延伸的原型工具：鱼缸矮柜里那块管补水泵、喂食器和水草灯 PWM 的 ESP32，正式版走 ESPHome 接 HomeAssistant，但在调试阶段用 MicroPython 更快——补水泵该抽几秒、喂食器舵机转多少度、日出曲线的 gamma 值，在 REPL 里改一个数立刻看效果，调顺了再把参数抄进 ESPHome 的 YAML。注意 MicroPython 和 ESPHome 不能同时在一块芯片上，多备一块 ESP32 专门做实验。
