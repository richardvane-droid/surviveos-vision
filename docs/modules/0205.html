地堡 · 模块 0205 · 生态鱼缸

地堡唯一的“窗”是一缸水草和三十条灯鱼

嵌进墙里的 1.2 米生态缸，不用换水，是地下室的活风景。

⬜ 真实项目待设计 #生态缸#嵌墙鱼缸#和植物一起住#精神角落#自然生活

🎬 沉浸式想象

你从楼梯下来，第一眼看到的不是灯，是墙上那块发着绿光的长方形。1.2 米的缸嵌在沙发对面的墙里，边框做成老式窗框，水草在缸里像被风吹过的草地一样慢慢摆，一群宝莲灯从莫斯石后面钻出来又钻回去。缸底的过滤在“呼吸”，气泡一串串往上冒，声音比任何白噪音都好听。晚上关掉大灯，只剩缸里那盏水草灯，整个地堡的墙都是淡绿的波纹。你坐在沙发上看了半小时，什么也没想。

✅ 设想方案清单

  1. 1200×450×500mm 超白缸嵌进沙发对面的墙，背面留 60cm 检修通道，前面做旧木窗框
  2. 水陆缸布景：左边沉木上长苔藓和蕨类，水里铺莫斯石和矮珍珠，做一小片“水下草原”
  3. 养 30 条宝莲灯 + 几只黑壳虾 + 一条清道夫，鱼小密度低，生态自己转
  4. 底滤 + 外置过滤双保险，自动补水接 0603 雨水系统过滤后的软水
  5. 水草灯用 ESPHome 控制日出日落曲线，跟 0201 模拟阳光同一份时间表
  6. 缸外装温度 / pH / TDS 三探头，数据汇到 0211 大屏，异常推送
  7. 缸前放一张单人小凳，专门用来“发呆”

🔥 小红书灵感点

  • “嵌墙鱼缸当电视”：小红书上很多人把缸嵌在沙发对面，比电视更耐看
  • “水陆缸/雨林缸”热潮：缸上半截养苔藓和小蕨，地堡的湿度反而是加分项
  • “精神角落”：缸前一张小凳一盏灯，这是地堡里最不“生存”的角落

⚠️ 避坑提醒

  • 1.2 米缸满水近 300kg，嵌墙前一定加固底座，别信“墙挺结实”
  • 地下换水麻烦，自动补水和溢流一定做，不然每周提水桶会想放弃
  • 水草灯太亮长绿藻，前两个月别贪亮，慢慢往上调
