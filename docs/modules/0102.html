🎬 沉浸式想象

傍晚五点，光从南墙的窗斜进来，正好打在北墙这块九宫格上。底板是整块的老松木，上面钉了 3×3 九个原木方格，每格 43 厘米见方，格里放两只 PSK 生存盒，从左上到右下是 2019 年第一版那只用月饼铁盒改的，到今年这只带了太阳能片的第七代。每只盒子下面挂一张手写的小牛皮纸标签：型号、年份、去过哪座山。你一路看过去，能看到我什么时候学会了激光切割、什么时候开始用钛合金。右下角那格故意空着两个位置，标签上写着：下一代，还在想。九宫格右边就是梯子床的梯子，最上一级也搁着一只。

✅ 设想方案清单

  1. 北墙作品区 1.35m 见方，底板用 18mm 老松木拼板，板之间留 3mm 缝隙，上沿贴着梁底 2400 往下排
  2. 3×3 九个原木方格，每格约 43cm 见方、15cm 深，每格两位，前缘做一道小凸边防盒子滑落
  3. 每只盒子下方挂 6×9cm 牛皮纸标签，手写型号年份，用小铜钉固定
  4. 每排格子上沿藏一条 2700K 灯带，斜向下打，盒子有阴影才有体积感
  5. 第一版、第四版、第七版三只关键作品用小射灯单独加光
  6. 九宫格右边就是梯子床的梯子，最上一级也放一只盒子，把展示往上延伸到床板
  7. 右下角预留两个空位，标签写下一代待定，自己每次看到都会催自己进度

  • 小红书收藏墙风：Switch 卡带墙、香水墙都是这个套路，我的是生存盒九宫格

⚠️ 避坑提醒

  • 灯带别正面打，正面打盒子是平的，斜上 30 度才有阴影
  • 格子别做太浅，10cm 深的格放 12cm 盒子，去年掉下来一只
  • 标签别用打印的，手写才有博物馆那种被人认真对待的感觉

wled/WLED ★ 18.7k 无中文

ESP32 控制可寻址灯带的开源固件，手机网页调色调亮度、存预设、本地定时，可接 HomeAssistant

→ 九宫格每排上沿那条 2700K 藏光灯带就刷它，一块 ESP32 管三段，预设与定时本地跑，HA 只负责按太阳高度切

WLED 是德国开发者 Aircoookie 在 2016 年发起的灯带固件，现在由 wled 组织维护，18.6k 星，2026 年 5 月发布了 v16，是 ESP32 控制可寻址 LED 的事实标准。它让一段 WS2812 灯带不写代码就能在手机上调色、调亮度、存预设、定时开关，还能被智能家居当成一盏灯。

工作原理是把 ESP32 变成一个自带网页的灯控器：固件刷进去后设备开热点，填好 Wi-Fi 用浏览器打开它的地址，页面上是调色盘、一百八十多种特效、分段控制和预设槽位。灯带数据从 GPIO 直接驱动，支持 WS281x、SK6812、APA102，也支持 PWM 白光和双色温灯带，一块板可以分多个段各自控制。对外提供 JSON API、MQTT 和 DDP、E1.31 实时协议，Home Assistant 有官方集成，插电即自动发现。

生态极大，成品控制器多围绕它转。官方文档只有英文，但 B 站和小红书上的教程非常多。

放进 0102，一块 ESP32 接三段 2700K 暖白灯带，藏在九宫格每排格子上沿，斜向下打；三段分别设成三个 segment，预设一是傍晚 40% 暖光，预设二是夜里 15%，本地定时器兜底；HA 用 sun.sun 的高度角触发切预设，同时单独控三只小射灯。坑在灯带要选高显色的暖白型号而不是 RGB 拼白，否则老松木会发绿。

benjaminjonard/koillection ★ 1.3k 界面有中文

自托管的个人收藏管理系统，任意物件都能建档、配图、写自定义字段，按收藏、条目、标签三层组织

→ 七代 PSK 盒子的档案库：每只盒子一条记录，字段记型号、年份、去过哪座山、格位号，导出来直接印牛皮纸标签

Koillection 是法国开发者 Benjamin Jonard 从 2017 年起维护的自托管收藏管理系统，1.3k 星，2026 年仍在发版，专为收藏党而不是仓库管理设计：书、邮票、模型、任何你想摆出来的东西都能建档。它解决的问题是：藏品越攒越多，哪只是哪年做的、去过哪里、现在摆在哪个格子，靠脑子记不住。

它是 Symfony 写的网页应用，Docker 起一个容器加 PostgreSQL 就能跑。数据分三层：收藏、条目、数据点，每个条目可以挂多张图片、任意数量的自定义字段，字段类型包括文本、日期、数字、评分、链接、文件，还能定义模板让同一收藏里的条目字段一致。自带标签、愿望清单、相册和统计页，可以做公开分享页给别人看。

界面有简体中文，通过 Crowdin 社区翻译已经百分之百，README 里直接列出，装完选语言就是中文；文档是英文。API 是标准 REST，能用脚本批量导出。

放进 0102，建一个 PSK 收藏，用模板定好字段：型号、年份、盒身材质、去过哪座山、格位号、在墙上还是在抽屉里。每次做出新一代盒子就拍照录一条；牛皮纸标签的文字从条目字段导出，套一个模板打印；右下角那两个空位也各建一条，字段写待定，催自己进度。注意图片上传要在 Docker 里设好持久卷，否则更新容器时照片会丢。

home-assistant/core ★ 88k 有中文文档站

本地优先、隐私优先的开源家庭自动化中枢，几千个集成，自动化引擎、仪表盘和手机 App 一体

→ 九宫格灯带和三只关键作品射灯的傍晚亮灯调度全在它里做：sun.sun 高度角触发，切 WLED 预设，再顺手拉低射灯

Home Assistant 是 Paulus Schoutsen 在 2013 年发起、如今由 Nabu Casa 与 Open Home 基金会维护的开源家庭自动化中枢，88k 星，是 GitHub 上最活跃的项目之一，每月发一个大版本。它解决的问题是：家里各种品牌的灯、传感器、插座各自为政，需要一个本地跑、不依赖云、能把它们串起来写规则的大脑。

架构是 Python 写的事件总线：每个集成把设备抽象成实体，状态变化都变成事件进总线，自动化引擎监听触发条件、判断条件、执行动作，历史数据存在本地数据库。它有两千多个官方集成，ESPHome、WLED、MQTT、Zigbee、Matter 都原生支持；仪表盘用 Lovelace 卡片拼，手机 App 能推送和定位，还带 Assist 本地语音助手。

社区规模全球第一，中文文档站 home-assistant.io 有官方翻译，界面本身也有简体中文，B 站教程数不胜数，国内玩家常和小米、华为设备一起用。

放进 0102，它负责调度而不是驱动：一条自动化以 sun.sun 的高度角低于 3 度为触发，动作是调用 WLED 集成把灯带切到傍晚预设，再把第一版、第四版、第七版那三只小射灯调到 60%；晚上十一点另一条自动化全部关掉；周末下午两点如果有人在木屋，再亮一次给拍照用。坑在太阳高度角在冬天下降得早，条件里加一个当前照度判断更稳。

延伸阅读 借这个模块顺手学一遍的热门项目

和本模块的关系没上面那么直接，但都是 GitHub 上值得整个看一遍的经典项目；每条最后一段写了在这里能怎么用。

AppFlowy-IO/AppFlowy ★ 75.4k 界面有中文 延伸

Flutter + Rust 写的开源 Notion 替代：文档、数据库表格、看板、日历，数据本地优先，可自托管云同步

→ 九宫格里每只盒子都值得一页出生故事：型号、年份、去过哪座山、当时的草图，AppFlowy 的数据库视图正好一行一只盒子

AppFlowy 是 AppFlowy-IO 团队做的开源协作工作区，目标很直白：做一个数据归自己管的 Notion。75.4k 星，是同类项目里星数最高的一个。它要解决的问题是：Notion 好用但所有笔记都在别人的云上，断网不能用，还随时可能改价。

它的架构是 Flutter 写界面、Rust 写核心，一套代码跑 macOS、Windows、Linux、iOS 和 Android。数据默认存在本地 SQLite 里，文档用块编辑器，数据库（Grid）像一张有类型的表格，同一份数据可以切成表格、看板、日历三种视图，属性支持文本、数字、单选、日期、复选框和关联。想多设备同步就自托管 AppFlowy Cloud（Docker Compose 一键起），也可以只用本地。2024 年后加了 AI 助手，可以接本地 Ollama 模型。

生态和社区：界面自带简体中文，Discord 和 GitHub 讨论区活跃，中文圈的评测和安装教程不少，2025 年后仍是几周一个版本。

放到 0102 里它是延伸项目：作品墙的每只盒子下面挂的牛皮纸标签只写得下型号和年份，而更完整的出生故事应该在一个数据库里。在 AppFlowy 建一张 PSK 作品表，一行一只盒子，列是版本号、年份、盒身材料、去过的山、当时的草图照片、当时犯的错，用日历视图看就是一条时间线。标签上印一个小二维码指向这一页，自己看到右下角那两个空位时，把下一代的想法也先记进去。注意别开太多字段，能坚持每代填完最重要。

TriliumNext/Trilium ★ 37.8k 官方中文 README 延伸

层级笔记树式的个人知识库：一条笔记可以挂在多个父节点下，带关系图、脚本能力和自托管服务端同步

→ PSK 的知识不是平的：一只盒子挂在年份下也挂在材料下，还连着某座山的日记，Trilium 的多父节点树正对这种交叉关系

Trilium Notes 最早由捷克开发者 zadam 做了六年，2024 年他退出维护后社区接手成立 TriliumNext，2025 年 6 月仓库正式改名为 TriliumNext/Trilium 继续开发，37.8k 星。它要解决的问题是：普通笔记软件是文件夹或标签，而真实知识是一张网，一条笔记常常同时属于好几个主题。

它的核心是一棵可以克隆的笔记树：任何笔记可以出现在多个父节点下，本质上是同一条记录的多个引用；笔记之间还能定义关系和属性，自动生成关系图。编辑器是富文本加代码块、Markdown 导入导出、画布、思维导图和网页剪藏。它内置脚本引擎，可以用 JavaScript 写自动化和小工具，服务端用 Node.js 写，Docker 一行起，桌面端用 Electron，手机用网页版，同步走自己的服务器，全程加密可选。

社区方面它是少数 README 自带简体中文和繁体中文的知识库项目，中文用户很多，Docker 部署教程遍地。

放到 0102 里它是延伸的另一条路线：如果说 AppFlowy 适合做一张干净的作品表，Trilium 适合把整个 PSK 七年的东西全塞进去——每一代盒子一条笔记，克隆到年份树、材料树和山的树下；每次上山的日记、供应商报价、失败的样品照都挂在旁边，关系图一拉就看到第四版为什么换钛合金。作品墙标签上的二维码也可以指向这里。注意它是给一个人用的深度工具，学习曲线比 AppFlowy 陡，先只用树和克隆两个功能就够了。
