阁楼间 · 模块 0301 · 小制作工具台

谁懂啊！阁楼最高处 1.9 米的小工具台，站着坐着都不撞头

阁楼可站立区的北缘，塞进一张只做小东西的工作台，每天拧两颗螺丝就很治愈。

⬜ 真实项目待设计 #动手主义#精神角落#洞洞板#斜顶阁楼#DIY

🎬 沉浸式想象

周日下午三点，天窗斜斜地把一块亮光扔在台面上。你坐在高脚凳上，身后是帐篷，头顶正好是阁楼最高的 2 米 06，往西看斜顶一路矮下去，反而有种被包住的安全感。台面是 1.88 米长的松木板，左边一排洞洞板挂着六把螺丝刀、一把小台钳、一卷 3M 胶带，右边是一盏可以掰来掰去的臂灯。桌角那台小小的桌面 CNC 正在嗡嗡地刻一块亚克力，铝屑闪闪的。你手里是给 PSK 盒子做的新扣件，第 4 版，这次终于卡得“咔哒”一声。楼下木屋的柴火味顺着楼梯飘上来，阁楼里只有电烙铁加热时的一点点松香。

✅ 设想方案清单

  1. 在可站立核心区北缘做一张 188×84cm 的松木台面，高 85cm，站着坐高脚凳都行，头顶正好是 2060 最高点
  2. 台面后方钉整面洞洞板，按“拆-量-切-焊”四类挂工具，用完必须归位，拍照存档
  3. 标配一台桌面 CNC 雕刻机 + 一台 60W 数显电烙铁 + 台钳，够做 PSK 小扣件和标牌
  4. 臂灯装 HomeAssistant 智能插座，坐下自动亮，离开 10 分钟自动断电防烙铁忘关
  5. 台面下方做两层浅抽屉，一层分格放螺丝钉配件，一层放砂纸和刀片
  6. 工作台边留一个 5 升的碎屑桶，桌面 CNC 装个小吸尘接口，木屑不落地
  7. 头顶平顶上装一根轨道灯，冬天补光，夏天下午天窗的光就够用

Ralim/IronOS ★ 8.3k 界面有中文

Pinecil、TS100 等便携电烙铁的开源固件，带自动休眠、动作唤醒和 USB-PD 供电协商

→ 买 Pinecil 那类烙铁刷它，放下几十秒自动降温休眠，正好解决“阁楼木头多怕忘关”的心病，还能用 0304 的储能直接供电

IronOS 是 Ben V. Brown（Ralim）从 2016 年起维护的便携电烙铁开源固件，最初为 TS100 写，后来成了 Pinecil、TS80P、MHP30 等一整批 USB 供电烙铁的事实标准，8.3k 星，2025 年 8 月还在发 v2.23。它解决的是原厂固件功能少、温控糙、不能休眠的问题，也是 Pinecil 出厂就预装的固件。

它的原理是把烙铁头当成一个带热电偶的加热丝：固件以毫秒级读取热电偶电压和手柄温度算出头温，用 PID 驱动 MOSFET 调功率；手柄里的加速度计一直在算动作量，静止超过设定秒数就把温度降到休眠档，再过一段时间直接关加热，拿起来一晃立刻回温。供电一侧它会跟 USB-PD 或 QC 充电头协商到 20V 以上，也能吃 DC 桶插头的 12～24V。

生态上它支持 31 种语言，简体中文是其中之一，菜单、校准提示全是中文；文档站和 B 站教程很多，刷写用 USB 拖拽或 blisp 工具就行。

在 0301 里它是“烙铁双保险”的第一层：烙铁本体刷它，休眠 30 秒、关机 5 分钟；第二层是 HA 智能插座按毫米波无人 10 分钟断电。供电可以直接接 0304 储能的 PD 口，不占市电排插。坑是 Pinecil 的 DC 口不能超 24V，接备用电池要经过降压。

kennetek/gridfinity-rebuilt-openscad ★ 2.2k 无中文

用 OpenSCAD 重写的 Gridfinity 收纳盒与底板参数化生成器，尺寸、分格、磁吸孔随便改

→ 台面下两层浅抽屉的螺丝钉分格盒直接用它生成，交给 0305 的打印机打，格子想多大就多大，全屋统一 42mm 模数

Gridfinity 是 Zack Freedman 在 2022 年提出的开放收纳标准：42mm 见方的网格底板加上底部带斜角的模块盒，任何盒子都能在任何底板上卡住。kennetek 这个仓库是用 OpenSCAD 从零重写的参数化生成器，2.2k 星，是这个体系里最常被引用的代码实现，解决的是官方模型尺寸固定、而自家抽屉永远是奇怪尺寸的问题。

工作方式很朴素：在 .scad 文件顶部改几个变量——网格数 gridx、gridy、高度 gridz、分格数、要不要磁铁孔和螺丝孔、标签条样式、底板类型——OpenSCAD 就实时生成实体，导出 STL 交给切片软件。库里分成盒、底板、省料薄壁的 lite 版和单壁花瓶模式几个模块。

它是 Gridfinity 社区的公共底层，自定义器界面不写代码直接拖滑块，Printables 上成千上万的衍生件多数基于它。文档只有英文，但参数名一目了然，B 站有中文教程。

在 0301 里它服务台面下那两层浅抽屉：先量抽屉内净尺寸，算出能放几乘几的网格，打一张底板铺进去，再按 M3、M4、木螺钉、扎带各生成一格；砂纸和刀片那层用 lite 版薄壁长盒。所有件送到 0305 那台自建的 Voron 打印，和 0401 抽屉柜用同一套模数。注意底板要留 0.5mm 余量，木抽屉冬夏会缩胀。

Denvi/Candle ★ 1.7k 无中文

GRBL 桌面 CNC 的开源上位机，Qt 写的，带 G 代码三维可视化和高度图补偿

→ 桌面小 CNC 大多是 GRBL 控制板，用它发刻小扣件和木牌的 G 代码，比机器自带软件顺手，高度图能补薄亚克力的翘曲

Candle 是俄罗斯开发者 Denvi 用 Qt 和 C++ 写的 GRBL 上位机，1.7k 星，2026 年 2 月刚发 11.2 版，Windows、Linux、macOS 和树莓派都能跑。桌面 CNC 雕刻机（3018、1610 这类）几乎清一色用 GRBL 固件，而 GRBL 本身只是一块听串口指令的板子，Candle 就是坐在电脑这头给它喂 G 代码、看它走到哪的那个软件。

工作流是：打开 CAM 软件导出的 .nc 文件，Candle 先在三维视图里把整条刀路画出来，你用手动面板把主轴移到工件角上设零点，然后按运行。运行时它逐行往串口送指令、实时回读机器坐标，高亮走过的路径，显示进度和预计时间；出问题随时暂停、单步、复位。最有用的是高度图：先让探针在工件表面扫一遍网格，再把 G 代码按这张图整体变形，薄板不平也能刻出均匀深度，做 PCB 和刻 2mm 亚克力尤其关键。

它还支持自定义按钮、控制台直发 GRBL 命令、转速和进给的实时倍率。文档是英文，但界面简单，国内 3018 圈子基本人人在用，中文教程多。

在 0301 里它是桌面 CNC 工位的操作台：工具台旁一台旧笔记本或树莓派跑它，扣件和标牌的刀路从 0204 设计工作台用 FreeCAD 出，铝屑吸尘接口随主轴启动。注意它不做刀路生成，也不支持第四轴，复杂件去 0307。

platformio/platformio-core ★ 9.3k 无中文 延伸

跨平台的嵌入式开发工具链：一个 platformio.ini 管住板子、框架、库依赖和烧录，VS Code 插件一键编译上传

→ 工具台上要给 PSK 盒子、标牌灯、烙铁定时器写各种小固件，PlatformIO 让每个小项目都有可复现的工程，而不是一堆散落的 Arduino 草图

PlatformIO Core 是 PlatformIO Labs 做的跨平台嵌入式开发工具，用 Python 写成，9.3k 星，是 VS Code 里 PlatformIO IDE 插件背后的命令行内核。它要解决的问题：Arduino IDE 管不住库版本、换板子要重装工具链、项目没法复现，它把这些都收进一个 platformio.ini。

它的工作方式是声明式工程：ini 里写清楚板子型号、框架（Arduino、ESP-IDF、Zephyr 等）、依赖库和版本号，首次编译自动下载对应的编译器、SDK 和库，之后 pio run 编译、upload 烧录、monitor 看串口，一套命令走完。它支持上千种开发板，AVR、ESP32、STM32、RP2040 都在一个界面里。

生态上它的库注册中心收录了上万个库，几乎所有 Arduino 库都能按名字直接引用；文档只有英文，但用的人多，中文博客和 B 站教程非常多。项目由公司维护，2026 年仍在持续发版。

对 0301 来说它是延伸项目：工具台上的小制作大多离不开一块 ESP32 或 RP2040——扣件测试治具、烙铁定时器、标牌背光。把这些固件统一建成 PlatformIO 工程放进一个仓库，每个目录一个 platformio.ini，台面上的电脑插上板子就能烧。配合 0802 服务器上的 Git，哪块板子跑的什么版本一目了然，一年后重做治具也能一键编译出来。

KiCad/kicad-source-mirror ★ 2.9k 界面有中文 延伸

KiCad 开源 EDA 套件的 GitHub 镜像：原理图、PCB 布线、3D 预览、Gerber 输出，专业级免费画板子

→ 工具台上做的小电路总有一天要从洞洞板走向自己画的 PCB，KiCad 是自由软件里画板子的标杆，且能直接导出给桌面 CNC 雕刻

KiCad 是自由开源的电子设计自动化套件，由 KiCad 团队和 CERN 等机构长期维护，主仓库在 GitLab，GitHub 上这个镜像 2.9k 星、五万多次提交，始终和开发分支同步。它要解决的问题是：画一块靠谱的电路板不该被专业软件的授权费挡住，KiCad 从原理图到出厂文件全流程免费，且专业厂商也在用。

它的工作方式是一条链：先在原理图编辑器里放元件、连线、标号，运行电气规则检查；再把网表同步到 PCB 编辑器，摆件、布线、铺铜，跑设计规则检查；最后导出 Gerber 和钻孔文件送厂，或者导出 SVG、DXF 给雕刻机。内置 3D 查看器能把板子和元件模型立体转着看，8 版之后交互式布线和差分对都很顺手，还带 SPICE 仿真和 Python 脚本接口。

生态上元件库和封装库随软件发布，社区库和嘉立创的 KiCad 库都能补齐国产元件；界面自带简体中文，中文文档和视频教程极多，国内高校和创客圈都在用。项目每年出一个大版本，2026 年依旧活跃。

对 0301 来说它是延伸项目：工具台上那台桌面 CNC 除了刻亚克力标牌，还能雕单面 PCB。烙铁定时器、PSK 盒子里的小电源板，先在 KiCad 里画好，把铜层导出成 DXF 或 Gerber，用 FlatCAM 之类的工具转成 G 代码，在 CNC 上把隔离槽铣出来，再用洞洞板旁那台烙铁焊上元件，一下午就能从想法走到实物板。批量做的时候同一份文件直接送厂，省去重画。
