阁楼间 · 模块 0307 · CNC 五轴雕刻机

被问爆了！阁楼上用铝型材自己搭了一台能转着切的五轴雕刻机

一台 3+2 定位的桌面五轴：三根直线轴加一只双旋转分度头，铝型材做骨，开源固件当脑。

🚧 真实项目需求收集中 #动手主义#铝型材#CNC#开源硬件#PSK

📐 它在哪、有多大

阁楼间（03）可站立核心区的东侧、0301 小制作工具台旁边，机器占地约 1.0×0.8m、高 1.2m，放在净高 ≥2060 的范围内；排屑管沿坡顶低矮带接到东侧 0404 木工间的集尘桶；整机重量和振动要先核实阁楼楼板承重。真实项目 2026-09-14 立项，需求收集中，还在“真五轴联动”与“3+2 定位”之间做取舍。（0008 未定位，设想落位）

位置与尺寸依据 0008 户型图与空间标注 v1；≈ 为按图面比例预估、未实测。看户型图 →

🎬 沉浸式想象

阁楼间东侧，工具台旁边那台方方正正的机器开始转了。主轴在一块胡桃木上先铣出生存盒的内腔，然后停住——A 轴把工件翻 90 度，C 轴再转 30 度，刀从侧面切进去，那道原来要换夹具做两次的斜槽一次成型。木屑被吸口全部拖进管子，顺着坡顶下的黑色排屑管跑向木工间的集尘桶，阁楼里只剩一股淡淡的核桃味。你隔着阳光板防护罩看，屏幕上是 grblHAL 的坐标在跳；一支半小时的程序跑完，你抬头看了眼头顶那扇天窗，站直了伸了个懒腰——它就装在核心区里，2060 的净高刚好够。

✅ 设想方案清单

  1. 机架全部用 0805 定标的欧标 2020 / 3030 喷砂黑铝型材，龙门式，行程 300×300×120，台面铝制 T 槽板
  2. 直线三轴用 1605 滚珠丝杠 + 42 步进（闭环），第四、五轴用一只蜗轮蜗杆 A/C 分度头，先做 3+2 定位，不上真五轴联动
  3. 控制走开源路线：grblHAL（支持 A/B/C 轴）跑在 Teensy 4.1 上，复杂曲面时切 LinuxCNC，不自研固件
  4. 主轴 500W 水冷或 1.5kW 风冷（看楼板承重结论），VFD 变频器和电源放在机器下层的型材柜里
  5. 四周阳光板防护罩 + 前门磁开关：门开即停主轴；吸尘口随主轴走，接 0404 木工间那套集尘
  6. 峰值功率 ≈2kW，并进 0304 光伏储能的负载表；夜里不跑，白天光伏够时跑
  7. 整机放在阁楼间可站立核心区东侧、0301 工具台旁；机器总重控制在 60kg 内，落在两根楼板梁上，承重核算前不上更重的主轴

🔥 小红书灵感点

  • 小红书上「桌面 CNC 开箱」帖最上头的镜头是转轴翻面那一下，所以分度头要露在外面能看见
  • 「动手主义」：机架自己切型材自己拼，配件全走 MakerWorld 打印件，和 0805 的黑色型材一个色系
  • 「痛屋」思路：机器旁挂一排它切出来的失败件，像画廊一样

⚠️ 避坑提醒

  • 真五轴联动的开源生态很薄，别一开始就追联动，3+2 定位能解决 90% 的生存盒零件
  • 阁楼楼板承重没核算前别买 2.2kW 主轴和铸铁分度头，先按 60kg 整机上限选
  • 型材机架刚性靠角码和内置角槽件，别只拧 T 螺母；切硬木时先降进给

🔧 GitHub 上的成熟方案

真实存在、可直接拿来用或改的开源项目（星数为 2026-09 抓取时页面显示值）。

grblHAL/core★ 489

grbl 的 32 位重写版核心，支持 A/B/C 附加轴、多种主控板（Teensy、STM32、ESP32）

→ 3+2 定位用它就够：三轴 + A/C 分度轴直接在 G 代码里指定，Teensy 4.1 板子几十块钱
LinuxCNC/linuxcnc★ 2.3k

老牌开源运动控制系统，驱动铣床、车床、机械臂，支持复杂运动学

→ 哪天真要上五轴联动，只有它有现成的五轴运动学和刀尖跟随（TCP）
FreddieHong19/Open5x★ 1.2k

把普通三轴机器改成五轴的开源硬件 + 软件方案（“Democratising 5-axis”）

→ 双旋转轴模块的机械结构和刀路后处理思路可以直接抄，它证明了桌面五轴能做
