被问爆了！阁楼上用铝型材自己搭一台三轴 CNC

一台三轴雕刻机，两条还没选的路线：木和亚克力走一条，铝走另一条，主材没定就不下单。

🚧 真实项目需求收集中 #动手主义#铝型材#CNC#三轴#开源硬件

📐 它在哪、有多大

阁楼间（03）可站立核心区的东侧、0301 小制作工具台旁边，机器占地约 1.0×0.8m、高 1.2m，放在净高 ≥2060 的范围内；排屑管沿坡顶低矮带接到东侧 0404 木工间的集尘桶；整机重量和振动要先核实阁楼楼板承重。真实项目 2026-09-14 立项，需求收集中，主切材料还在「木 / 亚克力」与「铝」两条路线之间取舍，型材截面和主轴选型跟着这个选择走。（0008 未定位，设想落位）

🎬 沉浸式想象

周六上午，阁楼东侧那台机器第一次装满了刀。它是一台三轴：铝型材搭的龙门，X 在横梁上走，Y 带着台面前后跑，Z 挂着主轴上下。台面上压着一块胡桃木，刀沿着生存盒内腔的轮廓一圈圈往下啃，木屑被吸口拖进黑色排屑管，顺着坡顶跑向 0404 的集尘桶，阁楼里只剩一股核桃味。你隔着阳光板防护罩看屏幕上的坐标在跳。旁边摊着两张清单：一张写 2020+3030 机架、500W 风冷主轴、行程 300×300×100；另一张写全 4040 加钢板、1.5kW 水冷、行程收到 200×200×80。两张都没画勾——主要切木头还是切铝还没拍板，所以主轴和型材截面一件都没下单。先借一套配置把流程跑通，想清楚了再决定它最后长成哪一版。

✅ 设想方案清单

  1. 先定一台三轴：龙门式铝型材机架 + 1605 滚珠丝杠 + HGR15 导轨 + 闭环 42 步进，台面用铝 T 槽板
  2. 木 / 亚克力路线：底座 2020+3030 喷砂黑型材，500W 风冷主轴，行程 300×300×100，进给可以放开
  3. 铝路线：全 4040 加一块钢板加强底座，1.5kW 水冷主轴，行程收到 200×200×80，进给保守、吃刀量小
  4. 主切材料没拍板之前，主轴和型材截面一律不下单，先用借来或租来的配置把 CAM 到成品的流程跑一遍
  5. 固件 grblHAL 或 FluidNC，三轴足够；cncjs 当发送端，跑在机器自带的小主机或机旁一块平板上
  6. 四周阳光板防护罩 + 前门磁开关：门开即停主轴；吸尘口随主轴走，接 0404 木工间那套集尘
  7. 峰值功率 ≈2kW，并进 0304 光伏储能的负载表；夜里不跑，白天光伏够时跑；整机重量按 60kg 上限选

🔥 小红书灵感点

  • 小红书上「桌面 CNC 第一刀」帖最上头的镜头是刀尖切进木头那一下，所以防护罩用透明阳光板别用铁皮
  • 「动手主义」：机架自己切型材自己拼，配件走 0305 那台自建 Voron 打的件，和 0805 的黑型材一个色系
  • 「痛屋」思路：机器旁挂一排它切出来的失败件，像画廊一样

⚠️ 避坑提醒

  • 主材没定之前别下单主轴和型材截面：切木和切铝是两台完全不同的机器，刚性和转速要求差一个量级
  • 铝屑和木屑不能共用一套集尘，铝屑混进木屑桶又扎手又有火星风险，分路阀和集尘桶都要分开
  • 阁楼楼板承重没核算前别上大主轴和加强钢板，先按 60kg 整机上限选；型材刚性靠角码加内置角槽件，别只拧 T 螺母

bdring/FluidNC ★ 2.5k 无中文

跑在 ESP32 上的 Grbl 系 CNC 固件：六轴、YAML 配置不用重新编译、自带 Wi-Fi 网页控制和 SD 卡脱机运行

→ 三轴用一块几十块的 ESP32 板就够；改轴参数只改 YAML 不用重编译，两条待定路线可以各存一份配置随时切

FluidNC 是 Bart Dring 主导的开源 CNC 运动控制固件，从 Grbl_ESP32 演化而来，用 C++ 写成，2.5k 星，2026 年 4 月发布 4.0.3 版。它要解决的问题是：Grbl 只能跑三轴、改引脚要重新编译，而 ESP32 便宜又自带无线，FluidNC 把 Grbl 的成熟运动核心搬到 ESP32 上，并把所有配置改成一个 YAML 文件。

它的工作方式是固件加配置文件：把编译好的固件烧进 ESP32，再上传一个 config.yaml，写清楚轴数、步进引脚、限位、步距、主轴类型和探针，重启就按新配置运行。它兼容 Grbl 的串口协议和 G 代码，cncjs、bCNC 都能直接用；自带 Wi-Fi 和 WebUI，浏览器就能上传、运行、点动，G 代码还能放 SD 卡脱机跑。

生态上有 6-Pack 等配套控制板，Discord 社区活跃，Wiki 完整但只有英文，中文资料零散；更新勤快。

对 0307 来说它是两个候选控制器之一：三轴不需要复杂运动学，FluidNC 加一块 ESP32 就能跑完 XYZ、限位、探针和 RS485 主轴。它最贴合本模块现状的地方是配置即文件——木 / 亚克力路线和铝路线的丝杠步距、进给、加速度和主轴类型差别很大，各写一份 config.yaml，试切时换文件重启就换了一台机器的性格，不用等主材拍板才动手。坑是 ESP32 引脚有限，外设一多就不够用；门磁急停必须走硬件输入，别依赖 WebUI 按钮。

grblHAL/core ★ 489 无中文

grbl 的 32 位重写版核心，支持 Teensy、STM32、ESP32 等十几种主控板，靠插件加网口、Modbus 和探针

→ 另一条控制路线：Teensy 4.1 跑它，脉冲快、插件全，Modbus 调 VFD、探针测刀长、门磁做安全门都是现成的

grblHAL 是挪威开发者 Terje Io 把经典的 Arduino 版 grbl 重写到 32 位平台的项目，core 仓库 489 星，加上各板卡驱动仓库是一大家子。原版 grbl 只能跑三轴、只支持 8 位 AVR，而桌面 CNC 早就需要更快的脉冲、更多外设和网口。

它的架构是核心加驱动加插件：核心负责 G 代码解析、轨迹规划、加减速与前瞻；驱动层适配 Teensy 4.1、STM32、ESP32、RP2040 等十几种 MCU；插件可以加 SD 卡、以太网、WebUI、主轴 Modbus、探针和自定义 M 代码。步进脉冲最高 300kHz，比原版高一个量级，配大导程丝杠和高细分驱动时余量很足；虽然最多能开到六轴，但本模块三轴就够。2026 年仍在更新，官网勾选板子和功能就能在线编译固件。

上位机用 ioSender、cncjs 或 Candle；没有官方中文文档，但 grbl 系教程基本通用。

在 0307 里它是两个候选控制器之一，也是更硬核的那个：Teensy 4.1 配一块 grblHAL 扩展板，XYZ 三路闭环步进，Modbus 插件调 VFD 转速，门磁接安全门输入，探针接刀长和 Z 零点测量。选它还是选 FluidNC 取决于主材：走铝路线时脉冲余量和硬件安全输入更要紧，grblHAL 更稳；走木 / 亚克力路线，FluidNC 改 YAML 更省事。坑是每种板子的引脚映射要按对应驱动仓库来，别照抄别人的接线图；软限位和回零方向第一次点火前逐条核对。

LinuxCNC/linuxcnc ★ 2.3k 无中文

老牌开源运动控制系统，把一台普通 PC 变成工业级数控：实时内核 + HAL 硬件抽象 + 可自定义运动学

→ 三轴阶段用不上，但它是这台机器的升级终点——哪天换闭环伺服、加光栅尺或要真正的曲面联动，只有它接得住

LinuxCNC 是有二十五年历史的开源运动控制系统，前身是美国 NIST 的 EMC 项目，2.3k 星，2026 年 7 月刚发 2.9.10 版。它解决的是把一台普通 PC 变成真正的工业级数控系统：铣床、车床、等离子、机械臂、六足平台都能驱动，而且运动学可以自己写。

它的架构分三层：底层是打了实时补丁的 Linux 内核，保证步进脉冲和伺服环以微秒级周期稳定输出；中间是 HAL 硬件抽象层，把并口引脚、Mesa FPGA 卡、以太网伺服都抽象成可以用配置文件互相连线的信号；上层是 G 代码解释器、轨迹规划器和 Axis、Gmoccapy 这些操作界面。对一台三轴机来说它的价值是余量：前瞻段数、加加速度控制、刚性攻丝、闭环伺服与光栅尺反馈都是现成的，而这些正是 Grbl 系固件够不着的地方。

生态成熟，论坛活跃，文档正在通过 Weblate 做多语言翻译，国内也有不少用它改老铣床的帖子，但完整中文文档还没有。

在 0307 里它是第二阶段的备选：先用 grblHAL 或 FluidNC 把三轴跑起来，等主切材料拍板、机器定型之后，如果走的是铝路线并且想换闭环伺服、上更高的切削参数，就在机旁换一台装 LinuxCNC 的小主机加 Mesa 7i96 卡，导轨、丝杠和限位全都不用动。坑是它对主机实时性要求高，迷你 PC 要先跑延迟测试，无线网卡最好禁用；另外它的配置是一整套文件而不是一个 YAML，第一次搭要花掉几个晚上，别在赶工期时切过去。

cncjs/cncjs ★ 2.6k 界面有中文 延伸

网页版 CNC 控制台：装在机旁一台小主机上，浏览器里发 G 代码、手轮点动、3D 预览刀路，支持 Grbl、grblHAL、FluidNC、Marlin

→ 机旁不想守一台电脑：cncjs 跑在机器自带的小主机上，机旁平板和 0204 设计台的浏览器都能开机、点动、看刀路

cncjs 是 Cheton Wu 发起、社区维护的网页版 CNC 控制软件，用 Node.js 和 React 写成，2.6k 星，是 Grbl 系控制器最常用的发送器之一。它要解决的问题是：CNC 控制器只有一个串口，传统做法是一台电脑守在机器旁，cncjs 把那台电脑换成一台巴掌大的小主机，操作都在浏览器里完成。

它的工作方式是服务端加网页：小主机通过 USB 串口连接控制器，cncjs 服务把 G 代码逐行发送并处理流控和实时状态回报；浏览器端是一组可拖动的部件——坐标、点动、主轴、宏、探针、控制台，以及一个 3D 刀路窗口，能看当前刀在程序的哪一行。它同时兼容 Grbl、grblHAL、Smoothieware、TinyG 和 Marlin，能接摄像头看加工画面。

生态上有树莓派和 Docker 镜像，界面自带简繁中文，国内 DIY CNC 圈用它的很多；更新节奏变慢但仍在维护。

对 0307 来说它是延伸项目：机上的 grblHAL 或 FluidNC 需要一个发送端，把 cncjs 装在机器自带的那台小主机上，机旁挂一块触摸屏或直接放一台平板当面板，0204 设计台的浏览器也能远程看进度。注意不同固件的状态解析随版本略有差异，显示不全就用 ioSender 做对照；门磁急停仍走固件的硬件输入，不要依赖网页按钮。摄像头画面可以顺手转进 HA，和 0305 那台自建打印机的监看放同一页；两条待定路线的进给参数也可以各存一组宏，试切时一键切换。

vlachoudis/bCNC ★ 1.7k 无中文 延伸

Python 写的 Grbl 发送器兼简易 CAM：自动调平、G 代码编辑、摄像头对刀、内置钻孔和轮廓加工，一个程序全包

→ 自动调平是雕 PCB 和铣不平整木料时最需要的功能，bCNC 用探针扫出曲面再实时修正 Z，是 grblHAL 上最省事的方案

bCNC 是欧洲核子研究中心的工程师 Vasilis Vlachoudis 写的 Grbl 发送器，用 Python 和 Tkinter 写成，1.7k 星，两千多次提交，社区持续维护。它要解决的问题是：小型 CNC 玩家不想为发送器、CAM、调平工具装三个软件，bCNC 把这些塞进一个窗口。

它的工作方式是发送器加工具箱：通过串口连接 Grbl 或 grblHAL，界面上有坐标、点动、主轴控制和 G 代码列表，可以直接在列表里编辑、拖动、镜像和缩放程序段。它最出名的功能是自动调平：用探针在工作台上按网格扫一遍，得到工件表面的高度图，再把 G 代码按这张图实时修正 Z 值，雕 PCB 时 0.1 毫米的隔离槽也能均匀。此外还有摄像头对刀、简单 CAM（钻孔、轮廓、口袋）和刀路 3D 预览。

生态上它是 Grbl 圈的老牌工具，教程不少，界面只有英文，中文资料以论坛帖子为主；界面偏老但功能扎实，仍在更新。

对 0307 来说它是延伸项目：这台三轴机日常发送用 cncjs 或 ioSender，但当工件是一块本身不平的胡桃木板，或者 0301 那边要借这台机器雕单面 PCB 时，切到 bCNC：先用主轴上夹的探针扫一遍工件表面，让它把程序的 Z 值按这张高度图修正，再开始铣。它跑在 0204 设计台的电脑上，USB 线拉到控制器即可，探针信号接固件的探针输入。自动调平主要服务木 / 亚克力路线，走铝路线时工件多是平整板材，用处不大；它内置的钻孔和轮廓 CAM 也够应付几个孔位。
