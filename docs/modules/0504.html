庭院 · 模块 0504 · 自动种植架

保姆级！一个 2 米种植架，让我半年没买过一片叶子菜

一座四层的自动滴灌种植架，土壤湿度自己判断，我只负责摘和吃。

⬜ 真实项目待设计 #阳台种菜#去家务化#自动浇灌#ESPHome#动手主义

📐 它在哪、有多大

在庭院东边界靠北一段，背对草地、面朝院子，从木屋南墙往南留 30cm 起摆 2m 宽×0.6m 深×1.8m 高的四层架；隔着东边界的碎石干河道，斜对面就是建筑东墙下的 1500L 雨水罐，滴灌主管从那边接过来。（0008 未定位，设想落位）

🎬 沉浸式想象

早上七点，太阳刚翻过东边草地的树梢，种植架顶上那根滴灌管准时滋滋响了二十秒，水珠顺着生菜叶滚下来。架子是镀锌管拼的，四层，每层六个种植箱，第一层是芝麻菜和罗勒，第二层小番茄已经挂了两串青果，第三层空心菜疯长，最上层是刚播的秋葵。架子侧面一块小屏幕闪着『土壤湿度 42%，今日不浇』。你摘了一把芝麻菜和几片罗勒，下午拌面用。旁边一只矿泉水桶改的液肥桶里，泡着上周的香蕉皮和淘米水，闻起来有点酸。风一吹，架子上挂的那串旧铜铃叮当响。

✅ 设想方案清单

  1. 东边界挨着草地那侧，用 25mm 镀锌管搭 2m 宽×0.6m 深×1.8m 高的四层架子，每层放 6 个 40cm 种植箱
  2. 每层一根 16mm 滴灌主管，每个箱子 2 个可调滴头，总管从东墙下的雨水罐加压泵接过来
  3. 每层埋一颗电容式土壤湿度传感器，ESPHome 本地判断低于 40% 才浇，不看时间表
  4. 架顶装可收放的遮阳网，夏天 35℃ 以上自动放下，靠温度传感器触发
  5. 按层分区：底层香草、二层茄果、三层叶菜、顶层新苗，高的放下面矮的放上面
  6. 侧面挂一块 2.9 寸墨水屏，显示每层湿度和上次浇水时间，数据同步全屋中枢大屏
  7. 架子旁放一只 20L 液肥桶，厨余泡水两周稀释十倍，每周日手动补一次

kizniche/Mycodo ★ 3.3k 有中文文档站

树莓派上的环境监控与调节系统，接传感器控水泵灯光风扇，带 PID、条件逻辑和网页仪表盘

→ 种植架的湿度判断、滴灌泵、遮阳网电机全接它一台树莓派，网页上看每层数据曲线，文档有中文

Mycodo 是美国开发者 Kyle Gabriel 从 2015 年维护至今的环境监控与调节系统，跑在树莓派上，GitHub 上 3.3k 星。它最初是为种蘑菇做的温湿度控制，后来长成通用的种植环境控制平台。

它的架构是输入、函数、输出三层：输入是传感器，支持上百种，从 DHT22 到各种 I2C 土壤和气体传感器；函数是逻辑，有 PID 控制器、条件判断、触发器，能写成简单规则也能写 Python；输出是执行器，GPIO 继电器、PWM、步进电机、脚本都行。数据存进 InfluxDB，网页仪表盘能拖出曲线、仪表和开关，所有配置都在浏览器里完成。还有 MQTT 输入输出，能和 HomeAssistant 双向交换数据。

项目一直在更新，2025 年 6 月发了 8.16.2 版；官方文档站有中文版，安装脚本一条命令，社区论坛活跃。

在 0504 里它是种植架的本地大脑：一台树莓派 4 放在架子侧面的防水盒里，四层土壤湿度探头接 ADC 输入，四路滴灌电磁阀和遮阳网电机接继电器输出；每层写一条条件函数，湿度低于 40% 且距上次浇水超过六小时才开阀二十秒，架顶超过 35 度放遮阳网。仪表盘上四条湿度曲线一目了然，再通过 MQTT 把每层湿度推给 HomeAssistant 和墨水屏。要注意它功能太多，第一次配置容易迷路，先只建输入和一条条件函数跑通再加。

OpenSprinkler/OpenSprinkler-Firmware ★ 543 无中文

OpenSprinkler 开源灌溉控制器的统一固件，跑在 ESP8266 或树莓派上，带网页、多程序排程、传感器输入和 MQTT

→ 四层架子每层一路电磁阀，它的多站点排程、传感器暂停和手动补浇是十年打磨过的成熟灌溉逻辑，YAML 都不用写

OpenSprinkler 是美国 Rayshobby 公司从 2011 年做起的开源灌溉控制器，硬件和固件都开源，这个仓库是它的统一固件，GitHub 上 543 星，2025 年 11 月还在发新版。它把多路电磁阀灌溉做成一个能联网、按天气自动调的控制器。

同一套 C++ 代码可以编译给 ESP8266 版、树莓派版和 Linux 机器。核心概念是站点和程序：每个站点对应一路电磁阀，程序定义哪些站点在什么时间浇多久，可以按星期、间隔天数、日出日落偏移；天气调节模块按本地气象数据算一个百分比，自动缩放浇水时长；传感器输入支持雨传感器、土壤湿度开关和流量计，雨天或土够湿就跳过；网页界面和手机 App 通用，还有 MQTT 和 HTTP API，HomeAssistant 有社区集成。

硬件可以买官方成品，也可以照开源原理图自己做一块 ESP8266 加移位寄存器的板子。没有中文资料，但界面简单。

在 0504 里它管四层滴灌的阀门：一块 ESP8266 加移位寄存器驱动四路 12V 电磁阀，四个站点对应四层，程序设成凌晨五点和傍晚六点各一轮，每层默认二十秒；四层的土壤湿度开关信号接到它的传感器输入，湿度够就跳过；加压泵用主站功能联动。断网也照常浇。要注意它的传感器输入是开关量，电容探头要先经 ESP32 比较阈值再给它一个干接点。

esphome/esphome ★ 11.7k 无中文（社区教程多）

用 YAML 配置 ESP32 / ESP8266 固件的系统，传感器、显示屏、灌溉控制器都是现成组件，原生接 HomeAssistant

→ 架子侧面那块 2.9 寸墨水屏和每层的电容湿度探头都靠它，还有内置的 sprinkler 组件能直接做四路滴灌

ESPHome 是 Nabu Casa 维护的 ESP32 固件生成系统，和 HomeAssistant 同一个团队，GitHub 上 11.7k 星。想让 ESP32 读传感器、控继电器、驱动屏幕，以前得写 Arduino 代码，而它只要一份 YAML 写清接了什么、往哪报，编译、烧录、OTA 全自动。

它的工作方式是 YAML 到 C++ 的编译器：你在 YAML 里声明传感器型号、引脚、采样周期，它生成固件；固件在设备上本地跑，通过原生 API 把实体推给 HomeAssistant，断网时本地逻辑照常工作。组件库有几百个，还有一个专门的 sprinkler 组件，内置多路阀门轮流浇水、主阀联动、暂停恢复的完整逻辑。

没有官方中文，但中文社区极大，B 站教程数不清。

在 0504 里它做两件事：一是每层一颗电容土壤湿度探头接 ESP32 的 ADC，用滤波组件取五分钟中位数，再用 sprinkler 组件驱动四路电磁阀，湿度低于 40% 才让对应阀门加入下一轮，本地判断不看时间表；二是架子侧面那块 2.9 寸墨水屏，用 display 组件画四行，每行一层的湿度和上次浇水时间，每十分钟刷一次。要注意 ESP32 的 ADC 非线性，探头要先在干土和水里标定两个点；墨水屏零度以下刷新会残影，冬天把间隔拉长。

farmOS/farmOS ★ 1.3k 无中文 延伸

基于 Drupal 的开源农场记录系统：地块、作物、播种收获、投入品、传感器数据全按日志记，有手机 App 和 API

→ 四层种植架 24 个箱子换茬轮作，播种日期、收成、上液肥的记录靠脑子记不住，farmOS 是专门干这个的

farmOS 是美国开发者 Michael Stenta 在 2014 年发起的开源农场管理系统，建在 Drupal 上，1.3k 星，被小型有机农场、社区农园和大学农业项目广泛使用。它要解决的问题是农事记录：哪块地什么时候种了什么、施了什么、收了多少，这些信息散在笔记本和脑子里，到了下一季就找不到。

它的数据模型很干净：资产是地块、植株、设备、动物；日志是发生在资产上的事，播种、移栽、收获、观察、投入品各是一种类型，每条带时间、地点、数量和照片。数据流是手机 App 或网页录入，进 Drupal 数据库，前端给出每块地的时间线、地图和库存。它还有传感器模块，任何设备 POST 一个 JSON 就能把读数存进来，配合 JSON:API 可以被别的程序读走。

生态上它有官方 Docker 镜像、可离线记录的 Field Kit 手机 App，模块市场里有灌溉、土壤检测等扩展。社区在论坛和 Matrix 上活跃，文档全英文，界面靠 Drupal 多语言机制可以自行汉化。

在 0504 里它是延伸：把四层架子建成一个地块，24 个种植箱各是一个子地块，每次播种、移栽、摘菜、周日补液肥都在手机上点一条日志；ESPHome 的四层湿度通过 HA 的 REST 命令每小时 POST 一次到它的传感器接口。一年下来能看出哪一层的番茄最早挂果、空心菜几茬之后该换土，第二年排层就有依据。对一个架子来说它偏重，但当草地和盆栽也要记的时候就值了。

FarmBot/Farmbot-Web-App ★ 969 无中文 延伸

开源龙门架种菜机器人 FarmBot 的网页控制端和 REST API：拖拽排苗、序列编程、按株浇水除草，全部开源硬件

→ 种植架的终极形态就是 FarmBot：一个龙门架按坐标给每棵苗单独浇水，它的网页端和序列编程思路直接能借来规划自己的滴灌

FarmBot 是美国 FarmBot 公司 2016 年众筹起家的开源种菜机器人，一台架在苗床上的 XYZ 龙门架，换头就能播种、浇水、除草、拍照，硬件图纸、固件、网页端全部开源。这个仓库是它的网页控制端和 REST API，TypeScript 和 Ruby 写的，969 星，2026 年 6 月还在发 15.27 版。它把家庭菜园变成可编程的东西：每棵植物有坐标，每个动作是一段可复用的序列。

它的工作方式是：网页里有一张苗床俯视图，把作物拖到格子上就定了坐标；序列编辑器像积木一样拼动作，移动到某坐标、开水阀几秒、拍照、读湿度探针，再用条件判断组合；定时任务按天安排序列。网页通过 MQTT 把指令发给树莓派上的 FarmBot OS，再由 Arduino 固件驱动步进电机。照片会和坐标对齐，可以做杂草检测。

生态上 FarmBot 卖整机套件，也有人打印零件复刻，论坛和文档完整；网页端有多语言翻译但没有中文。官方不鼓励自托管，直接用 my.farm.bot 也行。

在 0504 里它是延伸，架子本身不装龙门架，但它的两个思路值得直接抄：一是每个种植箱有坐标和作物记录，二是浇水序列由湿度读数触发而不是时间表，这正是方案里低于 40% 才浇的逻辑。可以照它的苗床图做一张 HomeAssistant 卡片，24 个箱子按层排开，点开每箱看作物、上次浇水和湿度。等哪天架子扩到第二座，想给番茄和罗勒按株给水，就真的可以在最上层架一根 FarmBot 的 X 轴。
