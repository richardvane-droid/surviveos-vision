钓台 · 模块 0703 · 钓台照明与电源

夜钓氛围感拉满！一块光伏板让钓台亮到天亮，不用拉一根电线

顶棚上一块太阳能板，柱子上一盏暖光灯，插座随时给手机和夜钓灯补电。

设想 真实项目尚未拆解此区域 #露营风#夜钓#光伏#智能家居#氛围感

📐 它在哪、有多大

光伏板贴在钓台顶棚 2.2×2m 的向阳坡面上；电池箱固定在靠坡一侧的杉木柱脚、离地 30cm；马灯挂顶棚正中，插座在临河一侧柱子上；地脚灯沿缓坡踏步一侧埋 4 个。（0008 未定位，设想落位）

🎬 沉浸式想象

晚上九点，河面黑得像墨。你伸手拍一下杉木柱上的开关，顶棚下那盏黄铜马灯亮起来，暖光刚好铺满台面，不会照进水里惊鱼。夜钓灯夹在台边，一束蓝光打在浮漂上，浮漂在黑水里像一颗小星星。手机插在柱子上的防水插座充电，HomeAssistant 弹一条消息：钓台电池 82%，今日光伏发电 0.6 度。蚊香在角落里烧着一圈红，远处传来蛙叫。你把椅子往后仰，灯光把顶棚的竹瓦影子投在水上，摇摇晃晃的。

✅ 设想方案清单

  1. 顶棚向阳坡装一块 200W 单晶光伏板，用铝支架垫 15° 角，正好和棚坡一致不突兀
  2. 杉木柱脚固定一个防水箱，里面装 12V 100Ah 磷酸铁锂电池 + MPPT 控制器 + 小逆变器
  3. 顶棚下挂一盏黄铜马灯改的 LED 暖光灯，2700K，功率只要 5W，调光旋钮在柱子上
  4. 台边装两个防水插座 + 两个 USB-C 口，专门给夜钓灯、手机和电动饵盘充电
  5. 缓坡踏步一侧埋四个太阳能地脚灯，天黑自动亮，走夜路不摔
  6. 电池箱装一个 ESPHome 节点，把电压、电量、发电量推到 HomeAssistant，电量低于 20% 手机报警
  7. 留一个 12V 输出口，冬天接一块小电热垫放在椅子上，屁股不冰

🔥 小红书灵感点

  • 「露营风」灯光公式：马灯 + 暖光 + 一点点蓝光夜钓灯，小红书夜钓视频都是这个配置
  • 「去家务化」思维：光伏自给自足，不用拉电线不用换电池，装完就忘了它存在
  • 「全屋数据可视化」：钓台电量做成地堡大屏上的一个小卡片，出门前看一眼

⚠️ 避坑提醒

  • 灯别对着水面照，鱼会跑，光只往台面上打，边缘留暗
  • 电池箱一定要架在柱脚离地 30cm 以上、高过河的汛期水线，涨水那几天你会感谢自己
  • 插座买真正 IP66 的，带盖子的那种，水边湿气比你想象的重

🔧 GitHub 上的成熟方案

按知名度（星数）优先、有中文版优先挑的开源项目，每个都在 2026-09 打开核实过存在。每个方案配一段科普介绍和一张铅笔风的“它怎么工作 + 怎么接进本模块”示意图。

syssi/esphome-jk-bms ★ 1.0k 无中文

ESPHome 外部组件，通过 UART-TTL 或蓝牙读极空 JK BMS 的每节电芯电压、温度、剩余容量，还能远程开关充放电和均衡

→ 磷酸铁锂电池组配 JK 保护板，用它把单体电压和温度读进 HomeAssistant，冬天低温禁充、电量低于 20% 报警都有数据可依

esphome-jk-bms 是德国开发者 syssi 维护的 ESPHome 外部组件，GitHub 上 1.0k 星，专门读深圳极空 JK 系列电池管理系统的数据。JK BMS 是 DIY 磷酸铁锂电池圈子里最常用的国产带均衡保护板，自带蓝牙和串口，但原厂只有手机 App，数据进不了家庭中枢，这个组件补上了这一段。

它的工作方式是一块 ESP32 通过两种途径之一和 BMS 通信：UART-TTL 接保护板的串口排针，或者用 ESP32 自带的蓝牙直接连，后者不用接线但要独占连接。解析出的实体非常细：总电压、电流、功率、剩余容量、每一节电芯电压、最高最低压差、均衡电流、两路温度、充放电次数和各类保护状态，还有几个开关能远程打开或关闭充电、放电和均衡。仓库按型号分了几份示例 YAML。没有中文文档，但极空保护板是国产的，参数名和 App 一一对应。

在 0703 里它装在杉木柱脚的防水电池箱里：12V 100Ah 磷酸铁锂四串配一块 JK 保护板，箱内的 ESP32 用 UART 接它，和读 MPPT 的那块合成一块板子；HomeAssistant 收到剩余容量低于 20% 就推手机报警，电芯温度低于 0 度就通过充电开关禁止充电，这是磷酸铁锂冬天最要紧的保护；单体压差超过 50 毫伏提醒做一次均衡。蓝牙方式会和手机 App 抢连接，用串口更稳；串口线别和 12V 输出线并排走，干扰会让读数乱跳。

KinDR007/VictronMPPT-ESPHOME ★ 409 无中文

ESPHome 外部组件，通过 VE.Direct 串口读 Victron MPPT 和 SmartShunt 的电池电压、光伏功率、今日发电量和充电状态

→ 电池箱里的 ESPHome 节点直接用它，今日光伏发电 0.6 度、电池电压这些数就是手机通知里那行字的来源，几根线加一份 YAML

VictronMPPT-ESPHOME 是捷克开发者 KinDR007 做的 ESPHome 外部组件，GitHub 上 409 星，用来读荷兰 Victron 公司 MPPT 太阳能控制器和 SmartShunt 电量计的数据。Victron 设备有一个叫 VE.Direct 的串口协议，每秒把电压电流等文本发一遍，文档公开，这个组件把它接进 ESPHome，不用买官方的联网网关。

接法极简：MPPT 侧面的 VE.Direct 口有四根线，接地和数据发送两根接到 ESP32 的一个 UART 引脚上就行，19200 波特纯文本，一行一个字段。组件解析出电池电压电流、光伏电压功率、今日和昨日发电量、充电阶段、错误码、负载输出状态等几十个实体。仓库提供完整示例 YAML。没有中文资料，但 Victron 在国内船用和房车圈有中文经销商和产品文档。

在 0703 里它是光伏电量看护的眼睛：顶棚那块 200W 板接一台 Victron 75/15 这类小 MPPT，电池箱里的 ESP32 用一个 UART 读它，和 JK BMS 那路合在同一块板上；HomeAssistant 做一张钓台能源卡片，显示电池电压、今日发电量、光伏功率和充电阶段，晚上九点那条电池 82%、今日发电 0.6 度的通知就从这里来；用 sun 实体判断天黑后再亮马灯和地脚灯。VE.Direct 的电平有些型号是 5V，接 ESP32 前加分压；串口线用屏蔽线，别超过一米。

Bettapro/Solar-Tracer-Blynk-V3 ★ 61 无中文

ESP32 或 ESP8266 通过 RS485 Modbus 读 EPEver Tracer 系列 MPPT 控制器，支持 Blynk、MQTT 和 HomeAssistant 自动发现，带网页配置

→ 国内买的 MPPT 多是 EPEver 这类国产 Modbus 机型，不想上 Victron 就用它接，几十块的控制器也能把发电量和电池电压推进 HomeAssistant

Solar-Tracer-Blynk-V3 是意大利开发者 Bettapro 做的固件，GitHub 上 61 星，用一块 ESP32 加一个 RS485 模块去读 EPEver Tracer 系列太阳能控制器。EPEver 是北京生产的 MPPT 品牌，Tracer AN 系列便宜好买，但原厂只给一个 RJ45 口的 Modbus 协议，这个固件把它变成一台能进家庭中枢的联网设备。

它的工作方式是主控通过 MAX485 芯片以 Modbus RTU 轮询控制器的寄存器，读出光伏电压电流功率、电池电压电流温度、负载状态、今日和累计发电量、充电阶段、故障位，还能写寄存器改负载开关。上报有三条路：Blynk 手机 App、MQTT 主题和 HomeAssistant 的 MQTT 自动发现，接上就自动出现几十个实体。没有中文资料，但 EPEver 的寄存器表有中文版可对照。

在 0703 里它是不用 Victron 时的替代路线：顶棚 200W 板接一台 EPEver Tracer 2210AN，电池箱里的 ESP32 通过 RS485 模块接控制器的 RJ45 口，自动发现后 HomeAssistant 的能源卡片、低电量报警和天黑亮灯的自动化都不用改；控制器自带的负载输出正好接马灯和地脚灯。RJ45 口的引脚要照它的接线图，接错会烧 RS485 模块；负载口有电流上限，逆变器走电池直出。

OpenEMS/openems ★ 1.5k 无中文 延伸

开源能源管理系统：Java OSGi 模块化平台，Edge 端接逆变器电池电表，Backend 汇总多站点，UI 看图表，德国 FENECON 主导

→ 钓台这套 200W 光伏加 100Ah 电池是院子里第二个独立电源，借它学工业级能源管理的分层架构，以后各处电池统一调度时用得上

OpenEMS 是德国储能厂商 FENECON 2016 年开源的能源管理系统，1.5k 星，Java 编写，OSGi 模块化，欧洲不少储能产品的固件底座就是它，2025 年仍每月发版。它解决的问题是：光伏、电池、充电桩、热泵各说各的协议，需要一个统一的控制平面来决定什么时候充、什么时候放、什么时候削峰。

它分三层：Edge 跑在现场的小电脑上，通过 Modbus TCP/RTU、SunSpec 等驱动读逆变器、电池、电表，内部把设备抽象成通道，控制器按优先级链条决定输出；Backend 在服务器上汇总多个 Edge 的数据到 InfluxDB 或 TimescaleDB；UI 是 Angular 写的网页和手机端，看实时功率流和历史曲线。

生态上它有 OpenEMS 协会和年度开发者大会，几十家厂商设备有驱动，文档全英文，中文资料几乎没有。

在 0703 里它是延伸：一块 200W 板加一个 MPPT 用 ESPHome 读一下已经足够，OpenEMS 对钓台是杀鸡用牛刀。但院子里的电池会越来越多，0304 的主光伏系统、0505 的充电桩、钓台这一箱，各自的 MPPT 和 BMS 都有 Modbus 口。哪天想让它们协同，比如钓台电池满了就把富余电量提示去给电动车充，就在 0802 服务器上跑一个 OpenEMS Edge，把几台设备的 Modbus 都接进来，用它的控制器链做调度，HomeAssistant 只负责显示和报警。

davidusb-geek/emhass ★ 668 无中文 延伸

HomeAssistant 的能源优化插件：用线性规划结合光伏预测、负载预测和电价，算出电池充放和可推迟负载的最优时间表

→ 钓台电池只有 1.2 度电，夜钓灯、电热垫、手机充电得排着来，让它按明天的日照预报算一算今晚能用多少

EMHASS 全称 Energy Management for Home Assistant，是澳大利亚工程师 David 2021 年开源的 Python 项目，668 星，作为 HomeAssistant 加载项安装，2025 年仍在活跃更新。它解决的问题是：HomeAssistant 能看能控，但不会算；什么时候充电、什么时候开大功率负载最划算，需要一个真正的优化器。星数不高，但它是 HA 生态里这个位置上最成熟的答案。

它的工作方式是把一天切成若干时段，输入三样预测：光伏发电（可接 Solcast 或按天气公式估算）、家庭负载（从 HA 历史数据学）、电价或自定义成本，再加上电池容量、充放电功率上限和几个可推迟负载的功率与时长，交给 PuLP 线性规划求解，输出每个时段电池该充还是放、每个可推迟负载该在哪个时段开。结果通过 REST API 发回 HA 变成传感器，自动化按它执行。

生态上它有详细的英文文档和 HA 社区长帖，用户主要在澳洲和欧洲，中文资料几乎没有。

在 0703 里它是延伸：钓台电池 12V 100Ah 只有 1.2 度电，冬夜电热垫 40W 开五小时就吃掉两成。把 200W 板按朝向和 15 度倾角配成一个光伏预测，电池参数照实填，电热垫和夜钓灯充电设为可推迟负载，EMHASS 每天傍晚算一次：明天要是阴天，今晚电热垫只批两小时，HA 自动化到点断掉 12V 口并推送一句提示；晴天就随便用。这样电量低于 20% 的报警基本不会响。
