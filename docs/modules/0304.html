阁楼间 · 模块 0304 · 光伏储能

码住！屋顶 4 块光伏板，阁楼一整年不用交电费

阁楼是离屋顶最近的房间，把光伏和储能都放在这里，太阳直接喂电。

⬜ 真实项目待设计 #能源自由#工业风#光伏#储能#低成本高质感

🎬 沉浸式想象

中午十二点，屋顶上四块光伏板正对着南边，热得能煎蛋。阁楼靠墙的角落里，一台 2 度电的户外储能电源亮着一排小绿灯，屏幕上的数字从 68% 慢慢爬到 71%。它旁边是一个自己焊的木架子，上面放着两块备用的磷酸铁锂电池，用魔术贴绑得整整齐齐。墙上一块小小的电流表指针轻轻抖着。手机推送来一条 HomeAssistant 通知：“今日已发电 3.2 度”。你看了一眼帐篷里那串正在亮着的灯，突然有一种“这个灯是太阳点的”的奇怪自豪感。傍晚它会自动切换，先喂帐篷区，再喂气象站，最后剩的给楼下木屋充手机。

✅ 设想方案清单

  1. 屋顶南坡装 4 块 400W 光伏板，用铝合金支架顺着斜顶贴装，不破坏瓦面
  2. 阁楼靠墙角落放一台 2kWh 户外储能电源，输入接光伏 MPPT，输出给阁楼所有低压设备
  3. 自焊一个木架子放 2 块备用磷酸铁锂电池，用魔术贴固定，留 10cm 散热间隙
  4. 墙上装一块复古指针电流表 + 一块小屏幕，实时显示发电和剩余电量
  5. 储能电源接 HomeAssistant，每天发电量推送到 0211 中枢大屏
  6. 用电优先级：帐篷区串灯 > 气象站 > 3D 打印机待机 > 楼下木屋充电区
  7. 阁楼里放一个二氧化碳灭火器 + 烟感，紧挨储能放，安全第一

🔥 小红书灵感点

  • “能源自由”话题：晒每天发电数字截图，评论区一定有人问型号
  • “工业风”角落：储能 + 电流表 + 铝架子，露出来反而好看
  • “低成本高质感”：光伏板不用最贵的，支架自己焊，省下来买储能

⚠️ 避坑提醒

  • 阁楼夏天温度高，储能电源别贴斜顶放，温度超 40 度会降速充电
  • 光伏线缆穿屋顶一定要做防水，不然第一场大雨就哭
  • 别一上来就全屋离网，先喂阁楼这几个小东西，够用再扩

🔧 GitHub 上的成熟方案

真实存在、可直接拿来用或改的开源项目（星数为 2026-09 抓取时页面显示值）。

syssi/esphome-jk-bms★ 963

用 ESP32 通过串口或蓝牙读取 JK 电池保护板的 ESPHome 组件，能看每节电压和温度

→ 木架子上那两块备用磷酸铁锂配 JK 保护板，一块 ESP32 就把电压温度送进 HA，过热立刻推送
tolwi/hassio-ecoflow-cloud★ 882

正浩 EcoFlow 户外储能电源的 Home Assistant 集成，读电量、输入输出功率并控制输出口

→ 买正浩这类储能电源的话直接装它，每天发电量和剩余电量进 HA，再推到 0211 中枢大屏
fl4p/batmon-ha★ 489

HA 加载项，通过蓝牙同时连接 JK、JBD、Daly 等多种 BMS，还能算电量和累计能量

→ 备用电池保护板不是 JK 也没关系，它一个加载项通吃 Daly、JBD，不用额外焊 ESP32
