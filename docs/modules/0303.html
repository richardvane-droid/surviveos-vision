阁楼间 · 模块 0303 · 帐篷区

沉浸式！在阁楼常驻一顶帐篷，下雨天躺进去听雨声

屋里搭一顶永远不用收的帐篷，门斜对着天窗，雨夜是我的逃避间。

🎬 沉浸式想象

晚上十点，杭州的梅雨敲在天窗玻璃上，滴滴答答。你钻进那顶搭在阁楼间可站立区里的双人帐篷，拉链拉到一半，留一条缝看天窗。帐篷里铺了一张 5cm 的自充气垫，上面是羽绒睡袋和一个毛茸茸的抱枕。帐篷顶挂着一串暖黄的小串灯，还有一个圆圆的露营灯，亮度调到最低。你手边是一杯热可可和一本翻了一半的书。雨声从斜屋顶上传来，比在外面露营时更近。帐篷外，光伏那边的储能电源亮着绿灯，安静地喂着串灯。你想，这可能是全屋最舒服的 3 平方米。

✅ 设想方案清单

  1. 阁楼间可站立区偏西搭一顶 2.35 米 × 2.16 米的帐篷，门朝东南对着天窗，永久不拆
  2. 帐篷下铺整块 3cm 泡沫拼接地垫，再铺自充气垫，最上层是羽绒睡袋
  3. 帐篷顶内挂 5 米暖黄串灯 + 一盏可调光露营灯，都接储能电源，不走市电
  4. 帐篷侧面挂一个网兜，放书、耳机、眼罩、热水杯，伸手就够到
  5. 天窗装智能遮光帘，早上 7 点自动打开让阳光进帐篷，雨天手动关
  6. 帐篷门口放一块小地毯 + 拖鞋，作为帐篷内外的分界线
  7. 帐篷外角落放一台小加湿器和一台白噪音机，梅雨季切换成除湿模式

wled/WLED ★ 18.7k 无中文

ESP32 控制 WS2812 等可寻址灯带的开源固件，手机调色、上百种灯效、原生接入 Home Assistant

→ 帐篷顶那串 5V 串灯换成灯带刷它，暖黄呼吸、星空闪烁随时切，HA 睡前自动调暗，全程吃 0304 储能的 5V 口

WLED 是奥地利开发者 Christian Schwinne（Aircoookie）2016 年开始写的可寻址灯带固件，18.7k 星，是 GitHub 上最受欢迎的灯光项目。它解决的问题是：一根 WS2812B 或 SK6812 灯带本来要自己写代码才能亮出花样，刷上 WLED 后打开手机就能调色、选特效、分段，还能被 Home Assistant 当成一盏普通灯来管。

它跑在 ESP32 或 ESP8266 上，用一个 GPIO 以单线协议驱动几百颗灯珠，内置一百多种特效和几十套调色板，每一帧算出所有灯珠颜色再一次刷出去。控制有三条路：板子自带的网页和手机 App、JSON 与 HTTP API、MQTT 或 HA 原生发现；还支持分段、预设、定时、按键、红外遥控和多板同步。

生态非常大：HA 官方集成开箱即用，Gledopto、Athom 等厂商直接卖预刷 WLED 的控制器，淘宝也有；文档是英文，但 B 站和小红书教程随手可搜，2025 年仍在密集更新。

在 0303 里它替换帐篷顶那串 5 米串灯：换成 60 灯/米的 SK6812 暖白灯带，一块 ESP32-C3 跑 WLED，供电走 0304 储能的 5V 3A 口，不碰市电。做三个预设——暖黄常亮、呼吸、星空闪烁，HA 场景在晚上十点自动切到呼吸并把亮度压到 10%。注意 5 米灯带要从两头注电，否则末端偏红。

remvze/moodist ★ 3.7k 无中文

开源的环境音播放器，雨声、雷声、篝火、风声等几十种声音可叠加混音，纯前端可自部署

→ 不下雨的晚上也想听雨，在旧手机或小平板上开它，混一段雨打帐篷加篝火当白噪音机，HA 场景一键调预设

Moodist 是开发者 Maryam Mousavi（remvze）在 2023 年发布的开源环境音网站，3.7k 星，定位是“专注与放松用的声音”，功能上对标 Noisli、A Soft Murmur 这类付费白噪音服务，但完全免费、无广告、开源，可以自己部署一份放在局域网里。

它是一个纯前端的 React 应用：页面上列着七十多种声音——雨、雷、风、篝火、溪流、海浪、咖啡馆、键盘、猫咪呼噜——每一种带一个音量滑块，你把想听的几种拉起来就混成一段自己的音景。声音文件是循环的短音频，浏览器里用 Web Audio API 叠加播放，不需要后端，也不联网取数据。上面还有睡眠定时、番茄钟、简易笔记、呼吸练习和分享链接，把当前混音存成一个 URL 就能在另一台设备上打开同样的组合。

它没有中文界面，但界面图标化、几乎不用读字；社区有 Docker 镜像和 HA 加载项，一条命令起服务。项目 2025 年仍在更新，声音库还在往里加。

在 0303 里它就是那台“白噪音机”的软件：帐篷外角落放一台旧安卓平板接小音箱，全屏打开自部署的 Moodist，存三个混音链接——雨打帐篷加远雷、篝火加风、纯溪流——HA 场景通过 Fully Kiosk 或平板浏览器打开对应 URL，配合 WLED 的呼吸灯做“晚安”场景。梅雨季真的下雨时就关掉它，听真的。注意平板别放在帐篷里，充电线和帐篷布不亲。

RoadkillUK/Motor-on-a-Roller-Blind-for-ESPHOME ★ 153 无中文

用 28BYJ-48 步进电机和 3D 打印件改造拉珠卷帘的 ESPHome 配置，自带 3D 模型和接线图

→ 天窗遮光帘不用买智能款，一个步进电机加打印件改成 HA 里的 cover，早上 7 点自动卷起；这类改造里它是 ESPHome 版本的现成答案

这是英国玩家 RoadkillUK 在 2019 年发布的卷帘电动化方案，153 星，把 nidayand 那套用 ESP8266 加步进电机改造宜家卷帘的经典做法完整移植到了 ESPHome 上。它解决的问题很具体：一幅几十块钱的手拉卷帘，怎么用最便宜的零件变成 HA 里能开能关、能停在任意位置的窗帘实体。

硬件只有四样：一块 ESP8266、一个 28BYJ-48 步进电机加 ULN2003 驱动板、一个 5V 电源，以及仓库附带的 3D 打印件——电机支架和咬住拉珠链的齿轮。软件是一份 ESPHome YAML：把步进电机声明成 stepper，再用 template cover 包装成窗帘，记着全开全关的步数；第一次手动走到最上最下各校准一次，位置存进闪存，之后发 open、close、set_position 就能精确到百分比，断网也能用板载按钮。

文档是英文，但只有接线图和 YAML 两页，照抄就行；同类改造 B 站有不少中文复刻。

在 0303 里它对应“天窗电动遮光帘”：天窗装一幅拉珠遮光卷帘，齿轮咬住珠链，ESP8266 供电走 0304 的 5V 口。HA 自动化早上 7 点 open 让阳光进帐篷，0306 气象站判断下雨时自动 close。注意 28BYJ-48 力矩小，遮光帘选轻布，超过 1 米宽换 NEMA17，YAML 只改几个数字。

advplyr/audiobookshelf ★ 14.3k 界面有中文 延伸

自托管有声书与播客服务器：扫描目录自动配元数据，网页和手机 App 记住进度，多用户各听各的

→ 帐篷区的夜晚要的是闭眼听书而不是刷手机，audiobookshelf 把有声书和播客放在自家服务器上，手机离线缓存后串灯下随听随停

audiobookshelf 是开发者 advplyr 用 Node.js 和 Vue 做的自托管有声书和播客服务器，14.3k 星，是自托管圈子里有声内容的默认答案。它要解决的问题是：买来或收集的有声书散在硬盘里，播客要靠各家 App 订阅，听到哪儿了换个设备就忘。它把这些集中到一台自己的服务器上。

它的工作方式是扫描加流式播放：把有声书按作者、书名整理成目录挂进 Docker，服务器扫描后从 Audible、Google Books 等源自动补封面和简介，多文件的书会合并成章节；播客直接填 RSS 就自动下载新集。播放时服务器按需转码，网页端、Android 和 iOS 官方 App 都能听，进度实时同步，支持倍速、睡眠定时和离线下载；多用户各有各的书架和进度，还带电子书阅读器和 Kindle 推送。

生态上它有 Docker、群晖和各种 NAS 的安装教程，界面通过 Weblate 翻译，简体中文完整，中文自托管社区讨论很多；项目更新频繁，2026 年仍在活跃发版。

对 0303 来说它是延伸项目：帐篷顶的串灯调到最低后，手边网兜里那副耳机连的就是它。在 0802 家庭服务器上跑一个 audiobookshelf，把有声书和几个户外、木工播客的 RSS 加进去，下雨前用手机把今晚要听的几集缓存好，钻进睡袋后开睡眠定时三十分钟。露营灯和白噪音机归 0303 管，听的内容归这台服务器管，早上七点遮光帘打开时，进度已经记在书架上，明晚接着听。

kovidgoyal/calibre ★ 25.7k 界面有中文 延伸

老牌开源电子书管理器：格式转换、元数据整理、自带内容服务器和阅读器，几十种设备一键传书

→ 帐篷网兜里那本翻一半的书，纸质之外还得有电子版随手可读；calibre 是电子书库的标杆，配墨水屏阅读器最省心

calibre 是 Kovid Goyal 从 2006 年起独立维护的开源电子书管理软件，用 Python 和 Qt 写成，25.7k 星，五万多次提交，Windows、macOS、Linux 都有。它要解决的问题是：电子书格式混乱、元数据缺失、不同阅读器互不兼容，买来的书和自己扫的书没有一个统一的家。

它的工作方式是一个书库加一堆工具：把书加进书库后，calibre 自动抓取书名、作者、封面和简介，按标签、系列、评分整理；内置转换器能在 EPUB、MOBI、AZW3、PDF 等格式之间互转，还能调字体、修目录；连上阅读器就按型号自动转换并传书，Kindle、Kobo、国产墨水屏都认。它自带一个内容服务器，在局域网开一个网页，任何浏览器和阅读器都能直接从书库里下载或在线读；再配上新闻抓取，能把网站文章定时做成电子书推送。

生态上插件市场有上百个扩展，社区论坛 MobileRead 非常活跃，界面自带简体中文，中文教程遍地都是；作者几乎每周发一个版本，二十年没断更。

对 0303 来说它是延伸项目：帐篷网兜里除了纸书，放一台墨水屏阅读器；calibre 装在 0802 家庭服务器上，内容服务器常开，晚上钻进帐篷用阅读器连 Wi-Fi 打开书库网页，挑一本下下来，露营灯调到最低就能看。和 audiobookshelf 分工：一个管听，一个管读。木工、户外、电子方面的 PDF 手册也一并塞进书库，帐篷里想起某个尺寸，伸手就能查。
