🎬 沉浸式想象

早上七点，我还在楼上，木屋里的画框墙先醒了。九台 iPad Pro 12.9 拼成 3×3，外面是我自己做的胡桃木大画框，接缝处刨得只剩一毫米。它们同时从黑屏淡入——九块屏用的是同一个图片池，夜里那台常驻的 M1 Mac 已经把 Pinterest 上那个 PSK 板同步进了共享目录，谁先轮到哪一张全看各自的节奏，所以九格永远凑不出重样的一面墙。你下楼倒咖啡，回头发现左上角换成了一张老式生存手册的插画，右下角变成一只雪地里的狐狸。屏幕亮度跟着窗外的光走，阴天暗一点，晴天亮一点，像挂了九幅真的画。以后想分主题、说一句就换一整面，那是下一步的事，眼下先把这一池画跑顺。评论区有人问：这是什么牌子的电子画框？我答：闲鱼牌。

✅ 设想方案清单

  1. 9 台闲鱼 iPad Pro 12.9 一代，拆掉保护壳后嵌进胡桃木框，屏幕间距压到 8mm
  2. 胡桃木外框 120×90cm 正好填满北墙那块位置，九屏区 92×70，内部 3mm 铝板做背板
  3. 一代机是 Lightning 口，9 条线得单独列一张清单采购，别跟其他模块的 Type-C 配件一起下单
  4. 9 条线从框下沿引出，走一条明装理线槽绕到吧台后面，木板墙不开槽不打孔，拆了不留疤
  5. 9 台集中到 1～2 个多口 USB-A 充电头（Lightning 线只配得上 A 口），插吧台那排插座
  6. 单台连框约 713g，挂钩按加强型选、每台两点吊挂，宁可超配也别赌木板墙的握钉力
  7. 抓图交给 0804 那台常驻 M1 Mac：夜里把 Pinterest 的 PSK 板同步进共享目录，九块屏轮询同一个池，统一轮播不分区
  8. 每台浏览器 kiosk 全屏加引导式访问锁屏，防误触也防息屏；亮度跟着 ESPHome 光照传感器走，人离开 30 分钟黑屏

MagicMirrorOrg/MagicMirror ★ 23.8k 无中文

模块化智能镜子平台，用网页模块拼接屏幕内容，社区壁纸轮播、天气、日历模块上千个

→ 备选画框方案：九屏里想留一屏显示时间、天气和当天日期，就用它的壁纸模块加两个信息模块拼

MagicMirror² 是荷兰开发者 Michael Teeuw 在 2014 年发起的开源智能镜平台，如今由 MagicMirrorOrg 社区维护，23.8k 星，每季度发版，是树莓派做信息屏和智能镜的默认选择。它让你在一块常亮的屏上组合显示时间、天气、照片，而不必从零写网页。

架构是 Node.js 后端加 Electron 全屏浏览器：核心只管布局和模块生命周期，屏幕分成几个区域，每个模块是一个网页组件，在 config.js 里声明放哪、传什么参数即可。模块的 node_helper 能访问文件系统和网络，所以能做本地图库轮播、接 MQTT。它也支持服务器模式，把页面开给局域网里任何浏览器，正好适合 iPad。

社区有上千个第三方模块，MMM-BackgroundSlideshow 支持本地文件夹定时换图，MMM-Remote-Control 给 Home Assistant 提供 REST 接口。文档是英文，B 站有不少树莓派魔镜教程。

放进 0103，它不是主方案，而是九屏里那一屏的备选：用服务器模式跑在 0804 那台常驻 M1 Mac 上，iPad 浏览器全屏打开，壁纸模块指向每天同步下来的那个共享图片池，角落叠一个小字号的时钟和当天日期；其余八屏仍走 immich-kiosk 的统一轮播。注意 iPad 要用引导式访问锁住浏览器，否则一碰就退出全屏。

mikf/gallery-dl ★ 19.2k 无中文

命令行批量下载图站图集的工具，支持 Pinterest 画板、板块和搜索结果，配置一次定时跑

→ 每天凌晨四点从 Pinterest 那个 PSK 画板拉新图进 Immich，靠它一条命令，配好 cookie 就不用管

gallery-dl 是德国开发者 Mike Fährmann 从 2014 年起维护的命令行图集下载工具，19.2k 星，几乎每两周发一个版本，支持三百多个图站，是 youtube-dl 在图片领域的对应物。它解决的是：想把某个画板或搜索结果整体保存下来，还要能定时增量更新。

工作原理是每个站点一个提取器：你给它一个网址，它识别站点、模拟浏览器请求列表接口、翻页、解析出每张原图地址和元数据，再按你定义的目录和文件名模板落盘，并用归档数据库记住已下载的条目，下次只拉新增。配置是一个 JSON 文件，每个站点可单独设 cookie、后处理器、尺寸过滤；Pinterest 支持画板、板块、搜索结果和相关图，需要登录 cookie。纯 Python，pip 装完就能用。

社区活跃，站点改版几天内就有修复；文档只有英文，但因为是命令行工具，国内博客和 B 站介绍也不少。

放进 0103，它跑在 0804 那台常驻 M1 Mac 的定时任务里：抓的是 Pinterest 上那一个 PSK 画板，凌晨四点拉一次，落进局域网共享目录形成九屏共用的同一个图片池，后处理器把小于 1500 像素的图丢掉，再交给 Immich 的外部库扫描进相册，九块屏各自轮询这一池，统一轮播不分区。坑在 Pinterest 的 cookie 会过期，每两个月要从浏览器重新导一次，最好加个失败通知到 HA。

damongolding/immich-kiosk ★ 1.7k 无中文

把 Immich 相册变成浏览器轮播画框的方案，老平板打开网页就能用，转场、时长、相册全靠 URL 参数

→ 九台 iPad 各开一个它的网址就是九幅画，同一个图片池、换图间隔、淡入淡出全用 URL 参数定，HA 还能远程控制

Immich Kiosk 是英国开发者 Damon Golding 从 2024 年起维护的画框软件，1.7k 星，更新非常勤，专门把自托管相册 Immich 里的照片变成浏览器里的轮播画框。它解决的是：闲置平板想当电子画框，又不想把照片交给商业云。

架构是一个 Go 写的小服务，Docker 一个容器，配置一个 YAML。它自己不存图，而是通过 API 向 Immich 要图：按相册、按人物、按日期或随机抽取，经过服务端缩放和裁剪后送给浏览器，浏览器端只是一个轻量网页，靠 HTMX 定时请求下一张。转场方式、停留时间、是否显示日期地点、多图拼接都可以在 YAML 里定，也可以直接写在网址参数里，所以同一个服务能给不同的屏发不同内容。它还有 Home Assistant 集成，能远程切相册、暂停、下一张。

文档站是英文，没有中文版，但配置项都是直白的英文单词。

放进 0103，0804 那台常驻 M1 Mac 上起一个容器，九台 iPad 的浏览器各打开一条带参数的网址：相册都指向同一个图片池、换图间隔 40 秒、转场用淡入淡出、九台的随机种子错开让画面不重复；早上七点 HA 调用集成让九屏同时从黑屏淡入，人离开 30 分钟后暂停并黑屏。坑在 iPad 一代的 Safari 较老，网页动画要关掉模糊背景效果才流畅，还得用引导式访问锁住浏览器防误触。

AUTOMATIC1111/stable-diffusion-webui ★ 165k 无中文（社区教程多） 延伸

Stable Diffusion 最流行的本地网页界面：文生图、图生图、局部重绘、放大、LoRA 与 ControlNet 扩展一应俱全

→ 画框墙每天要九张新画，只抓 Pinterest 总有版权和风格不齐的问题，本地生成一套北欧木屋或生存手册风的画最省心

stable-diffusion-webui 是网名 AUTOMATIC1111 的开发者在 2022 年 Stable Diffusion 开源后几周内做出来的网页界面，165k 星，是本地 AI 绘图最出圈的工具。它要解决的问题是：模型本身只是一堆权重和命令行脚本，普通人需要一个能调参数、看结果、反复试的界面。

它用 Python 和 Gradio 写成，启动后在本机开一个网页：输入正向和反向提示词、采样器、步数、尺寸，点生成后模型在显卡上跑扩散过程，几秒到几十秒出图。除了文生图，还有图生图、局部重绘、外扩画布、放大和批量生成；扩展系统让 ControlNet（用线稿控制构图）、LoRA（几十 MB 的小模型定义画风）一键装上，模型文件放进目录就能切换。

生态方面它是扩展最多的绘图前端，Civitai 上海量 LoRA 按它的格式发布；README 是英文，但中文教程、整合包和 B 站课程多到数不清。2024 年后更新变慢，Forge 和 ComfyUI 分走了一部分用户，但它仍是最简单的起点。

对 0103 是延伸玩法：眼下九屏轮播的是抓回来的同一个图片池，等以后想分主题——北欧木屋、生存手册、旧地图、雪地动物——每套用一个 LoRA 配一组提示词批量生成，凌晨四点跑一百张，按 3:4 出图，白天挑九张混进那一池；Pinterest 抓取管线保留，两条来源混着放。注意要一块 8GB 以上显存的显卡，Mac mini 跑 SDXL 会很慢，可以放到白天不用的游戏机上定时跑。

ImageMagick/ImageMagick ★ 16.8k 无中文（社区教程多） 延伸

三十多年历史的命令行图像处理套件：裁切、缩放、调色、加边框、拼图、格式转换，一条 magick 命令搞定批量处理

→ 九台 iPad 的屏幕是固定的 2048×2732，抓来和生成的画尺寸比例乱七八糟，进画框前必须统一裁切调色，这就是它的活

ImageMagick 是 1987 年就开始的开源图像处理套件，由 ImageMagick Studio LLC 维护，16.8k 星，装在几乎每一台 Linux 服务器上。它要解决的问题是：图像处理不该每次都打开 Photoshop，尤其是几百张图做同样的事的时候，一条命令行就该完成。

它的核心是 magick 这个命令（老版本叫 convert）：输入一张或多张图，按顺序执行一串操作，输出到新文件。操作有两百多种：resize 缩放、crop 裁切、gravity 对齐、modulate 调亮度饱和度、border 加边、montage 拼图、LUT 调色、格式转换，支持 200 多种格式包括 HEIC、RAW 和 PDF。它有 C、Python、Node 等语言绑定，2025 年后仍每周出小版本。

中文方面 README 是英文，但因为太经典，中文教程和命令速查表多到用不完；它的 Usage 文档是命令行图像处理的教科书。

对 0103 它是延伸中的基础工具：画框墙的管线里，抓来的画和 SD 生成的画推给 iPad 之前要过一道处理：统一裁成 3:4、缩到 2048×2732、给当天这一池统一压一点暖色偏移、四周留 3% 留白让画框有衬纸感、最后压成 JPEG 质量 85。写成一个 shell 脚本挂在常驻 Mac 凌晨四点的同步任务里，九张图几秒钟处理完。注意居中裁切可能切掉人物头部，画作类素材可以先用 SD WebUI 外扩画布再交给它。
