🎬 沉浸式想象

早上六点半，南侧梁下那根 3 米长的滑轨轻轻一响，南光灯从东头慢慢亮起来，菲涅尔透镜把光压成一道斜斜的暖黄，正好扫过床尾的亚麻毯。你翻个身，光斑刚好爬到枕头边——不刺眼，是那种被晒醒的感觉。到正午，灯已经走到滑轨正中，色温拉到 5600K，整个地堡白得像三楼的阳台。下午四点，灯慢慢往西头挪，墙上的绿植影子被拉得老长，音箱里自动切了一首慢歌。你根本忘了这间房一扇窗都没有。

✅ 设想方案清单

  1. 南侧梁内侧天花板贴梁装 3m 电动滑轨 + 云台（梁底 2400 就是灯的高度上限），南光 FS-300B 每天从东走到西，模拟 6:30～18:30 的日轨
  2. 灯头前加菲涅尔透镜，光斑收成一束“从窗户照进来”的硬光，墙上还能投假窗棂影子
  3. HomeAssistant 四场景：晨光 3200K / 正午 5600K / 黄昏 2700K 偏橙 / 阴天 4500K 低亮
  4. 沙发正上方再加一块 60×90cm 柔光箱，当“天光”补漫射，避免只有一个硬光源
  5. 接微型气象站数据：外面真下雨，地堡里就自动切阴天模式，跟地面同频
  6. 睡前 30 分钟自动进入“落日”渐暗，最后只剩床头 1% 的月光夜灯
  7. 滑轨中段留一个停靠点，冬天让灯正对沙发当“晒太阳位”

🔥 小红书灵感点

  • 小红书“假窗户”热帖：用一块木窗框 + 磨砂膜挂在光斑落点，假装光是从窗户进来的
  • “松弛感晒太阳角”：在灯走到的固定点放一张躺椅和一盆龟背竹，专门晒 20 分钟
  • “沉浸式日出闹钟”：把晨光场景当闹钟，取代手机铃声，被“晒醒”才是顶级仪式感

⚠️ 避坑提醒

  • 影视灯风扇有声音，滑轨也有电机声，睡觉前一定要把噪音测过，不然日出变噩梦
  • 菲涅尔硬光很热，别对着塑料收纳和皮沙发长时间烤
  • 滑轨承重要按灯 + 云台 + 线缆算，别用广告灯轨凑合，掉下来是真的砸头

basnijholt/adaptive-lighting ★ 3.4k 无中文

HomeAssistant 自定义组件，按太阳位置自动调整灯光色温和亮度，自带睡眠模式和手动接管检测

→ 直接拿它做晨光 3200K 到正午 5600K 再到黄昏 2700K 的自动曲线，睡前落日渐暗用它的 sleep mode 开关就有

Adaptive Lighting 是荷兰开发者 Bas Nijholt 写的 Home Assistant 自定义组件，3.4k 星，是 HA 社区里做“灯光跟着太阳走”最常用的方案。它解决的问题很单纯：人整天待在室内，灯却是死的，昼夜节律就乱了；它让每盏可调色温的灯按当地日出日落曲线，从清晨暖光过渡到正午冷白，再回到黄昏的橙光。

原理上它不碰硬件，只算曲线：读取 HA 的经纬度和时间，算出太阳高度角，映射成一个色温值和亮度百分比，再定时调用灯的开灯服务把值写进去。你手动改了灯，它会识别出“不是 HA 做的改动”并暂停接管，直到灯关掉再开。自带 sleep mode 开关，打开后所有灯降到最暖最暗，正好做睡前渐暗；日出日落时刻、色温上下限、过渡秒数、亮度曲线形状全部可调。

它走 HACS 安装、UI 配置，兼容 HA 里任何灯实体，包括 WLED、ESPHome 的 CCT 灯和各家智能灯泡，至今持续更新。文档只有英文，HA 中文社区里配置分享不少。

放进 0201，它就是那盏南光灯的“大脑”：南光 FS-300B 用 ESPHome 做成一个 CCT 灯实体交给它管，晨光、正午、黄昏三档色温由曲线自动给出，四场景里只剩阴天模式要单独写；睡前 30 分钟打开 sleep mode 做落日渐暗，最后交给床头夜灯。要注意它只管色温和亮度，滑轨走位得另写一条自动化按时刻换算步数。

claytonjn/hass-circadian_lighting ★ 887 无中文

HomeAssistant 昼夜节律灯光组件，把一天里自然光的色温变化算成一个传感器值，再按开关分组套到灯上

→ Adaptive Lighting 的前辈，配置更简单，还会把当前色温百分比暴露成传感器，滑轨换算走位时正好拿来当输入

Circadian Lighting 是美国开发者 claytonjn 在 2018 年发布的 Home Assistant 自定义组件，887 星，可以说是 Adaptive Lighting 的前辈，后者就是从它的思路上重写出来的。目标一样：让室内灯光模拟一天中自然光的色温变化，早上暖、中午白、傍晚再回暖。2025 年 9 月发了 2.1.6 版，仍在维护。

它的结构比 Adaptive Lighting 更简单，分成两层：一个传感器实体，按太阳高度角持续算出“当前应该是什么色温”和一个百分比；再加若干开关实体，每个开关绑一组灯，打开就把传感器的值写进这组灯，关掉就还给你手动控制。没有手动改动检测，也没有睡眠模式，换来的是配置只有十几行 YAML，出问题一眼能看懂。

它同样走 HACS 安装，兼容所有能调色温的灯；文档是英文，但配置极简，照抄示例就能跑。

在 0201 里它有两个位置。一是备选：如果 Adaptive Lighting 的接管逻辑和你的手动场景打架，就换它做最小方案，只让南光灯跟着时间变色温。二是更巧的用法——它那个传感器不控灯也能单独存在，滑轨走位的自动化直接读这个“一天走到几成”的百分比，换算成 3 米滑轨上的步数，灯的位置和色温就天然对齐了。注意两个组件别同时管同一盏灯，否则会互相覆盖。

isaac879/Pan-Tilt-Mount ★ 504 无中文

步进电机驱动、3D 打印的 Arduino 三轴摄影运动控制器：滑轨 + 云台，带蓝牙 App 和关键帧运动

→ 天花板滑轨上的云台可以照它的 3D 件、V 槽型材皮带结构和固件来做，灯头一边沿梁走一边慢慢转向床和沙发

Pan-Tilt-Mount 是创客 isaac879 开源的三轴摄影运动控制器，504 星，是自制电动滑轨里最常被复刻的一个。它原本给相机做延时和平移镜头：一根 2040 V 槽铝型材做滑轨，同步带拉着一个 3D 打印的滑车，滑车上再叠一个云台，做出滑动、水平转、俯仰三个轴。

控制核心是一块 Arduino Nano 和三颗 TMC2208 静音驱动，带三只 NEMA17 步进电机，霍尔传感器负责回零。固件通过串口收简单的字母指令：设速度、走到某位置、记关键帧、按关键帧序列平滑运动；板上接一颗 JDY-31 蓝牙串口模块，手机 App 就能遥控。定位精度滑轨 0.0225 毫米、转轴 0.0133 度，对灯来说远远够用，12V 供电。

仓库里有全套 STL、BOM、接线图和固件，文档英文，B 站有复刻视频。近年更新不多，胜在零件全是标准件。

在 0201 里，它就是梁下那根 3 米滑轨的骨架：型材接长到 3 米、皮带同样接长，滑车照 STL 放大加固，保留滑动和水平转两个轴，俯仰轴改成固定角度。固件不用蓝牙，串口接一块跑 ESPHome 的 ESP32 转成 HA 实体，走位指令由 HA 按时刻下发。最大的坑是负载：南光灯加透镜有两三公斤，皮带 3 米会松、NEMA17 直驱会丢步，建议换带 1:5 减速箱的电机，并把回零霍尔装在两端各一个。

MarlinFirmware/Marlin ★ 17.5k 无中文（社区教程多） 延伸

RepRap 3D 打印机的经典固件：G 代码解析、步进电机运动规划、加减速与限位归零，支持几百种主板

→ 3 米滑轨上的灯每天从东走到西，本质是一根轴的步进运动控制；Marlin 把归零、加减速、行程限制这套逻辑做得最成熟，可以直接借来用

Marlin 是 2011 年从 Sprinter 和 grbl 演化出来的 3D 打印机固件，17.5k 星，市面上大半消费级打印机的出厂固件都是它或它的分支。它要解决的问题是：把一串 G 代码变成几根步进电机精确、平滑、不丢步的运动，同时管好温度、限位、归零和安全。

它的工作方式是：主机通过串口发 G 代码，比如 G1 X100 F1200 是以每分钟 1200 毫米走到 X 等于 100 的位置；Marlin 解析后交给运动规划器，按设定的最大速度和加速度把移动切成梯形速度曲线放进缓冲区，再由中断驱动的步进器按微秒级节拍给电机脉冲。归零靠限位开关，软件行程限制防撞。它用 C++ 写，靠两个配置头文件适配几百种主板，PlatformIO 编译。

生态是 3D 打印圈最大的，2025 年后 2.1.x 仍在更新，README 是英文，但中文编译和配置教程遍地。

对 0201 它是延伸的取巧路线：南光灯的 3 米电动滑轨就是一根 X 轴，用一块打印机主板加一个步进电机和同步带，把 Marlin 配成单轴机器，两端装限位开关做归零。HomeAssistant 通过串口发一句 G1 X1500 F300 就能让灯慢慢走到滑轨正中，6:30 到 18:30 的日轨就是一张按时间发坐标的表，冬天的晒太阳位是一个固定坐标。注意灯加云台有几公斤重，电机选 NEMA 23、加速度设得很低，走起来才像太阳而不是打印头。

diyHue/diyHue ★ 1.8k 无中文 延伸

Python 写的飞利浦 Hue 桥模拟器：把 WLED、ESP 灯、Tasmota、MQTT 灯伪装成 Hue 灯，官方 Hue App 和娱乐同步都能用

→ 模拟阳光的柔光箱和床头夜灯如果想用 Hue App 的场景和影音同步功能，不用买 Hue 灯，diyHue 把自制灯全部伪装成 Hue

diyHue 是 Marius Cristian 发起的开源 Hue 桥模拟器，Python 写成，1.8k 星。它要解决的问题是：飞利浦 Hue 的 App、场景、日出模拟和影音娱乐同步做得好，但灯贵；如果自制的灯能装作 Hue 灯，就能白嫖整个 Hue 生态。

它在局域网里跑一个服务，完整实现 Hue 桥的 REST API 和 mDNS 发现协议，Hue App 搜索桥的时候找到的就是它。后端把各种灯接进来：WLED 和 ESPHome 的灯、Tasmota、MQTT 灯、Yeelight、Shelly，Zigbee 灯也能通过 zigbee2mqtt 挂在下面。App 里对灯做的开关、调色、场景、定时，它翻译成对应设备的命令发出去；娱乐区的低延迟同步走 UDP 流，能让灯跟着电视画面变色。Docker 一行部署。

社区中等规模，2025 年后仍有更新，README 是英文，中文资料很少。

对 0201 它是延伸的另一条控制入口：模拟阳光的主灯走 HomeAssistant 和滑轨，但沙发上方那块柔光箱和床头 1% 的月光夜灯如果做成 WLED 灯，挂进 diyHue 之后就能在 Hue App 里用它的日出唤醒和入睡渐暗，手机一拉就是那条从 3200K 到 5600K 的曲线；0207 看片时娱乐区还能让天光跟着电影变色。注意它和 HomeAssistant 同时控制一盏灯会打架，规定好谁是主：HA 管场景，diyHue 只管娱乐同步。
