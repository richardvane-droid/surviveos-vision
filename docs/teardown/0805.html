产品模块 1. 欧标 2020 型材配件套

D3 定标后的最小采购单元：一段欧标 2020 喷砂黑型材（槽宽 6mm、壁厚 1.8mm），配 M5 T 型螺母（或受力处的滑块螺母）、内六角螺栓、L 形角码、内置角槽件、端盖和层板托。内置角槽件是藏在槽里的连接方式，外面看不到金属件，正好符合“铝做骨藏在木后面”的原则；角码则用在需要刚性的位置。3030 / 4040 是另一套 8mm 槽的配件，必须分箱，不能混用。

关键参数 / 组成

  • 欧标 2020，槽宽 6mm，壁厚 1.8mm（轻载可 1.5）
  • M5 T 型螺母 / 滑块螺母 + M5 内六角
  • L 角码（外露）与内置角槽件（隐藏）两种连接
  • 3030/4040 为 8mm 槽，配件单独分箱

产品模块 2. 三材分层样板

一块 30×30cm 的样板，把三种材料按“铝做骨、木做面、皮草做触感”叠在一起：最底下是型材框，中间是一块 18mm 白蜡木面板，用内置角槽件从背面固定，正面看不到螺丝，边缘留 2mm 让木头热胀；面板一角包一块植鞣皮当把手位。它的用处是让每个模块动手前先摸一下这三种材料在一起是什么感觉，也是采购时对色的标准件——喷砂黑要对到同一个色号，木料的油蜡要对到同一个亮度。

关键参数 / 组成

  • 底：2020 型材框 30×30cm，内置角槽件连接
  • 中：18mm 白蜡木面板，油蜡饰面，背面固定不露钉
  • 面：植鞣牛皮包角 8×8cm，皮草只在手接触处
  • 作为对色标准件常年放在 0102 作品墙下

联动逻辑 3. 材质继承检查

这是一条给“设计对话”而不是给机器跑的逻辑：任何模块进入设备选型阶段前，把它方案里出现的每一种材料和规格过一遍 0805 的规则表——是不是三类之一、型材是不是欧标 2020/3030 喷砂黑、强电模块有没有单独接地、磨损面是不是木料覆盖。过不了的要么改方案，要么在 0805 里登记一条例外并说明理由。木料和皮草定标后，同样的检查再对已完成的模块回溯一遍。

触发 · 阈值 · 兜底 · 出口

  • 输入：模块的设想方案清单 + BOM 草稿
  • 检查：材料类别 / 型材规格与表面 / 接地 / 磨损面
  • 输出：通过 / 需修改 / 登记例外三种结论
  • 回溯清单：0103 0209 0301 0401 0403 0404 0501

主要实现路径

在 0005 启动清单的模块开场白里加一段“材质自检”提示，FreeCAD 里的型材做成 2020/3030 两个参数化零件库，选错规格画不出来
