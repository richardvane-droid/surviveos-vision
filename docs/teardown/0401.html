产品模块 1. 钢制洞洞板影子墙

过道两侧整面铺 60×90cm 白色烤漆钢板洞洞板，每件工具挂好后在板面留下一圈黑色“影子”轮廓。原理来自工厂 5S 管理的影子板：把“应该在哪”画在墙上，缺件不用清点，视觉一眼报警。钢板承重远高于木板，磁吸挂钩和零件盘随意贴；板后垫 20mm 龙骨留出挂钩勾挂的空腔，角落一枚 NFC 标签把这面墙接进数字清单。

关键参数 / 组成

  • 钢板 0.8mm 烤漆，单板承重约 30kg，孔距 25mm
  • 背板龙骨 20mm 空腔，膨胀螺丝固定进砖墙
  • 影子轮廓用油性笔手描或 3D 打印贴片
  • 角落 NFC 标签，手机碰一下打开工具清单

参考项目

stockholmux/pegmixer

产品模块 2. 透明分格抽屉柜

1.2m 高的一排透明抽屉柜共 48 格，专装螺丝、螺母、扎带这类“看得见才找得到”的小零件。透明抽屉解决的是视觉检索：不抽出来就能看到余量；抽屉里再放 Gridfinity 模数的分格托盘，M4 和 M5 同屉不混。抽屉口统一贴标签机打的白底黑字标签，整面柜子像一张表格。柜体螺栓上墙，抽屉底加止退卡口防抽脱。

关键参数 / 组成

  • 48 格透明 PS 抽屉，柜体 ABS，螺栓上墙
  • 抽屉内嵌 Gridfinity 42mm 模数分格盒
  • 标签 12mm 白底黑字，一次买够同款标签带
  • 抽屉止退卡口，抽到底不脱落

参考项目

kennetek/gridfinity-rebuilt-openscad

联动逻辑 3. 影子板生成流水线

手描工具轮廓费时且不准，这条流水线把它变成“拍照即出图”。输入是工具平放在 A4 白纸上的一张照片，程序做透视校正和阈值分割抠出外轮廓，按纸张尺寸换算成真实毫米，导出 DXF；再送进 OpenSCAD 参数化模型，生成凹槽外扩 1mm 的影子板。输出是可直接 3D 打印的 STL。核心判断是轮廓面积与纸面比例是否合理，不合理就提示重拍。

触发 · 阈值 · 兜底 · 出口

  • 输入：工具平放 A4 纸上的一张手机照片
  • 输出：DXF 轮廓 + Gridfinity 兼容的 STL 影子板
  • 阈值：轮廓面积占纸面 5%~80% 之外提示重拍
  • 打印失败兜底：直接把 DXF 打印成纸样手描

主要实现路径

用 tkubic/GridfinityShadowMaker 的照片转 DXF 流程，再用 kennetek/gridfinity-rebuilt-openscad 出可打印底板

联动逻辑 4. 借还归位提醒

解决“工具不知道被谁拿去哪了”。每件常借出的工具贴一枚 NFC 标签，离开过道时手机碰一下，HomeAssistant 收到 tag_scanned 事件，把它标记为“借出”并记下人和时间；归还时再碰一下即清零。每晚十点系统扫一遍借出清单，超过 3 天未还的推送提醒借用人，超过 7 天在中枢屏亮黄。墙上小白板保留，作为断网时的手写兜底。

触发 · 阈值 · 兜底 · 出口

  • 触发：NFC 碰一下 = 借出，再碰一下 = 归还
  • 阈值：3 天未还推送提醒，7 天中枢屏亮黄
  • 出口：借出清单实体 + 每晚汇总通知
  • 兜底：小白板手写借出卡，断网照常登记

主要实现路径

用 home-assistant/core 原生 NFC 的 tag_scanned 事件做借出/归还状态机，朋友借用扩展接 chicago-tool-library/circulate
