过道工具间：4 个核心模块与逻辑

胡桃色洞洞板加黄铜影子轮廓，竖着分三区，全屋电动工具共用一块 WORX 电池。

产品模块 1. 北墙三区工具墙

过道北侧隔断整面做成竖向三区的工具墙：上区留 40cm 吊长杆工具与高枝剪，中区是主墙面的胡桃色洞洞板，下区是 90cm 高的落地功能柜。分区的依据是取用频率和重量——重的、常用的落在肩到腰之间，长的、少用的抬上头顶，带电的、脏的收进柜子。中区每件工具背后描一圈黄铜色影子轮廓，沿用工厂 5S 影子板的思路：把“应该在哪”画在墙上，缺件不用清点。板后垫 20mm 龙骨留出挂钩勾挂的空腔。

关键参数 / 组成

  • 上区吊长杆，中区洞洞板主墙面，下区 90cm 功能柜
  • 中区洞洞板分四类：敲击紧固、切割修整、测量画线、电动工具
  • 黄铜影子轮廓外加一圈浅色描边，木色底上才看得清
  • 底色与布局两个版本未定，先按可拆板试挂再定稿

参考项目

tkubic/GridfinityShadowMaker

产品模块 2. WORX 20V 电池平台与割草四件套

全屋电动工具统一到 WORX 威克士 20V 大脚板电池平台：同一规格的电池在打草机、吹叶机之间通用，之后添工具只买裸机。下区功能柜里排一组充电位，电池取下即充，柜面这几格用荧光绿加黑色的标签和木色拉开。首批只落地割草工作流的四件套——手拔、电动打草机、手动修枝剪、大风量吹叶机 WU231.9（8.6～11.6 m³/min），够覆盖 0601 那条 100㎡ 长草地。柜子左半边同时给 0805 的铝型材配件分箱。

关键参数 / 组成

  • 统一 20V 大脚板电池，裸机通用，柜内一组充电位轮充
  • 首批四件套：手拔 + 打草机 + 修枝剪 + 吹叶机
  • 风量 8.6～11.6 m³/min，预算 ¥1,500～1,800
  • 配件分箱：20 系列槽 6mm、30-40 系列槽 8mm

参考项目

kennetek/gridfinity-rebuilt-openscadMultiMote/niimblue

联动逻辑 3. 影子板生成流水线

手描工具轮廓费时且不准，这条流水线把它变成“拍照即出图”。输入是工具平放在 A4 白纸上的一张照片，程序做透视校正和阈值分割抠出外轮廓，按纸张尺寸换算成真实毫米，导出 DXF；再送进 OpenSCAD 参数化模型，生成凹槽外扩 1mm 的影子板。输出是可直接 3D 打印的 STL，打黄铜色件贴在胡桃板上当轮廓。核心判断是轮廓面积与纸面比例是否合理，不合理就提示重拍。

触发 · 阈值 · 兜底 · 出口

  • 输入：工具平放 A4 纸上的一张手机照片
  • 输出：DXF 轮廓 + 可打印的 STL 影子板
  • 阈值：轮廓面积占纸面 5%~80% 之外提示重拍
  • 打印件用黄铜色料，外圈留 2mm 浅色描边才压得住木纹

主要实现路径

用 tkubic/GridfinityShadowMaker 的照片转 DXF 流程，再用 kennetek/gridfinity-rebuilt-openscad 出可打印底板

参考项目

tkubic/GridfinityShadowMakerkennetek/gridfinity-rebuilt-openscad

联动逻辑 4. 取用归位提醒

解决“工具不知道被自己带去哪个区了”。这面墙是全屋工具的总汇聚点，东西流向各个模块，靠 NFC 记账：每件常带走的工具贴一枚标签，离开过道时手机碰一下，HomeAssistant 收到 tag_scanned 事件，把它标记为“在外”并记下去向和时间；放回影子里再碰一下即清零。每晚十点扫一遍在外清单，超过 3 天未归位推送提醒。周末割草那四件套整组出勤，按一个组合登记，回来少一件立刻看得出来。

触发 · 阈值 · 兜底 · 出口

  • 触发：NFC 碰一下 = 带走，再碰一下 = 归位
  • 阈值：3 天未归位推送提醒，7 天中枢屏亮黄
  • 割草四件套按组合登记，整组出勤整组核对
  • 兜底：小白板手写去向卡，断网照常登记

主要实现路径

用 home-assistant/core 原生 NFC 的 tag_scanned 事件做带走/归位状态机，去向写进 input_select，逾期由模板自动化提醒

参考项目

home-assistant/core
