防灾食品：4 个核心模块与逻辑

先进先出的食品货架，罐头、米、水按日期滚动，永远不过期。

产品模块 1. 斜滑轨罐头架

罐头架是防灾墙的中间三层，原理来自超市冷柜的重力货架：层板上铺一排 15° 倾斜的导轨，罐头横着放进去，靠自重滚向前端，前端一根挡条把它拦住。从后面补新罐头、从前面取旧罐头，物理结构本身就保证了先进先出，不需要人记顺序。导轨用 3D 打印，每根宽度按罐头直径定制，两根一组夹住一列罐头，打印件用螺钉固定在镀锌层板上。整架离墙 5cm 留出通风，避免罐头背面结露生锈。最下层不放罐头只放水桶，把 200 多公斤的重量压在最靠近地面的位置。

关键参数 / 组成

  • 镀锌钢架 2.4m 宽 × 2m 高，5 层，层板承重 150kg
  • 3D 打印 PETG 导轨，15° 斜度，按罐径 75/85/100mm 三规格
  • 前挡条 + 标签夹，日期用马克笔写在罐顶
  • 架体离墙 5cm，底层专放 12 桶 18L 水

产品模块 2. NFC 密封米桶

米、面、豆这类散装粮食不适合滚动，用密封桶按“砖”存放。5kg 真空米砖是先抽真空再热封的方形包装，隔氧防虫，常温可放两年；砖放进带硅胶圈的食品级密封桶，桶里再丢一包脱氧剂，双层保险。桶盖中央贴一枚 NFC 标签，写入的是 Grocy 里这个 SKU 的链接，手机一碰就弹出入库日期、保质期和剩余数量，不用撕开看。桶体半透明，剩多少一眼可见。地下室湿度大，桶下垫塑料托盘让空气流通，不直接接触水泥地。

关键参数 / 组成

  • 食品级 PP 密封桶 10L，硅胶圈盖，可叠放两层
  • 真空米砖 5kg，热封包装，常温保质 24 个月
  • 脱氧剂 100cc 一包，开桶换新
  • NTAG213 NFC 贴纸，写入 Grocy 商品页 URL

联动逻辑 3. 先进先出到期提醒

货架保证了物理上的先进先出，这段逻辑保证“到期前一定有人知道”。每个 SKU 在 Grocy 里建档，入库时扫条码或碰 NFC 记下数量和保质期，取用时再扫一次做消耗。Grocy 按“最早到期的先出”维护库存，HA 每天早上 8 点拉一次即将到期列表：30 天内到期的推送“该吃掉了”并在小白板旁的 0211 大屏上标黄，7 天内标红。核心判断是到期天数和数量的组合：一罐将过期只是提醒，十罐将过期就自动生成一份“本周菜单建议”。忘了扫码的兜底是月底盘点，Grocy 的库存和货架实物对一遍。

触发 · 阈值 · 兜底 · 出口

  • 触发：每天 08:00 拉取 Grocy 到期列表
  • 阈值：30 天内提醒标黄，7 天内标红并推手机
  • 兜底：每月最后一个周日盘点，对不上就手动改
  • 数据出口：HA sensor.grocy_expiring + 大屏到期卡片

主要实现路径

grocy/grocy 管 SKU 与保质期，Forceu/barcodebuddy 扫码出入库，custom-components/grocy 把到期数暴露成 HA 传感器再推送

联动逻辑 4. 库存天数与轮换采购单

白板上那行“库存 92 天”不是估的，是算出来的。每个 SKU 除了数量还登记了单份热量，逻辑把所有在库食品的总热量除以两个人每天 4000 千卡，得到可支撑天数；水单独算，12 桶 18L 按每人每天 3L 得到饮水天数，取两者较小值显示。当天数低于 90 天或某个品类数量低于安全线，就把缺口写进 KitchenOwl 的采购清单，下次去镇上手机上勾一下。轮换日固定每半年一次（4 月和 10 月），提前两周把要换的水桶和罐头列成清单，换下来的进厨房，不扔。

触发 · 阈值 · 兜底 · 出口

  • 触发：每次出入库后重算，每天 08:00 刷新白板数据
  • 阈值：食品 < 90 天或水 < 60 天列入采购单
  • 兜底：热量表缺失的 SKU 按 300 千卡/份估算
  • 数据出口：HA sensor.food_days + KitchenOwl 采购清单

主要实现路径

HA template sensor 从 custom-components/grocy 的库存属性求和算天数，缺货项通过 TomBursch/kitchenowl 的 API 写入采购清单
