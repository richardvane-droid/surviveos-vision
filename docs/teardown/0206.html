物品数字孪生：5 个核心模块与逻辑

产品模块 1. 二维码收纳箱系统

全屋 800 件东西能被找到，前提是每件东西都有一个固定的“地址”。这套系统把地址拆成四级：区域、货架格位、箱、层。货架每个格位贴一张位置码，箱子统一用 40×30×24 厘米的透明 PP 箱，箱内物品按层记录，箱侧贴一张防水二维码加一行手写标签。二维码只编码箱号，箱里换了东西不用换标签，改的是数据库。透明箱的意义是“看得见”，避免不透明箱变成谁也不想打开的黑洞；防水标签则是因为地堡湿度高，普通打印纸一个月就糊。

关键参数 / 组成

  • 透明 PP 箱 40×30×24cm，全屋统一一款可堆叠
  • 二维码用合成纸热敏打印，防水防潮不掉色
  • 四级地址：区域 → 格位 → 箱 → 层
  • 货架格位贴位置码，挪箱子只需重扫绑定

参考项目

sysadminsmedia/homebox

产品模块 2. 扫码入库站

挂在地堡墙上的一块“操作台”，把建档和查找的硬件收在一个铝合金壁挂框里。核心是一块 12.9 寸平板，显示七个区域的等距地图，每件物品是地图上的一个点；平板后面藏一台 N100 小主机，跑 Homebox 数据库和 HomeAssistant，数据全在本地。框下方挂一把蓝牙扫码枪，扫箱号比用平板摄像头快得多；旁边是热敏标签机，装合成纸标签卷，新箱子建档时当场打一张贴上。整站只需一路电源，走线藏在墙挂底板后面。

关键参数 / 组成

  • 12.9 寸平板壁挂，常亮显示等距地图
  • N100 小主机跑 Homebox + HA，与 0211 共用数据库
  • 蓝牙扫码枪 + 挂座，扫码距离 30cm 内
  • 热敏标签机用合成纸卷，防水标签即打即贴

参考项目

sysadminsmedia/homebox

联动逻辑 3. 扫码入库

建档是整套数字孪生里最累的一步，这段逻辑的目标是“一个箱子只做一次”。流程从扫箱号二维码开始：箱号没登记过就新建并绑定货架格位，然后拍一张俯视照片压缩存本地，再逐件录入名称，可以用语音也可以用键盘。每录一件，系统在物品库里找相似名称，有就提示合并或加别名，避免“鱼钩钳”和“钓鱼钳”变成两条记录。最后生成物品的完整路径“区域 → 格位 → 箱 → 层”。输入是扫码和照片，输出是带位置坐标的物品记录，以后找东西全靠它。

触发 · 阈值 · 兜底 · 出口

  • 箱号二维码只编码编号，内容变了不用换标签
  • 俯视照压缩到 200KB 以内，扫码先看照片再决定开箱
  • 相似名称自动提示合并或加别名，避免重复建档
  • 一个区域一个周末，分批录入不贪多

主要实现路径

用 sysadminsmedia/homebox 的 Location / Item / Label 模型和标签打印功能建档，语音录入走 HomeAssistant Assist 转文字后调 Homebox API

参考项目

sysadminsmedia/homebox

联动逻辑 4. 找东西

对着平板说一声“鱼钩钳”，地图上就亮一个点，这是整个系统对外的样子。逻辑分三步：先把语音或键盘输入拿去物品库做模糊匹配，容忍一两个错字，也匹配别名和拼音；找到唯一结果就取它的箱号，反查格位和区域坐标，在等距地图上点亮并显示箱内照片和在库 / 外借状态；找不到唯一结果就列三个近似项让人确认，确认后自动把这次输入补录成别名，下次就能直接命中。全程在本地跑，一秒内出答案，没有云端。

触发 · 阈值 · 兜底 · 出口

  • 模糊匹配容 1~2 个错字，别名和拼音都能搜到
  • 唯一命中直接亮点，多个候选给 3 个近似项
  • 确认后自动补录别名，越用越准
  • 结果同步到 0211 大屏，全程本地无云

主要实现路径

用 sysadminsmedia/homebox 的搜索 API 做名称和别名匹配，HomeAssistant Assist 接语音，平板端等距地图按坐标点亮

参考项目

sysadminsmedia/homebox

联动逻辑 5. 借还提醒

拿走扫一下，放回扫一下，中间的事交给程序记。每次扫码先看距上次扫码是否超过 30 秒，避免手抖连扫两次把状态翻回去；确认有效后把物品状态在“在库”和“外借中”之间翻转，并记下时间戳。每天凌晨三点跑一次巡检：外借超过 7 天的推送提醒，电池、滤芯、种子这类消耗品低于设定下限的写进采购单。盘点日用平板批量扫码，没扫到的箱子列成待查清单。它解决的是“谁拿了、还剩多少”这两个最容易吵架的问题。

触发 · 阈值 · 兜底 · 出口

  • 30 秒内重复扫码视为误触忽略
  • 外借超过 7 天推送提醒，每天 03:00 巡检
  • 消耗品设最低数量，低于即写入采购单
  • 盘点日批量扫码，未扫到的箱子列成待查

主要实现路径

借还状态和到期提醒照 snipe/snipe-it 的 checkout / checkin 流程做，消耗品最低库存和采购单参考 inventree/InvenTree 的 BOM，用 HomeAssistant 自动化定时巡检
