小吧台：4 个核心模块与逻辑

产品模块 1. 老榆木自然边吧台

吧台的核心是一整块 1.8m 长、6cm 厚的老榆木板，一侧保留树皮弧线不切直，“自然边”让一块板看起来像一段树。台高 105cm 配 75cm 高脚凳，手肘搁上去刚好；板下是松木底柜，放小冰箱和几瓶黄酒，侧面一枚铜钩挂开瓶器。台面只留手冲架加磨豆机、煨热红酒的小铸铁锅两套。自然边必须整体封闭上油，否则树皮一年掉渣。

关键参数 / 组成

  • 老榆木自然边板 180×6cm，台高 105cm
  • 松木底柜：小冰箱格 + 黄酒层 + 侧面铜钩
  • 手冲架 + 磨豆机一角，电陶炉 + 铸铁锅一角
  • 黄铜小吊灯 ×3，2700K，离台面 70cm 以上

产品模块 2. 台后三层木架

吧台后墙的三层木架是这个角落的背景板，也是所有材料的家。两根榆木立柱用膨胀螺栓上墙，三层隔板榫槽插进立柱，没有一颗外露螺丝。中层放 8 只玻璃罐：咖啡豆、桂花、陈皮、干柠檬片，每罐系一张手写牛皮纸标签；上层一根杯钩条把十几只杯子倒挂起来，既晾干又是展示。架子只放这两类东西，台面就能永远空着，收拾只要三分钟。

关键参数 / 组成

  • 榆木立柱 ×2 膨胀螺栓上墙，隔板 ×3 榫槽插接
  • 玻璃罐 ×8：咖啡豆 / 桂花 / 陈皮 / 干柠檬片
  • 杯钩条倒挂十几只不同的杯子
  • 手写牛皮纸标签 + 麻绳，罐内物一眼看清

联动逻辑 3. 落座调光

解决的问题是：客人一坐下，吧台的灯应该自己退到刚好照亮台面的程度，不用谁去摸开关。输入是三把高脚凳凳面下的压力垫和 HA 的日落状态；输出是三盏吊灯的目标亮度。核心判断是“日落后且至少一把凳子有人”：吊灯 5 秒渐变从 80% 降到 30%，同时关台后射灯；白天不干预。离席后计时 3 分钟，再坐下续期，到时回 80%。

触发 · 阈值 · 兜底 · 出口

  • 触发：任一凳面压力垫有人，且 sun.sun 已日落
  • 动作：吊灯 5 秒渐变到 30%，关台后射灯
  • 兜底：离席 3 分钟回 80%，白天完全不干预
  • 出口：吊灯亮度实体 + 一条待客日志

主要实现路径

ESPHome 读凳面压力垫上报 HA，自动化按 sun.sun 调 light.turn_on 渐变 5 秒

参考项目

esphome/esphomehome-assistant/core

联动逻辑 4. 吧台点单账本

解决的问题是：架子上 8 只罐子和台下几瓶黄酒还剩多少、今晚能做什么，靠记忆总会答应了才发现缺料。输入是 Bar Assistant 的库存和配方库；输出是“今晚能做的”清单、每杯扣减后的库存和购物清单。核心逻辑是按库存反查配方：只列材料齐全的饮品，客人选定后按配方克数扣减；任一材料低于 1 份就进购物清单并推送手机。

触发 · 阈值 · 兜底 · 出口

  • 触发：客人坐下翻平板，按库存筛可做配方
  • 扣减：每杯按配方克数扣黄酒 / 桂花 / 陈皮
  • 阈值：任一材料低于 1 份用量进购物清单
  • 出口：库存 API + 购物清单手机推送

主要实现路径

用 karlomikus/bar-assistant 自托管库存、配方与购物清单，HA 经 REST API 推缺料通知

参考项目

karlomikus/bar-assistant
