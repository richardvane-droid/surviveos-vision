产品模块 1. 27 格零件柜

零件柜是工作台靠墙那一排 27 个小木格，每格只放一种物件：火石、鱼线、别针、消毒片，几十个一格。它按“一格一物、从左到右”排布，装配时手沿一条线走，不用找也不用想。柜体用白蜡木拼板，格深压在 8cm 以内，手能捏到最后几个小件；格底垫 3mm 毛毡防滚动，格口贴激光刻的名称和数量条，一眼看出该补什么。

关键参数 / 组成

  • 27 格，每格 8×8cm，深度不超过 8cm
  • 白蜡木拼板柜体，横向格板 2 块、纵向格板 8 块榫槽插接
  • 格底 3mm 毛毡衬垫，防止火石鱼线滚动
  • 格口激光刻标签条：物件名 + 标准数量

产品模块 2. 头顶灯光机位总成

这是吊在台面上方的一根横梁，把照明和拍摄合成一个总成。两根吊杆从天花垂下，挂一根 30×30 铝型材横梁，线槽走电和网线；梁上装一盏 1.2m 长条灯和一只俯拍摄像头。灯装在靠前 20cm 处，光从手前方打来，手不会挡住自己；4000K 加显色指数 95 以上，毛毡颜色不偏。摄像头用球头座固定，正对台面中央的皮垫。

关键参数 / 组成

  • 30×30 铝型材横梁 + 线槽，两根天花吊杆固定
  • 1.2m 长条灯 4000K，显色指数 Ra≥95
  • 防眩格栅，坐在高脚凳上抬头不刺眼
  • 俯拍摄像头球头座，正对 A3 装配区

参考项目

联动逻辑 3. 一键录制组装

解决的问题是：组装一只盒子就是一条内容，但手动开录、停录、命名太麻烦。输入是台边一颗实体按钮、盒盖磁簧开关和俯拍机位的 RTSP 流；输出是按日期和盒号命名的视频加一条手机推送。核心判断是“合盖即结束”：按下按钮灯打到 100%，Frigate 开一个手动事件，合盖磁簧断开就停录归档；忘了合盖，30 分钟无人也自动停。

触发 · 阈值 · 兜底 · 出口

  • 触发：台边实体按钮，同时开灯 100% + 开录
  • 停录：合盖磁簧断开，或 30 分钟无人兜底
  • 命名：日期 + 盒号，直接进剪辑素材库
  • 出口：NAS 视频文件 + 手机推送含路径

主要实现路径

用 blakeblackshear/frigate 手动事件 API 开始/结束录制，HA 接按钮与磁簧，视频落 NAS

参考项目

blakeblackshear/frigatehome-assistant/core

联动逻辑 4. 耗材库存提醒

解决的问题是：27 种小物件消耗速度不一样，靠眼看总有一种先断货。输入是合盖磁簧信号和 InvenTree 里的 PSK 物料清单；输出是库存看板、采购清单推送和格口指示灯。核心逻辑是“合一次盖就是一张组装单”：27 种零件各减 1；按最近 30 天日均消耗折算，低于 14 天用量就进采购清单并让格口灯闪。周日盘点。

触发 · 阈值 · 兜底 · 出口

  • 触发：合盖磁簧，调 InvenTree build 接口扣减
  • 阈值：按 30 天日均消耗，低于 14 天用量提醒
  • 兜底：每周日盘点校正，人工数字覆盖系统
  • 出口：库存 API + 采购清单推送 + 格口指示灯

主要实现路径

用 inventree/InvenTree 的 BOM 与 build 接口扣减并判断低库存，HA 接磁簧驱动格口灯
