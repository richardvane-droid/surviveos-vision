钓具储物与展示：4 个核心模块与逻辑

一面防水洞洞板 + 一个老木箱，钓具不再乱塞，每一件都像展品。

1防水洞洞板储物墙2老樟木箱分格储物3磁吸亚克力饵盒阵4钓具借还与鱼获账本

产品模块 1. 防水洞洞板储物墙

洞洞板的原理很简单：一块板打满等距的孔，挂钩随插随换，东西越多越像一幅画。放在水边的难点在防水——普通密度板半年就吸水分层，所以用 18mm 防腐胶合板，正反两面各刷三遍船用清漆，孔壁也刷到。板顶加一块小木檐，雨天板面基本淋不到。孔距 25mm 是通用规格，竿托、S 钩都买得到；三组斜向竿托把六根鱼竿排成扇形，短竿在下长竿在上。

关键参数 / 组成

  • 防腐胶合板 1.2×1.8m，孔距 25mm 孔径 6mm
  • 船用清漆三遍，孔壁同刷，年补一遍
  • 顶部 20cm 木檐板挡雨，背面留 2cm 通风缝
  • 三组斜向竿托，六根鱼竿扇形排列

产品模块 2. 老樟木箱分格储物

一只闲鱼淘来的老樟木箱当主储物，不打磨不上漆，越旧越对味。樟木含樟脑，本身就是天然驱虫剂，线轮和浮漂放在里面不生虫不发霉。箱内用 6mm 薄木板拼一个六格井字架：线轮、铅坠、钩、浮漂、工具、杂物各占一格，格架可整体拎出来清理。木箱不能直接落在木平台上，垫两块青砖抬高让底板通风，否则先烂的一定是箱底。

关键参数 / 组成

  • 老樟木箱约 80×45×40cm，保留包浆不上漆
  • 六格井字分格架，6mm 薄木板可整体取出
  • 青砖垫高 6cm，底板通风防烂
  • 盖内贴分格示意图，物归原位

产品模块 3. 磁吸亚克力饵盒阵

路亚假饵又小又杂，这套系统把它们变成随手取放的“展品”。每个透明亚克力小盒背后粘一块 20mm 强磁，吸在洞洞板上钉的 3mm 铁板上；盒子按饵的颜色排成渐变，一眼找到今天要用的。铁板刷防锈漆，磁铁选镀镍钕磁，水边湿气重也不锈。旁边留一个铁皮小盒专放 PSK 生存盒的钓鱼组件，角落一块小黑板用粉笔记鱼获，写满拍照存档再擦。

关键参数 / 组成

  • 亚克力盒 60×60×25mm，背贴 20mm 镀镍钕磁
  • 3mm 铁板 40×60cm 刷防锈漆固定在洞洞板
  • 假饵按颜色渐变排列，铁皮盒放 PSK 钓鱼组件
  • 小黑板 30×40cm 记鱼获，写满拍照存档

联动逻辑 4. 钓具借还与鱼获账本

解决“这根竿上次钓了什么、那盒饵借给谁了”的问题。每根鱼竿和每盒假饵贴一枚二维码，出发前手机扫一下即“借出”，收竿扫一下即“归还”，钓具库里始终能看到哪件在墙上、哪件在谁手里。归还时顺手填一条鱼获：鱼种、饵、天气，黑板上的粉笔字就有了数字备份。数据攒多了，系统能统计出哪种饵在哪个月最好用，下次出发前先看一眼。

触发 · 阈值 · 兜底 · 出口

  • 触发：扫竿或饵盒上的二维码，切换借出 / 归还状态
  • 出口：钓具库存状态 + 鱼获统计（饵 × 月份）
  • 借出超 7 天未归还，推送提醒借用人
  • 兜底：黑板粉笔记录照常，拍照后补录

主要实现路径

用 m1ndgames/OpenFishing 的二维码钓具库和渔获记录做借还账本，cohenadair/anglers-log 做手机端统计
