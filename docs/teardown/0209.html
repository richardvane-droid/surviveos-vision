藏宝阁：4 个核心模块与逻辑

40cm 的帆布滑门一推，里面是一整面书格、一张写字台，和一墙不给人看的海报。

产品模块 1. 床下密室与帆布滑门

藏宝阁是在西北角架空床下围出来的一间密室：床板 1750、床下净高 1700，平面 1.5×2 米，两条 2 米长墙南北向，西侧那条直接借既有结构和外墙当靠山。围合用轻钢龙骨加 9mm 木饰面板，不承重，拆掉不影响床体。1700 的净高开不下平开门，也没有回转余地，所以入口做成一道 40cm 宽的帆布滑动门，开在东侧长墙靠南、离写字台最远的那一端：上方一根隐藏滑轨，帆布下沿坠一根配重杆，推开只要侧身的宽度，合上时贴墙压住光。

关键参数 / 组成

  • 平面 1.5×2m，净高 1700，床板 1750 就是它的天花
  • 轻钢龙骨 + 9mm 木饰面板围合，不承重、可拆
  • 东侧长墙南端一道 40cm 帆布滑门，隐藏滑轨 + 配重杆
  • 滑门合上贴墙压光，是密室与地堡之间唯一的开口

产品模块 2. 写字台与连续书格

家具按正经书房配：净高 1700 足够一个人坐直写字，就不必将就。北端 1.5 米短墙整面给一张标准写字台，台面高 740；配一把人体工学椅，选型的硬指标是总高不超过 1300mm，头枕和气压杆升到顶也不碰床板。西侧那条 2 米长墙贴既有结构做一整排连续书格，进深只有 180mm——浅格逼着书脊全部朝外，抬眼就能扫完，放的也只是最近常翻的书。尽端留一格塞铁皮宝箱；写字台一角明放瓷银茶器，磕碰和氧化的风险是主动接受的选择。

关键参数 / 组成

  • 写字台 1.5m 宽、台面高 740，正对北侧短墙
  • 人体工学椅总高 ≤1300mm，升到顶不碰床板
  • 西侧长墙 2m 连续书格，进深 180mm，层高 320 / 260 两档
  • 台角明放瓷银茶器，书格尽端一格放铁皮宝箱

联动逻辑 3. 环绕洗墙调光

这段逻辑管的是密室里唯一的光源：顶部沿四边绕一圈的 360° LED 洗墙灯带，色温 2700～3000K，分书格侧和海报墙侧两路独立供电与调光。输入是滑门上的磁簧开关和写字台下的一颗存在传感器，输出是两路的亮度配比。滑门一推，先给 40% 的迎接光；人在椅子上坐定切写字档，书格侧压到 25%、海报墙侧拉到 60%，光都打在墙面上，不直射眼睛也不在台面反光。核心判断是滑门开合加人在不在位，离位 15 分钟渐暗到 5%，再 30 分钟全灭。

触发 · 阈值 · 兜底 · 出口

  • 触发：滑门磁簧开 → 40% 迎接；人落座 → 写字档
  • 分路：书格侧 25% / 海报墙侧 60%，2700～3000K
  • 兜底：手动在网页调过亮度，1 小时内不自动干预
  • 数据出口：HA 两个 light 实体 + 每日进入次数

主要实现路径

两路灯带各一块 ESP32 刷 wled/WLED 存迎接 / 写字 / 收工三个预设，ESPHome 读滑门磁簧和座位存在传感器，HA 按状态切预设

参考项目

联动逻辑 4. 换墙与透气

这段逻辑管两件事：墙上贴什么，和什么时候该开门。素材平时用手机随手记进自托管的 memos，按名言、电影、对话三个标签分流——名言来自张岱《陶庵梦忆》、沈复《浮生六记》、陶渊明《归园田居》、李渔《闲情偶寄》，对话则是自己聊天里截下的金句；每季度按标签筛一批，打字机字体打在牛皮纸上换到海报墙，换下来的按日期收进铁皮宝箱。另一半是空气：密室不装通风装置，只在顶角挂一颗 CO2 传感器兜底，浓度爬过阈值就提醒推开滑门。

触发 · 阈值 · 兜底 · 出口

  • 三类标签：名言（张岱 / 沈复 / 陶渊明 / 李渔）、电影、对话
  • 每季度筛一批打印上墙，旧的按日期收进铁皮宝箱
  • 兜底：CO2 超 1200ppm 推送提醒开门，1500ppm 强提醒
  • 数据出口：HA 的 CO2 曲线 + memos 里的归档标签

主要实现路径

素材记进 usememos/memos 按三标签分流、换季用它的 API 导出筛选；CO2 用 esphome/esphome 读 SCD40 上报 HA 做阈值推送

参考项目

usememos/memosesphome/esphome
