哑铃：4 个核心模块与逻辑

一副可调哑铃、一块镜子、一根单杠，20 分钟就能把一天重启。

产品模块 1. 可调哑铃与铃架

可调哑铃用一副替代一整排：握把两端各有一组配重片，拧动把手上的选重旋钮，卡爪会咬住对应数量的片，抬起时没被咬住的片留在底座上。这样 2 到 32 公斤十几个档位只占一个底座的位置，正适合 2×3 米的地下健身角。底座是配重片的“停车位”，每片有自己的槽，放回去时必须对准槽才能换重，这也防止了片子散落。铃架用方管自己焊，两层：上层放哑铃底座，下层放壶铃，架脚垫橡胶，掉落时震动先被 2cm 地垫吸掉，再由架子分散。

关键参数 / 组成

  • 可调哑铃 2~32kg，2.5kg 一档，旋钮选重
  • 配重片铸铁 + 橡胶包边，底座槽位定位
  • 方管 40×40 焊接铃架，两层，脚垫橡胶
  • 2cm 橡胶地垫 2×3m，四边木条收口

产品模块 2. 墙装单杠与折叠仰卧板

地下层高有限，所以把上肢和核心训练都挂在墙上。单杠离地 2.1 米，用两片三角支架固定在承重墙的四颗 M12 膨胀螺栓上，杆是 32mm 钢管，杆面滚花防滑；安装前先量清楚，确保引体时头顶还有 30cm。仰卧板用铰链挂在单杠正下方的墙上，不用时折起只有 10cm 厚，放下来用一根撑杆支住脚端。镜子 1.8 米高贴在旁边墙上，角度与 0211 大屏错开 15° 避免反光，镜顶一条灯带跟 0201 的场景联动。木凳、水壶架、毛巾钩挤在墙角，练完不用走开。

关键参数 / 组成

  • 单杠 32mm 钢管，离地 2.1m，M12 膨胀螺栓 ×4 承重 150kg
  • 折叠仰卧板铰链上墙，收起厚 10cm
  • 1.8m 高镜子，与大屏错开 15°，镜顶灯带
  • 木凳 + 水壶架 + 毛巾钩，一体挂墙

联动逻辑 3. 训练模式心率上屏

训练开始后，0211 的大屏应该只显示两样东西：心率和计时。输入是手环的蓝牙心率广播，主机旁的 ESP32 用 BLE 接收，把每秒心率转发成 HA 实体。逻辑的触发条件是“人在健身角 + 心率超过 100”：健身角的 PIR 有动作并且心率持续 30 秒高于 100，大屏自动切到训练模式，黑底、超大数字、按心率区间变色（绿 < 120、黄 120~150、红 > 150），旁边一个计时器从切换那一刻开始跑。心率回落到 100 以下持续 5 分钟，或人离开，就切回普通仪表盘，并把这次训练的时长和平均心率写进记录。

触发 · 阈值 · 兜底 · 出口

  • 触发：健身角 PIR 有人 + 心率 > 100 持续 30 秒
  • 阈值：心率区间绿 < 120 / 黄 120~150 / 红 > 150
  • 兜底：手环断连 60 秒后计时继续，心率显示为“--”
  • 数据出口：HA sensor.heart_rate + 每次训练时长与均值

主要实现路径

esphome/esphome 的 BLE 客户端读手环心率特征值上报 HA，HA automation 判断切换仪表盘视图，训练记录通过 wger-project/wger 的 API 写入

联动逻辑 4. 训练计数与周进度

墙上那张手写周计划打钩最有成就感，但组数和重量还是得有地方记。这段逻辑用一块放在铃架上的小按键板做输入：每做完一组按一下，长按切换动作，重量从旋钮旁的一个小拨码开关读。每按一次，HA 就在当天记录里加一组，累计到计划的组数时按键板上的小灯亮绿。一天练完，所有动作的组数和重量打包写进 wger 的训练日志，wger 按周汇总出“计划 5 天完成 4 天”的进度，大屏训练模式退出时显示一次。核心判断是“组数达标才算完成一天”，只做了一半的日子不算勾，跟白板上的规则一致。

触发 · 阈值 · 兜底 · 出口

  • 触发：按键板单击 +1 组，长按切换动作
  • 阈值：组数 ≥ 计划组数才算当天完成
  • 兜底：按键板离线时用手机 Flexify 补记
  • 数据出口：wger 训练日志 + HA sensor.week_progress

主要实现路径

ESPHome 按键板上报 HA counter，一天结束后 HA 调 wger-project/wger 的 workout API 写日志并读周汇总；离线时用 brandonp2412/Flexify 手机端补记

参考项目
