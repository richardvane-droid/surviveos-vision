CNC 五轴雕刻机：4 个核心模块与逻辑

一台 3+2 定位的桌面五轴：三根直线轴加一只双旋转分度头，铝型材做骨，开源固件当脑。

🚧 真实项目需求收集中 产品模块 2 联动逻辑 2

产品模块 1. 铝型材龙门机架

整台机器的骨架按 0805 的规格用欧标喷砂黑型材拼：底座是 4040 做的矩形框，两侧立柱和横梁用 3030，龙门在 Y 向的两根直线导轨上前后走，主轴滑块在横梁上左右走，Z 轴挂在滑块上上下走。型材机架最怕的是刚性不够导致切削时发抖，所以角部全部用内置角槽件加角码双重锁定，导轨座直接压在型材面上而不是打印件上；台面用一块 300×300 的铝 T 槽板，工件和分度头都靠 T 槽压板固定。

关键参数 / 组成

  • 底座 4040、立柱横梁 3030、附件 2020，全部喷砂黑欧标
  • 行程 300×300×120，X/Y 1605 滚珠丝杠 + HGR15 导轨
  • 42 闭环步进 ×3，丢步自动报警
  • 台面 300×300 铝 T 槽板；整机目标 ≤60kg（阁楼承重待核）

参考项目

FreddieHong19/Open5x

产品模块 2. A/C 双旋转分度头

让三轴机器变成“3+2”的关键零件：一只小型双轴分度头，A 轴让工件绕水平轴翻转（±110°），C 轴让工件绕垂直轴旋转（360°），两根轴各由一台带蜗轮蜗杆减速的步进驱动，蜗轮自锁，切削时不会被刀推动。它不参与联动，只在换面时按 G 代码转到指定角度再锁住，所以对精度的要求是“回得准”而不是“转得快”。头顶一只三爪小卡盘或一块 100mm 的小 T 槽板夹工件。

关键参数 / 组成

  • A 轴 ±110°、C 轴 360°，蜗轮蜗杆 1:50 自锁
  • 两台 42 步进 + 编码器，回零靠光电开关
  • 顶部 100mm 小 T 槽板 / 三爪卡盘可换
  • 接 grblHAL 的 A、C 轴口，作定位轴不联动

参考项目

grblHAL/core

联动逻辑 3. 3+2 定位加工流

一个零件从模型到成品的流程：CAM 里把零件的每个加工面定义成一个“姿态”（A、C 两个角度），每个姿态下生成一段普通三轴刀路；后处理把它们串成一个程序，段与段之间插入 A/C 转位和一次刀具长度补偿。机器执行时先转位、再让主轴抬到安全高度、然后跑三轴刀路。这样不需要真五轴联动的运动学，用 grblHAL 就能跑，错误也容易查——每一段都是能单独看懂的三轴程序。

触发 · 阈值 · 兜底 · 出口

  • 触发：CAM 导出带姿态段的 G 代码
  • 每段前：主轴抬到安全高 → A/C 转位 → 等待锁定信号
  • 换面后用探针重测 Z 零点，误差 >0.05mm 报警
  • 失败兜底：门开 / 丢步 / 主轴过流任一触发即进给暂停

主要实现路径

FreeCAD Path 或 Fusion 出各姿态刀路，自写后处理拼接；grblHAL 用 A/C 轴做定位并用 M 代码触发探针重测

参考项目

grblHAL/coreLinuxCNC/linuxcnc

联动逻辑 4. 功率与除尘联动

机器一开，两件事要跟着动：一是电，主轴 + 步进峰值约 2kW，必须先问 0304 光伏储能“现在能不能给”，电池低于阈值或正在给电摩充电就只允许低功率模式；二是灰，主轴转起来之前 0404 木工间的集尘器要先启动并把阁楼这一路的阀门打开，主轴停后延时 30 秒再关。两条都由 HomeAssistant 做判断，机器本身只暴露“主轴请求启动”和“主轴已停”两个信号。

触发 · 阈值 · 兜底 · 出口

  • 主轴启动请求 → 查储能 SOC 与当前负载 → 允许 / 限功率 / 拒绝
  • 允许后先开集尘 + 阁楼分路阀，3 秒后才通主轴
  • 主轴停 → 集尘延时 30 秒关阀；VOC / 粉尘超标推送
  • 数据出口：HA 里的 cnc_power_mode 与 cnc_runtime 实体

主要实现路径

ESPHome 读主轴继电器状态与电流互感器，HA 自动化查 0304 的 SOC 实体并联动 0404 集尘分路阀（参考 HAsmartirrigation 之类的阈值判断写法）
