CNC 雕刻机：4 个核心模块与逻辑

一台三轴雕刻机，两条还没选的路线：木和亚克力走一条，铝走另一条，主材没定就不下单。

产品模块 1. 龙门机架与两条刚性路线

整台机器的骨架用 0805 定标的欧标喷砂黑型材拼成龙门式：底座是矩形框，两侧立柱托着横梁，龙门在 Y 向导轨上前后走，主轴滑块在横梁上左右走，Z 轴挂在滑块上上下走。型材机架最怕刚性不足导致切削发抖，而需要多少刚性取决于切什么：木和亚克力一条路线，铝一条路线，两条路线的型材截面完全不同。主切材料没拍板之前，截面和导轨规格都不定标。

关键参数 / 组成

  • 木 / 亚克力路线：2020+3030 底座与横梁，行程 300×300×100
  • 铝路线：全 4040 + 钢板加强底座，行程收到 200×200×80
  • X/Y 1605 滚珠丝杠 + HGR15 导轨，闭环 42 步进 ×3
  • 角部用内置角槽件加角码双重锁定；整机目标 ≤60kg（楼板承重待核）

产品模块 2. 主轴与变频选型（待定）

主轴是这台机器上最贵也最难改的一件，它的功率、转速区间和冷却方式直接跟着主切材料走。木和亚克力要的是高转速、小吃刀，500W 风冷主轴配 ER11 夹头就够，噪音和维护都省心；铝要的是扭矩和持续负载，1.5kW 水冷主轴加 VFD 变频器，还得配一套水箱和管路。两条路线的 VFD 型号、线径、电流保护都不一样，所以在主材拍板之前不下单，先用借来的主轴把整条流程跑通。

关键参数 / 组成

  • 木 / 亚克力：500W 风冷，ER11，转速 12000～24000rpm
  • 铝：1.5kW 水冷 + VFD 变频器 + 水箱管路，转速 8000～18000rpm
  • VFD 走 RS485 / Modbus 由固件调速，不用手动旋钮
  • 主材未定前只租借试切，不采购主轴与变频器

联动逻辑 3. grblHAL / FluidNC 三轴控制与限位安全

三轴不需要复杂运动学，开源的 Grbl 系固件就够：grblHAL 跑在 Teensy 4.1 上，或者 FluidNC 跑在一块 ESP32 上，两者都兼容 Grbl 的串口协议，上位机用 cncjs 发送 G 代码。固件负责 G 代码解析、前瞻加减速和步进脉冲输出，同时管三类安全信号：限位开关定行程、防护门磁开关做安全门输入（门一开立刻进给暂停并停主轴）、探针做刀长与工件 Z 零点测量。发送端跑在机旁的小主机或平板上，不接中枢。

触发 · 阈值 · 兜底 · 出口

  • 触发：cncjs 从机旁小主机 / 平板下发 G 代码，串口或网口进固件
  • 限位 + 门磁 + 探针三路信号直接接固件，安全逻辑不走网页
  • VFD 主轴经 RS485 / Modbus 由固件调速，M3/M5 控启停
  • 失败兜底：门开、丢步、主轴过流任一触发即进给暂停并抬刀

主要实现路径

grblHAL/core 配 Teensy 4.1 或 bdring/FluidNC 配 ESP32 跑三轴，门磁与探针接固件硬件输入，cncjs 在机旁小主机上做发送端

联动逻辑 4. 功率与排屑联动

机器一开，两件事要跟着动：一是电，主轴加步进峰值约 2kW，必须先问 0304 光伏储能现在能不能给，电池低于阈值或正在给电摩充电就只允许低功率模式；二是屑，主轴转起来之前 0404 木工间的集尘器要先启动并把阁楼这一路的阀门打开，主轴停后延时 30 秒再关。木屑和铝屑走不同的分路阀和集尘桶，绝不混用。两条都由 HomeAssistant 判断，机器只暴露主轴请求启动和主轴已停两个信号。

触发 · 阈值 · 兜底 · 出口

  • 主轴启动请求 → 查储能 SOC 与当前负载 → 允许 / 限功率 / 拒绝
  • 允许后先开集尘 + 阁楼分路阀，3 秒后才通主轴
  • 木屑与铝屑分路阀与集尘桶分开，切铝时不许走木屑桶
  • 数据出口：HA 里的 cnc_power_mode 与 cnc_runtime 实体

主要实现路径

ESPHome 读主轴继电器状态与电流互感器，home-assistant/core 的自动化查 0304 的 SOC 实体并联动 0404 集尘分路阀

参考项目

home-assistant/core
