产品模块 1. Voron 2.4 机架与运动系统

Voron 2.4 是一台开源的 CoreXY 打印机：两条交叉的皮带驱动打印头在 X、Y 平面上跑，电机固定在机身上不跟着动，惯量小所以能开高速。热床由四根丝杠同步升降，开机自动扫描床面并补偿倾斜。骨架是铝型材加板材做成的封闭腔体，腔温保得住，才敢打 ABS、ASA 这类会翘边的材料。整机按官方 BOM 自己配件、自己拧，一两百个结构件要用 ABS 打印，所以第一批件必须找别人代打。

关键参数 / 组成

  • CoreXY 皮带 + 250 方案，行程 250×250×250
  • 四丝杠同步升降热床，开机自动调平补偿
  • 铝型材骨架 + 板材封闭腔体，腔温可到 50℃ 以上
  • 结构件 ABS 打印 100+ 件，第一批需代打

产品模块 2. 铝型材工作站与人体工学高度

围着打印机搭的一张一体工作站，用 0805 定标的欧标喷砂黑型材：3030 做立柱和横梁，2020 做层板与附件，占地约 0.5×0.5m。它解决参考方案的两个毛病：一是把腔口中心抬到 1100～1200，站着平视就能看进打印仓，不用蹲下去；二是侧板改成铰链加磁扣的可翻式，清碎屑时整块翻开，而不是固定死。台面和滑轨接触面铺一层木板，因为黑色阳极氧化型材一划就露白。

关键参数 / 组成

  • 3030 立柱横梁 + 2020 层板，占地约 0.5×0.5m
  • 腔口中心 1100～1200，站姿平视操作
  • 侧板铰链 + 磁扣可翻开，方便清碎屑
  • 台面与摩擦面覆木板，避免型材划伤露白

产品模块 3. 腔体排风与耗材干燥

全封闭腔体打 ABS 时会散发微粒和气味，在阁楼这种斜顶小空间会闷一整天，所以腔体顶部开一个 100mm 排风口，接铝箔管横过天花 1.5 米到天窗边的排气口，中段装一台 12V 静音管道风扇，打印开始自动开、结束后再抽十分钟，管里加一片活性炭滤棉。工作站下层是一只带加热的耗材干燥箱，可以边烘边打，ABS 和 PETG 吸潮后会炸响、拉丝、层间结合变差，阁楼温差大更容易吸潮。

关键参数 / 组成

  • 100mm 铝箔排风管 + 12V 静音风扇，排气口在天窗边
  • 打印开始联动开风扇，结束延时 10 分钟；活性炭滤棉 3 个月一换
  • 下层加热干燥箱可边烘边打，目标 <15% RH
  • 排风未装好前一律不打 ABS，只打 PLA

联动逻辑 4. Klipper 上位机与打印监看

自建机的固件用 Klipper：主板上的单片机只负责按时间戳打步进脉冲，解析 G 代码和运动规划交给一台 Linux 电脑上的 klippy 主程序——这里就是 0804 那台常驻的 M1 Mac。中间隔一层 Moonraker API，前端用 Mainsail 网页：上传 G 代码、点动、看温度曲线、看摄像头、改 printer.cfg 都在浏览器里。所有参数集中在一个文本文件，改完重启就生效，不用重新编译固件。

触发 · 阈值 · 兜底 · 出口

  • 触发：Mainsail 网页或 OrcaSlicer 经 Moonraker 直发任务
  • klippy 跑在 0804 常驻 M1 Mac，主板只跑 MCU 固件
  • 装完先跑共振测量出输入整形参数，再调压力提前
  • 出口：开始 / 结束 / 失败经 Moonraker 推 HomeAssistant，摄像头看层数

主要实现路径

Klipper3d/klipper 的 klippy 跑在 0804 的 M1 Mac 上，mainsail-crew/mainsail 做网页前端，OrcaSlicer 经 Moonraker 直发

联动逻辑 5. 耗材账本与接屑清理

每卷线材登记进自托管的 Spoolman：厂商、材质、颜色、初始重量、开封日期，打印结束后 Moonraker 把这一单消耗的克数回写，剩余量自动扣减，标签上的剩余克数不用再手写。剩余低于 150g 提醒补货，库存超过八卷就提示先用完再买。另一半是物理清理：工作站下层那块接屑盘能整块抽出，翻开侧板把碎屑扫进去端走倒掉，每次换料或拆件之后顺手做一次。

触发 · 阈值 · 兜底 · 出口

  • 输入：每卷初始重量 + Moonraker 回写的每次用量
  • 阈值：剩余 <150g 提醒补货；库存 >8 卷提示停买
  • 出口：Spoolman 网页看板 + 耗材架上的二维码标签
  • 兜底：每月称重校准一次；接屑盘每次换料后抽出清空

主要实现路径

用 Donkie/Spoolman 记每卷剩余克数，跑在 0804 的 M1 Mac 上，Klipper3d/klipper 侧由 Moonraker 的 spoolman 组件自动扣减
