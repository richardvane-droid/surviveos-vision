爬山虎墙：4 个核心模块与逻辑

木屋朝南的那面砖墙交给爬山虎，夏天降温三度，秋天整面墙红得像着火。

⬜ 真实项目待设计 产品模块 2 联动逻辑 2

1种植带与引蔓横杆2透光地灯组3墙脚滴灌器4四季延时机

产品模块 1. 种植带与引蔓横杆

爬山虎靠吸盘攀附砖面，不需要网架，真正要设计的是墙脚和墙顶。墙脚沿木屋南墙外那 5 米宽的砖墙、避开门口挖一条 40cm 宽的种植带，底层铺 5cm 陶粒排水，再回填掺了腐叶土的园土，每 80cm 种一株三叶地锦；2.2 米高处架一根 3 米长的毛竹横杆，用角铁托住，藤蔓爬到杆就顺杆横向铺开，被拦在阁楼屋面之外；门框窗框外 20cm 剪干净。预留一块 60×60cm 的“观察窗”，用一圈薄铁皮框住不让藤爬。

关键参数 / 组成

  • 种植带沿墙 ≈4m×0.4m（门口断开），底铺 5cm 陶粒，上填腐叶土
  • 三叶地锦每 80cm 一株，第一年可爬 1.5m
  • 毛竹横杆 3m，角铁托架固定在 2.2m 高处
  • 60×60cm 观察窗用铁皮框隔离

产品模块 2. 透光地灯组

绿墙晚上的看点是叶脉。墙脚埋两盏 3000K 暖光地灯，光从下往上打在叶子背面，叶子成了半透明的灯罩，叶脉和藤须的影子全在墙上。地灯选 IP67 的埋地款，装在直径 10cm 的预埋套筒里，套筒底部留排水孔，杭州的暴雨不会把它泡坏。每盏 3W 足够，太亮反而一片白。开关接 HomeAssistant，日落自动亮，夜里十一点自动灭。

关键参数 / 组成

  • 3000K 暖光 IP67 埋地灯，3W×2，间距 2.5m
  • 预埋 PVC 套筒 φ10cm，底部留排水孔
  • 光束角 30°，朝上斜 15° 打叶背
  • 24V 供电，HA 日落亮、23:00 灭

联动逻辑 3. 墙脚滴灌器

爬山虎成熟后几乎不用管，但头两年的根系还浅，杭州七八月一周不下雨就会卷叶。这段逻辑用一块 ESP32 加太阳能板、一颗电容式土壤湿度探头和一台 12V 小水泵，全装在种植带边上的一只防水盒里，不从屋里拉水拉电。每小时醒一次读湿度，低于阈值且当天没浇过就开泵 90 秒，从雨水罐往滴灌带送水；连续三次浇后土壤都不变湿，说明水罐空了或管断了，推送提醒。

触发 · 阈值 · 兜底 · 出口

  • 触发：每小时读土壤湿度，<35% 且今日未浇则开泵
  • 单次 90 秒，每天最多 2 次，雨天（HA 天气）跳过
  • 兜底：浇后湿度不涨 3 次判故障并推送
  • 出口：湿度曲线与浇水记录进 HA

主要实现路径

照 Lumics/Plantwatery 的 ESP32 + 太阳能 + 电容探头 + 水泵方案做硬件，ESPHome 本地判断阈值，HA 记录曲线

参考项目

Lumics/Plantwatery

联动逻辑 4. 四季延时机

同一个机位、每天同一时刻拍一张，一年 365 张连起来就是一条 30 秒的四季延时。核心难点不在拍，而在一致：机位固定、构图固定、曝光要跟着季节的光变化。实现是把一只树莓派摄像头装进对面石墩旁一根立柱顶的防水盒，每天正午自动拍一张，程序按日出日落自动调曝光，照片按日期命名同步到家里的 NAS。每月月底自动合成一段预览，秋天变红那几周可加密到每天三张。

触发 · 阈值 · 兜底 · 出口

  • 触发：每天 12:00 定时拍一张，日出日落自动调曝光
  • 机位固定在南端石墩旁的立柱上，防水盒 + 遮光罩
  • 出口：照片按日期同步 NAS，每月自动合成预览
  • 兜底：拍摄失败或文件过小则推送提醒

主要实现路径

用 pageauc/pi-timolo 的定时抓拍与自动曝光做拍摄和同步，年末用 ffmpeg 合成 30 秒视频
