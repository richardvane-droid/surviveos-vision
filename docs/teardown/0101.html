产品模块 1. 胡桃木展台与黑胡桃托盘

展台是整间木屋的“祭坛”，台上只有一张 PSK 卡和它展开后的那套小件。它不落地，而是悬挑在北墙、作品九宫格正下方：两块手刨胡桃木托架用膨胀螺栓咬进墙里，上面是一层放历代原型卡的薄抽屉和一块前低后高倾斜 12 度的台面。台面中央嵌一块黑胡桃托盘，左半是收起态的卡位，右半是十来件小件按爆炸图排布的浅坑，一收一开对照着看。卡极薄，毛毡内衬因此改到 1.5mm 只压四边，槽口开一个指槽，手指一按卡就翘起来。

关键参数 / 组成

  • 外形 135×35cm 挂墙悬挑，台面高 900，倾斜 12°
  • 黑胡桃托盘 30×20cm：左卡位，右十来件小件爆炸位
  • 毛毡内衬 1.5mm 只压四边，留 18mm 指槽好抠卡
  • 黄铜铭牌 40×18mm，蚀刻 PSK Card No.1 与年份

产品模块 2. 掠射射灯与放大压片

照一张卡和照一只盒子是两回事：卡太薄，顶光直打只剩一片反光。所以这盏 3000K 射灯仍装在北墙上方那道梁的梁底，灯头却压到很低的角度，光几乎贴着托盘掠过去，刻痕、开瓶口、火石槽各自拖出一道影子，厚度才被看见。灯头按博物馆布光拆成六层：可旋转的梁底安装座、0-10V 调光的恒流驱动器、能俯仰的云台关节、带散热鳍的 COB 灯体、限制光束角的蜂窝防眩罩，以及扣在外侧的毫米波存在传感器小板。

关键参数 / 组成

  • COB 灯珠 3000K，显色指数 Ra≥95，功率 12W
  • 蜂窝防眩罩 15° 窄光束，入射角压到 15~25° 掠射
  • 云台俯仰 ±45°，0-10V 调光，2 秒渐亮渐暗
  • 三倍放大压片可翻下，翻下时距卡面约 25mm

参考项目

联动逻辑 3. 人近感应亮灯

解决的问题是：展台的光只在自己站到它面前时亮，其余时间留黑，既省电也保留“走近才亮”的仪式感。输入是毫米波传感器上报的存在状态和环境照度，输出是掠射射灯的目标亮度。核心判断是“有人且环境够暗”才亮，人离开后给 3 分钟宽限。凑近看一张卡本来就是一动不动的姿势，站着不动不会被误判成离开，这正是选毫米波而不是红外的原因。

触发 · 阈值 · 兜底 · 出口

  • 触发：展台前 3m 内检测到存在，且环境照度低于 30lx
  • 亮灯 2 秒渐亮到 80%，灭灯 5 秒渐暗到 0
  • 宽限：无人后计时 3 分钟，期间再检测到即续期
  • 兜底：传感器离线时按日落到 23 点定时常亮

主要实现路径

用 everything-presence-lite 的 ESPHome 配置读毫米波存在与照度，HA 自动化控制射灯

联动逻辑 4. 侧屏轮播调度

展台前脸那块 7 寸小屏要做到“插电就放，没人管也不会停”。输入是 U 盘或网络共享目录里的视频和图片，输出是屏幕上循环播放的内容。树莓派开机自启，按文件名顺序读播放列表；平时静音放图片幻灯——这张卡从收起到展开的分解图、每件小件的用途说明；展台前有人时切到有声的野外实测视频，无人半小时后屏幕休眠。新素材拷进目录，凌晨自动重载，不用重新设置。

触发 · 阈值 · 兜底 · 出口

  • 触发：树莓派上电自启，无需登录和人工操作
  • 有人：播放实测视频；无人：展开分解图幻灯每张 8 秒
  • 无人 30 分钟屏幕休眠，再有人 1 秒内唤醒
  • 素材：U 盘或共享目录，凌晨 4 点热重载

主要实现路径

用 Screenly/Anthias 开机自启循环播放，HA 按存在状态调它的 API 切播放列表

参考项目

Screenly/Anthias
