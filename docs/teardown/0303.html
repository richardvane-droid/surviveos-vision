帐篷区：4 个核心模块与逻辑

产品模块 1. 常驻双人帐篷总成

一顶约 2.35 米 × 2.16 米的帐篷搭在阁楼间可站立核心区偏西，门朝东南斜对天窗，永远不拆。思路是把露营的“睡眠系统”原样搬进屋：底层 3cm 泡沫拼接地垫隔凉隔震，中间 5cm 自充气垫承托身体，最上层是羽绒睡袋。室内不用防风防雨，所以只搭轻量铝杆内帐，外帐省掉，天窗的光和雨声直接透进来。侧面网兜放书和耳机，门口小地毯做分界。

关键参数 / 组成

  • 帐篷约 235×216cm，铝杆内帐，不挂外帐
  • 地垫 3cm 泡沫 + 5cm 自充气垫，两层缓冲
  • 门朝东南对天窗，整顶待在 2060 可站立区内
  • 侧网兜放书和耳机，门口地毯 + 拖鞋

产品模块 2. 5V 帐篷灯光组

帐篷里所有灯都走 5V USB，不用 220V，安全第一。5 米暖黄串灯换成 WS2812 可寻址灯带，由一块 ESP32 刷 WLED 固件控制，手机上调色调亮度，还能做“星空闪烁”和“呼吸”效果；顶部一盏圆形露营灯做主光，最低档就是夜灯。整组灯从光伏储能的 USB 口取电，功率不到 10W，一晚上用不到 0.05 度电。

关键参数 / 组成

  • WS2812 灯带 5 米 + ESP32 刷 WLED
  • 露营灯 USB 充电款，三档亮度可调
  • 整组灯功率 <10W，全部从储能 USB 口取电
  • 灯带沿帐篷顶内侧走，磁吸挂钩固定

产品模块 3. 天窗电动遮光帘

天窗遮光帘不用买智能款，用一颗 28BYJ-48 步进电机加几件 3D 打印的支架和卷轴接头，就能把普通卷帘改成 HomeAssistant 里的 cover 实体。ESP32 跑 ESPHome，记住上下两个端点，早上 7 点自动卷起让阳光进帐篷，雨天由气象站联动关上。电机功率很小，从储能的 USB 口取电就够，断电时还能手拉。

关键参数 / 组成

  • 28BYJ-48 步进电机 + ULN2003 驱动板
  • 3D 打印卷轴接头和电机支架，由 0305 打印
  • ESPHome cover 实体，记忆开 / 关两端点
  • 手拉备用：断电时可手动卷帘

参考项目

联动逻辑 4. 帐篷场景调度器

把帐篷区的灯、帘、声音串成几个“场景”，由 HomeAssistant 按时间和天气自动切换。早上 7 点：天窗帘卷起、串灯关闭；晚上 10 点：串灯调到暖黄 20%、露营灯夜灯档；收到 0306 的下雨事件：帘关上、白噪音机播雨声混篝火；梅雨季湿度高时切除湿模式。每个场景是一组实体状态，一键覆盖，随时能手动打断。

触发 · 阈值 · 兜底 · 出口

  • 触发：时间点 / 0306 下雨事件 / 人进帐篷
  • 四个场景：晨起 · 夜读 · 雨夜 · 梅雨
  • 动作：WLED 灯效 + 天窗帘 + moodist 音景
  • 兜底：手动开关优先，30 秒无响应回退默认

主要实现路径

HA scene 编排：灯效调 wled/WLED 的 JSON API，音景开 remvze/moodist 预设，帘走 ESPHome cover
