稀树草原环境系统：4 个核心模块与逻辑

一片不用割的草原，几棵歪脖子树，风一吹整片草浪往一个方向倒。

产品模块 1. 地埋滴灌草原植床

草原带不是铺草皮，而是一块按层做出来的“植床”。最底下是原土掺粗砂的排水层，梅雨季芒草根不泡水全靠它；往上 15cm 埋一圈带内嵌滴头的滴灌管，水直接渗到根区，表面一滴不飞；再上是种植土，细叶芒、狼尾草、蓝羊茅按比例混播；最表面盖一层蒲席草，压籽保湿，也遮住出土口。整床没有一条直线，但每株的位置都在图纸上。

关键参数 / 组成

  • 排水层：原土掺三成粗砂，翻深 30cm
  • 滴灌管埋深 15cm，滴头间距 30cm，流量 1.6L/h
  • 混播比例：细叶芒 5 · 狼尾草 3 · 蓝羊茅 2
  • 蓝羊茅怕涝，垫高 5cm 种

产品模块 2. 疏林带朴树护根圈

疏林带只种 3 棵朴树和 1 棵乌桕，间距 4m 以上，故意挑歪脖子苗，草原感全靠这几棵树的姿态。每棵树根部做一个“护根圈”：树穴底垫碎石排水，根球用三角木桩撑住，歪着长也不倒；滴灌管在这里露出唯一的 3cm 出土口，环根球绕一圈；上面铺 8cm 厚碎树皮，保湿压草，二月割下的草秆也垫在这里。树皮慢慢腐烂就是肥。

关键参数 / 组成

  • 树穴 80cm 见方，底垫 10cm 碎石排水
  • 三角木桩支撑，麻绳绑扎，两年后拆
  • 滴灌出土口只露 3cm，环管绕根球一圈
  • 碎树皮护根圈直径 1m、厚 8cm，每年补一次

产品模块 3. 碎石干河道与看草石

草地和庭院之间不立围栏，用一条 30cm 宽的碎石“干河道”分隔。这是枯山水里的老办法：挖 20cm 浅沟，铺防草布，先填粗砾再铺河卵石，平时是一条石头河，暴雨时真有水在石缝里流，把雨水罐溢流和草地积水一起排走。河道旁半埋一块 60×80cm 青石当“看草石”，旁边压一块桧木牌手写各分区植物名，这是整片草原唯一的坐标。

关键参数 / 组成

  • 沟宽 30cm 深 20cm，底铺防草布防泥沙上翻
  • 粗砾垫层 10cm，面层 3~8cm 河卵石
  • 青石 60×80cm，埋入三分之一，坐面朝草原
  • 桧木名牌 15×25cm，烙印分区植物名

联动逻辑 4. 分区养护日历

草原的麻烦不在活多，在于“什么时候该做哪件事”容易忘。这段逻辑把三个分区的植物档案（各自的割、补播、覆盖月份）和气候节点合在一起，按月生成养护任务：二月底连续 3 天无雨才贴地割草，梅雨前查干河道排水，六月野花补播，十一月补树皮。任务进 HomeAssistant 日历，到期推送手机，完成打勾，一年就是一本成长日志。

触发 · 阈值 · 兜底 · 出口

  • 输入：三区植物档案 + 当地气候节点
  • 关键判断：割草前看未来 3 天无雨且气温 >5℃
  • 出口：HA 日历 + 手机推送 + 完成打勾
  • 兜底：桧木名牌背面手写全年月份表

主要实现路径

用 Ecohackerfarm/powerplant 的种植时间表建三区植物档案，任务写进 HA 本地日历按月推送
