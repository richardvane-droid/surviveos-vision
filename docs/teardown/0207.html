产品模块 1. 98 寸电视挂墙总成

影音室的“大屏幕”不是幕布，是南侧梁下那面隔墙上的 98 寸电视：宽 220，正好塞进梁底 2400 以下的墙面。隔墙是砖墙，先固定一块钢制壁挂底板，四颗 M10 膨胀螺栓分摊近 60 公斤的整机重量，电视用 VESA 800×400 挂臂挂上去，可以前倾几度对准沙发。电视背面贴一圈约 300 颗的可寻址灯带，给跟色灯用。电视下方一条 220×40 的实木矮机柜放功放、播放器和唱盘，HDMI 和电源线从机柜后面沿隔墙暗管上到电视，正面看不到一根线。地堡没窗、够黑，电视不用抗反光屏，普通 4K 面板画面反而更准。

关键参数 / 组成

  • 98 寸 4K 电视，宽约 220cm，重约 60kg
  • 钢制壁挂底板 + M10 膨胀螺栓 ×4，VESA 800×400 挂臂
  • 观影距离 ≈2.5m（沙发到隔墙），线缆走隔墙暗管
  • 电视背面约 300 颗 WS2812 灯珠，供跟色灯用

产品模块 2. 低音炮减震座

第二排座位没有了（沙发到隔墙只有 2.5 米），但低音炮还是需要一个“减震座”。小房间的低频容易跟墙体和地面共振，整个地堡嗡嗡响，所以低音炮不直接落地，而是坐在一块分四层的独立底座上：最底是 20 毫米橡胶减震垫，隔开水泥地面；上面是一只填干砂的木箱底座，靠质量把振动吃掉；箱顶四角各一只弹簧减震器，托着一块 18 毫米多层板托板；低音炮放在托板上。整座塞在电视矮机柜西端旁边、写字台南头的角落里，占地不到 40×40。低音从地板传上来是“胸口发麻”的震动，而不是墙壁的轰鸣。

关键参数 / 组成

  • 橡胶减震垫 20mm 隔离水泥地面
  • 木箱底座填干砂，约 25kg 配重
  • 弹簧减震器 ×4，托板 18mm 多层板
  • 占地 ≈40×40，塞在电视矮机柜西端旁

联动逻辑 3. 观影场景

墙上那个铜色按钮按下去之后发生的所有事，就是这段逻辑。它先让 0201 模拟阳光用 90 秒从黄昏落到零，眼睛不会被突然的黑吓到；接着电视开机、功放上电预热、Kodi 打开片库、东南角门口留 5% 夜灯；0203 新风切到静音档但不关，两小时提醒通风一次。之后程序监听播放状态：暂停时灯光回到 20%，去倒咖啡不用摸黑；续播再全暗；结束时整个流程倒放，灯光慢慢回升。输入是一个按钮或一句语音，输出是六个设备的有序动作。

触发 · 阈值 · 兜底 · 出口

  • 触发：铜按钮或语音，先落日 90 秒再开电视
  • 暂停时灯光回到 20%，续播 3 秒内回全暗
  • 新风静音档不关，每 2 小时提醒通风一次
  • 结束流程倒放，功放冷却 2 分钟后再断电

主要实现路径

用 HomeAssistant 场景串联 0201 灯光、电视和功放，播放状态从 xbmc/xbmc（Kodi）的 media_player 实体读取，片库由 jellyfin/jellyfin 提供

联动逻辑 4. 电视跟色灯

让电视背后的灯带跟着画面颜色变，画面的红从电视边缘漫到隔墙上，地堡全黑的环境下沉浸感翻倍。做法是把播放器的 HDMI 信号分流一路进 USB 采集卡，以 1080p、每秒 30 帧抓画面；软件把画面四条边各切 60 段，共 240 段，每段取平均色，再按灯带布局表映射到 300 颗 LED 上，加上平滑和亮度上限，由 WLED 控制器刷新，延迟低于 50 毫秒。整帧接近黑或只有字幕时自动熄灯，不会闪成迪厅；它随观影场景一起开关。

触发 · 阈值 · 兜底 · 出口

  • HDMI 分流 + USB 采集卡，1080p 30fps 取色
  • 四边各 60 段共 240 段平均色，映射 300 颗 LED
  • 黑场 / 字幕自动熄灯，500ms 淡出
  • 延迟 < 50ms，随观影场景一起开关

主要实现路径

用 hyperion-project/hyperion.ng 在 N100 上取色和映射，输出走 WLED 协议驱动电视背后的灯带，开关由 HomeAssistant 观影场景控制

参考项目
