产品模块 1. 幕布投影总成

影音室的“大屏幕”其实是两件东西：天花板上的电动幕布和头顶的投影仪。幕布铝壳嵌进天花板，只露出一条缝，按钮一按 120 寸的幕面垂下来；投影仪用四点固定的吊架挂在楼板上，4K 激光光源寿命长、开机快，不用换灯泡。幕布四周藏一圈约 300 颗的可寻址灯带，给幕布跟色灯用。所有 HDMI 和电源线埋在天花板里走到投影，正面看不到一根线。地下室天生够黑，所以不需要抗光幕，普通白幕反而画面更准。

关键参数 / 组成

  • 120 寸 16:9 电动幕布，铝壳嵌天花板
  • 4K 激光投影，2000 流明以上，观影距离 3.5m
  • 吊架四点膨胀螺栓固定楼板，线缆全部埋顶
  • 幕布边框约 300 颗 WS2812 灯珠，供跟色灯用

产品模块 2. 地台减震座

第二排座位不是沙发，是一块 20 厘米高的地台，它同时是低音炮的“减震座”。地下室的低频容易跟墙体和地面共振，整个地堡嗡嗡响，所以地台从下往上分五层：最底是 20 毫米橡胶减震垫，隔开地面；上面是木龙骨框架，格子里填岩棉吸收驻波；低音炮放在框架里的一块独立减震托板上，与地台面板不直接接触；面板用 18 毫米多层板；最上面铺厚羊毛地毯和懒人沙发。低音从地板传上来是“胸口发麻”的震动，而不是墙壁的轰鸣。

关键参数 / 组成

  • 地台高 200mm，橡胶减震垫 20mm 隔离地面
  • 木龙骨 300mm 格距，格内填 50mm 岩棉
  • 低音炮独立减震托板，不与面板刚性连接
  • 18mm 多层板面板 + 厚羊毛地毯 + 懒人沙发

联动逻辑 3. 观影场景

墙上那个铜色按钮按下去之后发生的所有事，就是这段逻辑。它先让 0201 模拟阳光用 90 秒从黄昏落到零，眼睛不会被突然的黑吓到；接着幕布下降、投影上电预热、Kodi 打开片库、走廊留 5% 夜灯；0203 新风切到静音档但不关，两小时提醒通风一次。之后程序监听播放状态：暂停时灯光回到 20%，去倒咖啡不用摸黑；续播再全暗；结束时整个流程倒放，灯光慢慢回升。输入是一个按钮或一句语音，输出是六个设备的有序动作。

触发 · 阈值 · 兜底 · 出口

  • 触发：铜按钮或语音，先落日 90 秒再动幕布
  • 暂停时灯光回到 20%，续播 3 秒内回全暗
  • 新风静音档不关，每 2 小时提醒通风一次
  • 结束流程倒放，投影散热 2 分钟后再断电

主要实现路径

用 HomeAssistant 场景串联 0201 灯光、幕布和投影，播放状态从 xbmc/xbmc（Kodi）的 media_player 实体读取，片库由 jellyfin/jellyfin 提供

参考项目

xbmc/xbmcjellyfin/jellyfin

联动逻辑 4. 幕布跟色灯

让幕布四周的灯带跟着画面颜色变，画面的红从幕布边上漫出来，地堡全黑的环境下沉浸感翻倍。做法是把投影的 HDMI 信号分流一路进 USB 采集卡，以 1080p、每秒 30 帧抓画面；软件把画面四条边各切 60 段，共 240 段，每段取平均色，再按灯带布局表映射到 300 颗 LED 上，加上平滑和亮度上限，由 WLED 控制器刷新，延迟低于 50 毫秒。整帧接近黑或只有字幕时自动熄灯，不会闪成迪厅；它随观影场景一起开关。

触发 · 阈值 · 兜底 · 出口

  • HDMI 分流 + USB 采集卡，1080p 30fps 取色
  • 四边各 60 段共 240 段平均色，映射 300 颗 LED
  • 黑场 / 字幕自动熄灯，500ms 淡出
  • 延迟 < 50ms，随观影场景一起开关

主要实现路径

用 hyperion-project/hyperion.ng 在 N100 上取色和映射，输出走 WLED 协议驱动幕布灯带，开关由 HomeAssistant 观影场景控制

参考项目
